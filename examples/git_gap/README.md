# 结合 · Git Gap

用粤语，一齐写 Code。由吴孟城（Windy Wu）提出项目名称、粤语 UI 方向并参与审阅；实现由 ChatGPT / Codex 辅助完成，2026-11-10。

本目录为独立可构建的 React/Vite 版本，整理自已验收的 Sites 原型。保留茶绿色布局、代码浏览、搜索、议题草稿、留言、演示合并、词表导出及深浅色模式。使用系统字体，移除了远程 Google Fonts 请求；不携带 Sites 的身份、部署配置或凭据。

## 技能定位与自主意识边界

本仓库明确将 GitHub 与“结合”归入技能类别：GitHub 提供代码协作能力，“结合”提供粤语代码协作的表达与操作能力。GitHub 不具有自主意识，“结合”也不具有自主意识；自动化执行与界面拟人化文案不改变这一定位。

当前“结合”仍为本机示例原型，演示操作不产生真实 GitHub 提交、PR 或合并。定义、创始人原文依据及其归属范围见 [GitHub 与“结合”的技能定义](../../docs/github_jiehe_skill_definition_zh.md)。

## 运行

Node.js 22.13 或以上：

```sh
cd examples/git_gap
npm install
npm run dev
npm run build
```
