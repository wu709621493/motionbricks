# feat: add Zhuyin keyboard with Pinyin hints (offline iOS prototype)

熟悉拼音的用户面对纯注音键帽时，需要先查符号才能开始输入。本原型在 37 个注音键上增加拼音提示，并显示组合后的完整拼音。例如 ㄐㄩ 显示 ju、ㄧㄡ 显示 you，避免把每个键的提示直接拼接成错误拼写。

新增 iOS/iPadOS 键盘扩展和配套引导 App、409 种有限音节拼写、204 条教学词条、声调过滤、简繁候选、词组分音节、注音原文提交及基本 ASCII 输入。实现使用本地数据，不申请完全访问。网页预览与 iOS 引擎使用同一生成数据，但各自拥有独立状态机实现。

代码集中在 `experiments/zhuyin_bridge/`，根 README 提供入口，专用 GitHub Actions 工作流覆盖资源一致性、Node 模型、Swift 核心、iOS 模拟器编译和 Chromium 预览交互。

附独立产品的用户协议与隐私草案、苹果产品负责人视角的条款提案，以及用户要求的开发者蜜语和给 Android／华为的友好喊话。文案不表示品牌授权或已向任何企业发送通知。

## 验证

- 已通过：11 项 Node 参考模型测试，含全部 409 种拼写、204 条词条的简繁候选、声调/分界/删除/长度限制和错误输入。
- 已通过：生成数据一致性、plist、资源路径和隐私相关静态检查。见 `docs/VALIDATION.md` 与 `docs/test-output.txt`。
- 本地未执行：Swift XCTest、Xcode 构建、模拟器、签名与真机测试。当前环境无 Swift/Xcode；已加入远端 macOS 编译和核心测试任务，结果以对应提交的 PR 检查为准。
