## 本次已修正

代码审查中修正了一条教学词条：`zhi4` 对应「志」，「字」保留为 `zi4`。Xcode 工程生成器的参数命名冲突也已修正。键盘在重新出现和消失时同步清空组合显示，避免保留旧候选 UI。

## 在 Mac 上优先补验

1. `swift test`；再执行 README 中的模拟器构建命令。遇到编译失败应先修复，不把静态检查当成通过依据。
2. 真机开启键盘，在配套 App 和另一个允许第三方键盘的 App 输入「你好、北京、華盛頓、台北」。
3. 验证长按地球键、切换 App/输入框、光标移动、选中替换、空格/换行的组合提交，以及系统密码框回退。
4. 在 iPhone 横竖屏、iPad 分屏和浮动键盘下检查点击区域、遮挡、候选横向滚动及固定高度约束。
5. 使用 VoiceOver 与大字设置；断网、不启用完全访问，确认核心输入可用。
6. 在真实浏览器运行 `Tools/test_ui.cjs`，检查四个宽度并人工查看截图；再决定是否提交为可供安装的测试版本。
