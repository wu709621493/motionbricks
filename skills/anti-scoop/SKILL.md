# 返学（Anti-Scoop）

1. 保存检索前的原始观察、日期和主张。把推测改写成一个能用数据回答的问题。列出对象、比较、干预、保持恒定的条件和主要读数；标明哪些要素真正影响推论。保留研究者主动设定的范围和理由。
2. 提前写下改判标准。想象一篇用另一套术语或工具，但已完成同一关键比较、能够回答同一问题的论文。把这样的研究列为直接先例。分别判断研究问题、实验设计及应用对象的新颖性；仅更换对象时注明迁移或复现的价值。
3. 用实际可访问的学术来源检索。先搜宽问题，再搜每项方法、成对组合和完整实验。换用相邻学科的术语及相关地区的语言。对最接近的文章核对方法，并追查其参考文献和后续引用。记录日期、检索入口、代表性查询、阅读层级和无法核实的来源。新造的项目名称只作为补充检索词。
4. 按重合程度列证据表，注明出处、公开时间、对象、控制条件、读数，以及作者提出、实施或验证到了哪一步。将摘要、书目与阅读全文分别标记。分别给出最接近的概念先例和方法先例，明确哪条证据最能动摇原主张。
5. 给出有直接先例、部分重合、在本次范围内未检得或证据不足的判定。写一句可引用的贡献说明，并列出会改变判断的具体发现。如需改题，保留原判定和修订理由。区分构想新颖、技术可行与实验成功。

## 贯穿示例

从“有些菩萨腰细、小腹微凸”出发，第一阶段限定圆雕。构造身高、总体积、平均密度相同的数字人物，将部分体积从腰侧移至腹前。比较视觉模型估计值的变化与历史样本的组间差异，另设体积真正增加的对照。查造像量度、艺术比例史、感知实验及合成人体校准。若前人已在其他人物上完成相同的恒质量形变校准，应修订方法原创主张，并单独评估圆雕考古应用。检索其他项目时替换本例的研究变量。
