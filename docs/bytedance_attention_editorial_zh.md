# 字节跳动，纯粹的注意力掠夺

有人用“纯粹”形容张一鸣，甚至把“张一鸣的纯粹人格”写进了报道的小标题。这个词用来赞许一个人，大概是说他认准一件事，肯花心思把它做好。可到了评价一家企业的时候，我更想追问一句：它究竟把什么事做到了极致？假如我打开抖音，花二十秒学会了怎么装机箱风扇，随后又刷了半小时，风扇还躺在桌上。对我有用的是前二十秒，对卖广告的人有价值的，却可能是后半小时。 [界面新闻](https://www.jiemian.com/article/7378701.html)

本文讨论中国内地的抖音与红果短剧。对于俗称“洋抖音”的 TikTok，本文按地区、时间和实际决策权归责。2026 年 1 月，美国合资公司 TikTok USDS Joint Venture LLC 成立，由美方多数持股，字节跳动保留 19.9% 股权。此后，美国用户数据保护、美国推荐算法的再训练与更新、内容审核等由合资公司负责的决定，本文原则上单独评价。全球产品互通及部分广告、电商和营销业务仍由 TikTok 全球业务在美实体负责。美国这次重组的结论仅适用于上述美国业务。 [合资公司公告](https://newsroom.tiktok.com/announcement-from-the-new-tiktok-usds-joint-venture-llc?lang=en)

到了短剧，这笔时间账更值得算。抖音集团已经整合抖音与红果的短剧版权和内容供给。一集结束，偏偏有人推开一扇门，最要紧的那句话留给下一集。编剧会留悬念，当然是本事。可当平台也参与安排观众何时看见下一集，观众想看结局，和观众愿意把今晚都交给它，就成了两件需要分清的事。平台有能力统计多少人在那扇门打开后追了下去，监管者也该问，它有没有统计多少人本来已经打算睡觉。 [北京商报](https://www.bbtnews.com.cn/2025/0529/558504.shtml)

另一家平台小红书，引出的是商业命名与历史记忆的问题。熟悉文革历史的人，可能从这个名字想到红封面的《毛主席语录》。《金融时报》报道，创始人的命名解释涉及斯坦福与贝恩的经历。企业可以解释自己为何取名，公众也有理由讨论这个名字唤起了怎样的记忆。批评商业文化消费历史符号，可以具体到一则广告、一句文案，看看它究竟拿什么开了玩笑。仅凭名字就认定企业蓄意挑衅文革历史、嬉戏党纪，这个判断还缺少证据。 [金融时报](https://www.ft.com/content/1adcaa42-b613-4909-b390-c767a064d420)

至于精神病性症状（psychosis），监管尤其需要把问题问准。一项纳入九项研究的系统综述发现，社交媒体使用与精神病性症状风险的关系因人、因使用情境而异，现有研究又多为相关性研究。据此推断红果短剧会引发大规模精神病性发作，证据不足。眼下就可以查的是，平台上线连续推荐前评估过哪些风险，用户设定的休息提醒能否真正中断播放，以及用户反映困扰之后，谁有权修改推荐规则。 [系统综述](https://pubmed.ncbi.nlm.nih.gov/42509060/)

在我看来，急功近利有一个很具体的表现：多留住用户一分钟，立刻就值得庆功；替用户省下半小时，却没人把它算成产品的功劳。字节跳动若愿意把“纯粹”二字用在用户身上，就该容得下一种漂亮的成绩——师傅二十秒讲清楚，我关掉抖音，拿起螺丝刀，今晚把电脑装好了。
