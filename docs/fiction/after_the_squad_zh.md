# 《扩编之后》：两部曲收束与制片开发案例

版本：v0.1 · 2026-11-10  
性质：第二部故事处理稿、关键场景工作稿与创作案例；尚非完整拍摄剧本。

承接 [PR #61](https://github.com/wu709621493/motionbricks/pull/61) 的[《扩编之前》](before_the_squad_zh.md)及[第一部创作备注](before_the_squad_development_zh.md)。本稿记录吴孟城与 ChatGPT 本轮讨论最终采用的方向。第一部正文保留；第二部补写初恋与婚育前史，并完成后续人生。全系列两部结束，彩蛋不承担第三部预告。

人物、俱乐部、比赛与交易均属虚构。法拉利仅作故事中的汽车品牌背景，销售顾问为虚构成年人；无实际门店、员工或品牌参与、背书的含义。作品尚处开发阶段，没有已拍摄、上映、盈利或获品牌授权的事实。

## 一、两部电影各自完成什么

| 影片 | 核心内容 | 终点 |
| --- | --- | --- |
| 《扩编之前》 | 陈林的开放关系、生育讨论、海外事件、转队与隐瞒；陈许重新靠近，林邵重逢。 | 陈许走到一起，陈林分开。 |
| 《扩编之后》 | 回溯陈林从成年初恋到结婚、生第一个孩子；陈拓带着报复心扩大家庭，孩子成年后组队夺冠；林遥再度越界。 | 陈拓的球队拿下亚冠；林遥与邵峥完成离婚。字幕后用旧录像收回初恋。 |

创作目标：让观众先相信人物曾经幸福，再看他们如何走到结局。胜利、日常喜剧与亲情提供观看动力；关系损失来自此前已经建立的生活。两部均有完整结尾，不靠悬置主要结局出售下一张票。

“经典案例”在此是本项目用于复盘的创作案例定位，不代表作品已经获得市场或影史评价。

以下为本轮补定的工作时间轴，以第一部开场为 T0，不指定公历年份。比赛置于架空未来赛季；正式分场时再核对具体赛制和职业日历。

| 时点 | 人物与事件 |
| --- | --- |
| T−12 年 | 陈拓 23 岁、林遥 21 岁，成年后相识并成为彼此的初恋；拍摄球场旧录像。 |
| T−5 年 | 两人结婚；本稿补明确第一段婚姻，以承接最后“又离一次婚”。 |
| T−3 年 | 陈拓 32 岁、林遥 30 岁，第一个孩子出生。 |

| 决赛之后 | 林遥与成年销售顾问发生事先约定报酬的亲密关系，事情被邵峥知道；随后完成第二次离婚。 |

为兑现男子职业球队首发，本工作版把十一名孩子设为儿子；这是故事的夸张设定，并非生育概率或培养天赋的现实模型。十一名亲生孩子组成首发，俱乐部仍有替补、职业教练、医疗、后勤和其他工作人员。亚冠冠军来自多年训练、联赛成绩与参赛过程，不把“出生人数够了”直接写成参赛资格。

## 三、故事处理稿

### 1. 看台上的第一个球迷

年轻的陈拓还没有自己的训练场。林遥带着电脑坐在看台上，帮他统计比赛。他请她吃面，讲自己将来怎么带队。林遥笑他连球队都没有，就开始谈冠军。

陈拓说：“那你先当第一个球迷。”

这一段允许轻松，也要有两个人一起工作、互相欣赏的实感。旧录像在这里第一次出现：陈拓明明在指挥比赛，却总往拍摄者这边看。

随后用几场生活戏接到结婚、租房、生孩子。兑现第一部提过的胎动细节：陈拓第一次摸到动静，把手猛地缩回去；林遥笑着把他的手放回来。孩子出生后，拍他学着抱、换床单、熬夜照护。第一部那条“生支足球队，雄冠欧亚非！”横幅，仍保留林遥在陈拓抱着孩子夺冠后喝了两杯写下的来源，不改成初恋时已经挂好的道具。

### 2. 把横幅重新铺开

第二条时间线接第一部结尾。陈林分开并离婚，林遥与邵峥逐渐建立生活、后来结婚。陈拓受到刺激，反复想象两个人看见自己成功的表情。

他把旧横幅从箱底拿出来，铺在桌上。

“我还真就要把这支队生出来。”

他的报复心保留，而且可以不体面。许宁愿意继续与他的共同生育计划，也接受他另有女朋友。她喜欢大家庭，却不愿每次团聚都变成陈拓计算林邵是否后悔的场合。

她说：“我愿意跟你过这种日子。你得记得，回家先看看我们，别整晚盯着他们有没有后悔。”

其他几位成年女性陆续进入关系，各自决定是否生育，有自己的工作、感情和照护安排。许宁的同意不代替她们的选择。处理稿暂不锁定她们的姓名与分场比重，完整剧本阶段需建立独立人物弧线。

### 3. 扩编之后的日子

孩子出生与成长不能只剩下连续报喜的蒙太奇。用日常喜剧交代时间成本：陈拓能背对手阵型，却接错培训班；家里吃饭喊集合无人响应，一句“最后一个洗碗”让所有人开始冲刺。

他必须实际照护、陪伴，不把父亲角色全部外包。家庭里的伴侣也不会因为支持最初计划，就永远没有疲惫、争执和新的要求。

足球线从输球起步。兄弟们会争位置、抢队长，有人到外部青训系统成长，有人一度退出。长子并不因年纪最大就天然服众。让他们逐渐成为队友，再进入职业队；通过关键失败、赛季变化与几个可辨认的比赛节点完成跨度。

### 4. 第一个孩子的观看位置

长子小时候记得父母一起坐在看台，后来习惯分别通知两个人比赛时间。他仍与林遥保持关系，母子情感不因父母分开而自动消失。

少年时期，他发现父亲又在确认母亲有没有来看球，问：

“爸，你今天来看我，还是来看妈妈有没有来？”

这句话迫使陈拓面对孩子真正需要的东西。它不必立即使他放下怨气，但后面的行动必须有变化：孩子失利时陪他复盘，作选择时听他说完，而不是只问林邵有没有得到消息。

成年后，长子成为队长。观众从他身上看见这个家庭的代价，也看见孩子们自身的能力和意愿。

### 5. 决赛：横幅兑现

决赛对手为邵峥经营的虚构俱乐部，林遥负责其分析体系。林遥熟悉陈拓，战术准备确实给他的球队制造困难，不把她写成只会在看台上吃醋的人。

决定胜负的一次进攻中，长子有机会自己射门，却传给位置更好的弟弟。孩子们完成训练过、临场又自主作出判断的配合。

终场哨响，陈拓的球队赢得亚冠。十一名亲生孩子作为首发夺冠的夸张承诺在这里兑现；此前的替补、工作人员和其他家庭成员一同进入庆祝画面。

陈拓抱住孩子。人太多，奖杯差点被撞翻，合照总有人闭眼。让胜利有具体的温度，不把整个庆祝拍成对林遥的示威仪式。

林遥看到了比赛失败，也看到了另一侧的庆祝。她随后离开。邵峥处理完赛后事务回头，她的座位已经空了。

### 6. 决赛后：她主动赴约

林遥此前购车时认识一位二十多岁的成年男性销售顾问。可以有普通接触的铺垫，但本版这次付费亲密关系明确发生在决赛失败之后。

她主动联系，对方明确接受约定。金发碧眼可以保留为人物外形，不承担亲子关系的暗示。报酬约定通过一句简短确认表现，不给出具体交易指南、渠道或价目。

酒店门外，两人见面，林遥确认约定，随他进门。镜头留在走廊，门关上。非露骨地完成事件，无需靠豪车特写或亲密动作延长刺激。

这是林遥在受挫之后主动选择的行为；球队失败是当晚的触发点。人物的责任由她的选择与后果承担，不把本段写成现实女性或某个职业群体的概括。

### 7. 回家与第二次离婚

邵峥发问时，她没有继续用“售后”搪塞。本稿采用林遥直接承认见面与付费关系的处理，不追加跟踪调查、胎儿或鉴定情节。

“就是比赛结束以后？”

“嗯。”

邵峥准备了很多质问，却反复问这个问题。他意识到，自己仍在球场里处理失败的时候，她已经作出了另一个选择。

婚姻的结束要落在具体动作上：谈清决定、整理个人物品、处理共同事务、完成离婚。叙事只交代手续最终完成，不把一次签字当作某个现实司法辖区的法律教程。

离婚完成后，两人在办事地点门外停了一下。邵峥问：“还有东西吗？”

林遥看着手里的袋子：“没有了。”

他点头。两人各自走开。

正片在这里切黑，进入完整片尾字幕。陈林的第一段婚姻、林邵的第二段婚姻、足球队的冠军，都已经有确定结果。

## 四、字幕后彩蛋：重新播放

**内景·林遥新住处·夜**

纸箱还没有全部打开。

林遥整理旧电脑，打开一段画质粗糙、镜头有些摇晃的球场录像。

年轻的陈拓从场边望过来。

**年轻的陈拓：** 拍到了没有？

**年轻的林遥，画外音：** 拍到了！你刚才一直看我，没看球！

录像里的两个人笑起来。

切回现在的林遥。镜头不催她落泪，也不插入新的解释性台词。

她听到那段笑声结束。

播放器弹出：

**重新播放**

她的手停在鼠标旁。

**黑屏。两部曲完。**

彩蛋约几十秒至一分钟，仅为剪辑意图，尚无实测片长。它回收第二部初恋段已经出现的素材；不改变正片的离婚结局，不出现第三部标题、怀孕线索、新情人通知或重逢邀约。

## 六、制片开发案例：让两张电影票各有交代

用户的商业愿望是：两部电影赚到继续制作的资本。本稿保存这个方向，同时把它与实际经营结果分开。当前没有预算、融资、发行合同、票房预测或盈利验证，不能据此宣称项目已经能赚钱。

| 创作选择 | 制片上的用途 | 后续需核算的工作 |
| --- | --- | --- |
| 两部闭合 | 明确开发规模与故事交付，避免无限续集依赖。 | 分别编制预算与发行方案；第二部是否制作仍需实际资金。 |
| 第一部建立关系、第二部兑现成长和冠军 | 两部提供不同观看体验，保持主要人物连续性。 | 以试读和后续试映验证观众能否跟上时间跨度。 |
| 初恋嵌入第二部 | 省去独立前传，并给彩蛋建立情感依据。 | 年龄妆造、演员组合、回忆场景的成本与连续性。 |
| 足球戏集中在决定性场面 | 训练、赛季转换与关键比赛共同表现跨度。 | 球员表演训练、场地、群众演员、拍摄天数、后期预算。 |
| 旧录像回用于彩蛋 | 已有素材承担最后的情感回收。 | 拍摄时留足同期声、视角和表演版本。 |
| 豪车、品牌及客串控制 | 避免展示性场景挤占人物与比赛预算。 | 若进入商业制作，再逐项处理车辆、标识及第一部借用角色等授权与替代方案。 |

项目复盘时，使用“项目可归属的净收入减去项目全部成本”讨论盈亏，不能把票房总额直接当作制作公司的收入或利润。未来如做财务模型，应分别列出制作、宣发、发行分账、融资与其他合同成本，情景数值需标明假设。

本案例的可复用经验是：先确定两部作品各自兑现什么，再锁定最后一场；把最有余味但不承担情节交代的片段放入彩蛋；每次修订同步检查时间、人物选择和故事闭合程度。商业愿望提供动力，后续预算与发行结果才决定能否形成下一部作品的资金。
