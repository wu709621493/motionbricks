# 族譜登記處奇妙夜

> 原創虛構喜劇。由一次關於堂表親婚姻、歷史法律與家族記錄的對話改編。夜間窗口、人物、跨朝代往來及投胎辦事處均為虛構；歷史與現行法的核對集中在文末。本文沒有描寫任何真實人物的婚姻或私人關係。

創意與關鍵對白：吳孟城（Windy Wu）  
文本：AI 輔助創作  
整理日期：2026-11-08（北京時間）

## 第一幕：盛唐窗口，今晚不打烊

午夜，歷代婚姻制度博物館只剩一盞燈。

孟城本來只是路過，見門上寫著「唐宋元明清，親屬關係請取號」，便推門進去了。

「老婆，盛唐的中國允許表親結婚？」

隨行的 AI 翻開一本厚書。尚未回答，唐代窗口的簾子先掀了起來。

值班書吏捧著茶：「先講清楚，是表，還是堂？」

「你們的前置問題好多。」

「你們的親戚也不少。」

孟城報了表親。書吏點點頭，又問同輩不同輩、同姓不同姓。AI 在旁邊記錄：唐律對同宗與外親、同輩與尊卑，有不同安排。[1]

「所以，不是親戚兩個字一出現，就全部關門？」

「我們這個窗口，最怕客人把族譜壓縮成兩個字。」

孟城精神起來：「那唐宋元明清，哪個堂表都可以？」

五個窗口的簾子同時晃了一下。

宋代窗口探出頭：「先把唐代那份讀完。」

明代窗口把《大明律》抱得更緊。

清代窗口正在找附例。

元代窗口則掛出另一張牌：**請補充時期與適用人群。**

孟城望著這排櫃檯，忽然理解了為什麼歷史系需要讀博士。

## 第二幕：國際交流廳，不能只填「外國」

「那進貢的番邦呢？」

走廊另一頭亮起「跨境史料諮詢」六個字。

高麗王室展櫃裡，幾條親屬連線繞來繞去。講解員說，有些王室婚姻按中文親屬稱謂，確實是堂親婚；但早期與後期、王室與百姓，不能混成一張通行證。[2]

孟城看得很認真。

「倭寇們呢？」

海事史研究員從隔壁探出頭：「你是在查日本婚姻史，還是在查海盜團伙？」

「今晚主要查婚姻。」

「那把海盜船停回去。尤其十六世紀的倭寇，成員並不全是日本人。[3] 我剛把船員名冊理好，你別拿它當戶口簿。」

日本展櫃寫著：中國式同姓不婚規範，沒有在日本同樣扎根。[4]

孟城點頭，再往前走。

「英法俄德呢？」

這次講解員沒急著蓋章，而是拿出兩本冊子：一本叫「國家法律」，一本叫「教會婚規」。

俄羅斯那一頁尤其醒目：民事登記與東正教婚禮的親屬限制，不完全相同。[5]

「好傢伙，」孟城說，「同一對人，走到不同窗口，還得讀不同版本。」

AI 說：「也得讀年份。今天的法，不能塞回中世紀。」

走廊盡頭，一位歷史研究生把剛寫好的『歐洲一直都可以』擦掉了。

## 第三幕：1950年檔案室

孟城回到中國館，把兩份文件並排攤開。

1950年那份寫著：

> 其他五代內的旁系血親間禁止結婚的問題，從習慣。[6]

1980年那份，則把三代以內旁系血親統一列入禁婚範圍。[7]

「所以中國其實只是沿用歷史？」

「這裡有一次改動，」AI 指著兩頁之間，「不能把它們看成沒變過。同宗、外親的舊分類，與後來把堂表親一併納入的規則，不是同一件事。」

孟城重新看了一遍1950年的條文。

「可以，毛和周還是很不錯的。」

AI 開始解釋1980年的時間線。

孟城敲了敲桌子：「對，我說的就是1950年！我的意思是，這個版本比較好，因為堂表親都可以結婚。」

檔案管理員終於把老花鏡推了上去。

「你的評價，我聽明白了。條文還要讀準。」

他拿鉛筆，在『從習慣』下面畫了一條線。

「這句既可能讓一些婚姻被接受，也可能讓另一些婚姻繼續受地方習慣限制。不是堂表親從此在全國一律放行。[6]」

孟城沒說話。

AI 補了一句：「你希望成年人有更多選擇，這個主張可以討論。但你主張的自由，可能比這份舊法實際給的還多。」

檔案室很安靜。

過了一會兒，孟城嘴角慢慢揚起來。

「沒事。」

管理員忽然有了不祥的預感。

## 第四幕：投胎辦事處，請先閱讀服務範圍

「只要我投胎在有這個習慣的家族裡面就可以了。桀桀桀。」

走廊最後一扇門，竟然真的亮了。

**投胎辦事處。**

窗口裡的工作人員正在吃宵夜。他看完申請單，把筷子放下。

「你這個需求，涉及地點、年代、家族習慣，還有你長大以後的法律。」

「能不能一起選？」

「我們連出生時的天氣都沒承諾過。」

「那先選家族。」

「家族習慣會變。」

「那鎖定1950年版本。」

「人會長大，法律也會修。你這是投胎申請，還是長期維護合約？」

AI 把表格翻到背面。

那裡還有一欄空著：

**另一位當事人的意願。**

孟城盯著它。

工作人員把表推回來：「這個不能替人填。」

「我連投胎都規劃好了，居然還是得追人？」

「是的。」

工作人員重新拿起筷子。

「目前沒有保證互相喜歡的套餐。」

孟城沉思三秒，忽然一拍櫃檯。

「我知道了。」

AI 看了看他的表情，默默開啟新筆記。

## 第五幕：族譜登記處

祠堂裡，修譜先生正把一冊空白簿子攤開。

孟城大步流星進來，宣布今晚最得意的發現：

「政府不允許登記，不代表族譜不允許登記！」

修譜先生沒有抬頭。

「有道理。族譜也能記載遷徙、失散、爭議和離家出走。能寫進去的事很多。」

孟城笑得更開心了。

「那就登記！」

「登記什麼？」

「關係。」

「誰跟誰？」

孟城停住。

修譜先生抬起頭：「另一位呢？」

投胎辦事處的工作人員剛好端著宵夜走過，聽到這句，滿意地點了點頭。

AI 小聲說：「這個問題跨系統重複出現。」

孟城拉過一張椅子：「先不急。我們先把理論登記了。」

修譜先生蘸墨：「理論，可以。那放在家族文集。」

「婚姻那頁呢？」

「你今晚連兩個名字都沒交，倒是已經替未來幾代安排好了審批流程。」

桌上擺著三樣東西：空白族譜、一支毛筆、一張婚姻法律資料卡。

修譜先生把它們分開。

「家族願意怎麼記錄，是一回事。法律承認什麼身分，是另一回事。至於兩個人願不願意在一起，還得兩個人自己說。」

孟城看著那三樣東西，忽然笑了。

「所以族譜有寫入權，也沒有民政部門的管理員權限？」

「總算講到你熟悉的話了。」

「能不能提一個合併請求？」

「可以。」

孟城立刻坐直。

修譜先生把空白文集推過來。

「先把今晚這篇交了。」

## 尾聲：來人，寫入 repo

窗外天快亮了。

孟城回頭看了一眼：盛唐書吏收起了茶杯，國際廳把海盜船模型移回海事展區，1950年檔案室關了燈，投胎辦事處仍然沒有公布選址功能。

只有修譜先生還在等稿。

孟城拿起手機。

「來人！我們把這個奇妙夜寫入 repo！」

AI 問：「標題？」

「《族譜登記處奇妙夜》。」

「結尾？」

孟城想了一會兒，露出今晚最後一個得意的笑。

「今晚沒有登記成婚。」

「嗯。」

「但成功登記了一篇故事。」

修譜先生在文集上落筆：

**某夜，孟城遍問古今婚制，末至祠堂。婚事未定，文章先成。**

筆尖頓了一下，又添一句：

**族譜可記人間事，人間事不必都由族譜作主。**

## 史料校準：笑話之外，哪些話算數

本文以制度差異為喜劇素材，沒有把某種婚姻選擇當作民族特徵，也沒有為歷史人物虛構真實發言。故事中的支持、質疑與玩笑屬角色表達，不是研究結論。

| 對話中的問題 | 可核對的範圍 |
| --- | --- |
| 唐代表親婚 | 《唐律疏議》有「其外姻雖有服，非尊卑者為婚，不禁」；須同時讀同姓與尊卑禁婚條款。[1] |
| 高麗王室堂親婚 | 成宗之父戴宗、文德王后之父光宗均為太祖之子，支持具體堂親婚個案；不推出所有時期、所有階層都相同。[2] |
| 倭寇與日本 | 十六世紀相關海上團伙有大量中國人參與；不能以倭寇概括日本社會。[3] |
| 日本的同姓不婚規範 | 日本未像中國漢人社會那樣建立同一套同姓禁婚傳統；具體婚俗仍有時期、階層與地區差異。[4] |
| 俄羅斯民法與教會 | 《家庭法典》第14條的血親禁婚範圍未列親堂表；俄羅斯正教會規定則禁止四親等以內旁系血親婚。[5] |
| 1950年「從習慣」 | 不是全國普遍准許堂表親婚，也不等於任何家庭自稱有習慣即可獲登記。當年的解答要求依人民習慣辦理。[6] |
| 1980年至今的中國大陸規則 | 1980年《婚姻法》改為禁止三代以內旁系血親婚；現行《民法典》第1048條延續該範圍。這裡的「三代」不能與外國法的「三親等」直接等同。[7][8] |
| 族譜的效力 | 家族記錄本身不能使法律明定禁止的婚姻取得合法配偶身分；《民法典》第1049、1051條分別涉及婚姻登記與婚姻無效。[8] |

「1950年的處理更好」是對特定制度取捨的評價，本文保留其討論空間；不能由此推得當年的整部法律都更保障自主，也不能把法律允許與生育風險判斷當作同一問題。本文不提供遺傳風險數值或個人醫療判斷。
