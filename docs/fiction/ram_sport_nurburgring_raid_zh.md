# RAM Sport：纽伯格林百鬼夜行团本

创意：吴孟城（Windy Wu）｜AI 辅助编写｜2026年11月8日

八人协作团本，预计一局35—45分钟。RAM Sport 车队进入一条被幽灵数据占据的虚拟纽伯格林北环，夺回终点计时权，将困在循环中的车队带回维修区。

这是 CF、DNF 与百鬼夜行意象的非官方跨界同人设计。“模块”指玩法结构；本文为副本剧本与规则草案，不是已接入游戏的程序。百鬼夜行采用原创妖怪编队；所有数值、Boss、赛车技能与对白均为本团本创作。

## 开场剧情

午夜，RAM Sport 的一千根 DDR4 同时亮起。

工程师盯着监控：“容量够，带宽也还有，点解终点一直读唔出？”

屏幕弹出一行字：

**您前方仍有99辆幽灵赛车。预计等待时间：上一辈子。**

孟城拍了拍方向盘：“叫个识得管理亡灵嘅过嚟。”

副驾驶的女死灵术士合上赛道手册，抬手画出黑色法阵。

“降临——尼古拉斯。”

王子从蛛丝中走出来，低头看见自己手中的维修工牌。

“我受召前来，是为了征服这片土地。”

“好。”她把耳机塞给他，“先征服无线电。有人霸住频道讲咗七分钟。”

赛道广播随即响起：

“欢迎来到绿色地狱。本站采用歼灭规则。”

CF 老兵摸了摸空枪套：“枪呢？”

维修区大门轰然落下。远处的第一只妖怪，推着装满武器的工具车，慢慢拐进浓雾。

尼古拉斯看了一眼车尾的 RS：“Rennsport？”

孟城：“RAM Sport。物种不限，唔准挂机。”

## 编队与基础规则

八名玩家分成两支四人车组。每组驾驶一辆四座幻想赛车：一名驾驶员、一名火力手、一名工程师、一名术式手。全队一名术式手扮演女死灵术士，另一名负责封印。玩家可在战斗间的维修区换岗。

| 岗位 | 操作任务 | 关键协作 |
| --- | --- | --- |
| 驾驶员 ×2 | 驾驶、避让预警、对齐机关 | 为火力手保持射界，为术式手进入施法范围 |
| 火力手 ×2 | 拾取武器、清除敌人、打断读条 | 把稀缺弹药留给机关与首领弱点 |
| 工程师 ×2 | 维修、供能、管理任务队列 | 处理设备过热与重复任务 |
| 术式手 ×2 | 尼古拉斯指令或幽灵封印 | 区分敌对妖怪和可护送的幽灵车手 |

战斗包括驾驶段与封闭战斗区。到达战斗区，两车停入指定平台，全员下车；清场后才重新发车。射击与施法均采用游戏化规则。

四个关卡各算一个回合。每回合玩家只有一条命，出局后可观察和报点，不能操作机关或造成伤害；通过关卡后全员在下一个维修区恢复。团灭、护送目标被摧毁或关卡超时，重试当前关卡，已通过的关卡保留。

回合开始时不带主副武器；武器从场内固定资源点拾取。职业指令与工具保留，武器、弹药在回合结束时清空。死亡玩家掉落的武器可由队友接手。首关提供足够基础武器，不靠随机刷枪卡住进度。

尼古拉斯不是第九名玩家。他由女死灵术士切换“跟随、守护、攻击”三种本团本指令；召唤者出局则暂时退场。王子战败可在20秒后重新召唤，每回合最多一次，不能复活玩家、替玩家完成双人机关或越过关卡门。

## 第一关 维修区歼灭战

**Boss：无主车队长。目标：夺回两枚发车芯片。限时6分钟。**

维修区被两队空壳维修机器人占领。近处是基础武器，远处的高火力武器箱由机器人看守。玩家必须先用基础装备夺取工具车，再分配破解护甲的武器。

车队长每损失四分之一生命，便呼叫两名搬运兵抢走一箱弹药。搬运兵只跑向明确标出的仓库出口；到达后弹药被锁入仓库，可重新攻占取回。

两枚发车芯片分别位于车库两侧。清掉车队长与剩余敌人后，由两名存活玩家在10秒内依次启动两处控制台，打开出口。若仅剩一人，车队长掉落的一次性延时继电器可代替另一人，避免胜局被人数条件锁死。

**团长口令：**“唔好八个人抢同一把枪！冇枪嗰个先报资源，唔使报仇！”

**过关伏笔：**车队长最后一条维修记录写着：“本车已到站。系统仍判断它正在路上。”

## 第二关 狐穴百鬼夜行

**Boss：提灯领队。目标：从百鬼巡游中护送三辆幽灵车。限时8分钟。**

狐穴主题驾驶段共出现三波妖怪，数量为24、32、44，总计100只。它们不是同时塞满道路：前一波处理完才开始下一波。另有三辆中立幽灵车，不计入百鬼数量。

本关每辆车都有独立的敌我符号；妖怪不能伪造队伍名单。

| 原创妖怪 | 干扰方式 | 可观察的破解线索 |
| --- | --- | --- |
| 提灯鬼 | 将假出口照得比真路更亮 | 假路缺少连续的编号路标 |
| 轮入道 | 沿预告轨迹滚动，封住一条车道 | 地面提前显示轮迹与方向箭头 |
| 反光镜妖 | 在后视镜生成追车幻影 | 车外视野与队伍雷达没有对应实体 |
| 排队鬼 | 贴近赛车后，占据一个术式槽位 | 术式面板出现带倒计时的陌生任务 |

三辆中立车最初没有轮胎接地影，遭误伤也不还击。封印术式手辨认其车号，尼古拉斯进入守护模式，为它们打开短暂的穿雾通道。两辆玩家车交替领航与压后，护送目标共享一条“车队凝聚度”；凝聚度归零则重试。

提灯领队在第三波现身。此时如果一味追杀它，幽灵车会被落在雾里。必须先让三辆车进入路侧收容区，解除其护盾，再清除剩余敌对妖怪。

**王子对白：**“这些亡灵不听我号令。”

**女死灵术士：**“它们拿的是导航订单，不是你的军令。”

## 第三关 旋转弯蛛丝阵

**Boss：弯心织网者。目标：解除三个赛道封印。限时7分钟。**

以 Karussell 旋转弯为舞台意象的封闭竞技场内，织网者不断把玩家拖向弯外。三个封印柱分别连接一条蛛丝。任何时候只有被尼古拉斯显形的那条蛛丝可以被攻击。

循环分成三个动作：

1. 死灵术士将尼古拉斯切换为守护，抵挡一次拉拽，保护工程师完成柱体供能。

2. 供能完成后切换攻击，在指定柱旁展开本团本改编的蛛丝显形阵。

3. 火力手击断显形蛛丝，取得封印碎片；王子回到跟随，带队躲过下一次扫场。

敌人的假指令会出现在场内广播，但真正的模式按钮始终保留玩家所选状态。不能用隐藏界面或颠倒按键制造“难度”。

如果尼古拉斯退场且重召次数耗尽，场内应急封印器会启动。两名玩家可分别供能和显形，但每次需要更长的站位时间。若只剩一人，应急装置自动维持供能，幸存者仍需独自应对清怪与显形。召唤协作能提高效率，失误不会直接把关卡变成不可解。

三个封印解除后，织网者失去外壳，进入最后的歼灭阶段。

**王子对白：**“我以为你召唤我，是为了展示王族的力量。”

**女死灵术士：**“你刚才保住工程师，就已经展示咗。”

## 最终关 长直道与终点的垃圾回收之王

**Boss：GC 王。目标：让计时系统承认这一圈已经完成。限时10分钟。**

长直道尽头，报废赛车、过期计时单和未结束的召唤契约堆成一尊巨人。它的胸前镶着一块仪表：

**可用容量：很多。可执行任务：零。**

这是虚构的“死循环”反派。内存、任务队列和垃圾回收在此是战斗隐喻，并非真实硬件性能模型。

### 第一阶段 重复任务

GC 王不断复制同一张维修工单。两名工程师各自处理一侧队列，火力手守住处理平台，封印术式手标记原始工单。删除副本可降低积压，误删原件则刷新本轮工单。

攻击 Boss 只能压制它，不能越过队列机制。

“我一千根内存都喂畀你，你仲想点？”

“再来一千根，”GC 王回答，“我就能同时卡住更多人。”

### 第二阶段 全场暂停

生命降至60%与30%时，GC 王分别开始一次8秒“Stop the World”读条。三道计时锁依次亮起，必须按以下顺序完成：

- 王子或应急封印器揭示真正的锁；

- 火力手击断外壳；

- 工程师关闭重复任务源。

每一道锁都显示独立进度。失败会令角色冻结3秒并受到一次团队伤害，不直接判定团灭。提前进入封印术式手的守护区可减轻伤害。

**团长口令：**“停输出！先搞清楚边个任务仲需要活着！”

### 第三阶段 最后一圈

GC 王倒下，只剩通往终点的一段短距离。三辆获救幽灵车重新出现。两辆玩家车至少有一辆仍可行驶，便能拖带另一辆；无存活玩家则本回合失败。

通关需要三辆幽灵车和两辆玩家车全部越线，并由任一存活玩家在终点控制台确认“本轮结束”。少一辆车，系统就会继续等待。完成清场只是取得最后行驶权。

尼古拉斯主动走进收容队列，逐一解除已经完成的召唤契约。不是抹掉那些车手的成绩，而是让他们不必再重复这一圈。

系统终于显示：

**已完成。无需再次证明。**

## 结算与尾声

基础通关奖励：RAM Sport 车尾标、尼古拉斯维修工牌、百鬼夜行车队涂装。全是外观与剧情收藏，不增加下一局基础伤害。

| 成就 | 判定 |
| --- | --- |
| 少啲等 多啲跑 | 最终关未吃到全场暂停 |
| 王子有工伤保险 | 尼古拉斯全程未战败 |
| 一只鬼都不能少 | 三辆幽灵车均未受到玩家伤害 |
| 唔准挂机 | 八名玩家各完成至少一次岗位交互 |
| 人 Sport 机 Sport 鬼 Sport | 八人均在最终回合存活并完成终点确认 |

天亮了。女死灵术士准备解除最后的召唤。

尼古拉斯却站在领奖台旁，不肯走。

“还有何事？”她问。

王子举起工牌：“夜班补贴。”

工程师递来一张签字单：“你没有打卡。”

整条维修区忽然暗了下来。

团长立刻打开麦克风：

“各位注意，隐藏 Boss 开了。”

孟城看着那张纸，缓缓系回安全带。

“下一本——人事部。”
