# After MCP there are still bugs, what the hell, Dario?

*《Elon 的愤怒》｜虚构短剧*

中午十二点零七分。硅谷某地下会议室。八个人围着一张长桌，看 Claude 通过 MCP 给大家订午饭。

工程主管拿起激光笔。墙上三盏绿灯。模型在线，工具在线，披萨店在线。

**Elon**　很好。我的要求是什么？

**工程主管**　一个大号意式辣肠披萨，切八块。

**Elon**　现在进展到哪一步了？

**工程主管**　披萨店老板想跟您通个电话。他问附近是不是有学校开运动会。

Dario 把百叶窗拨开一条缝。楼下，一个戴头盔的小伙子正用脚撑住玻璃门，好让后面的人把饼推进来。

**Elon**　订了多少？

**工程主管**　四十八个。好消息是，您的优惠券每次都生效了。

Elon 慢慢摘下眼镜。

**Elon**　亲手点过下单按钮的人留下。

七把椅子同时往后一响。

**Elon**　都坐回来。这句话现在听起来比刚才严重多了。

走廊里，送餐员撕下一张小票。屋里突然传来一声——

**Elon**　**After MCP there are still bugs, what the hell, Dario?**

**Dario**　Elon，把手机给我。你们等店家回复，等了多久？

**工程主管**　两秒。超过两秒就自动重试。

**Dario**　每次重试，用的是同一个订单号吗？

**工程主管**　当然不是。订单号怎么能重复呢？

Dario 把手机还给 Elon。

**Dario**　查清楚了。你每隔两秒走进同一家店，换个名字，再要一张饼。MCP 替你把意大利语都说得很地道。

**Elon**　我花了那么多年才让一枚火箭能发射两次。你们一个中午就让一张优惠券飞了四十八趟！谁定的两秒？

实习生把上周的会议纪要转到大屏幕上。第一条，Elon 亲笔批示。

*「任何让用户等两秒以上的东西，都给我再试一次。」*

屋里只剩投影仪的风扇声。

**Elon**　……把后半句删了。先问披萨店，第一单到底收没收到。

门开了。送餐员把一摞小票搁在他面前，递过来一支笔。

**送餐员**　吴该，签四十八次。

**Elon**　买的时候一次都不用我确认，收货要我签四十八次？

**送餐员**　我打过电话想跟你确认㗎，老板。

**Elon**　那我怎么没接到？

**送餐员**　响咗两秒，你就挂咗。

送餐员把笔递过去。Elon 没接，反而双手一撑桌沿，朝 Dario 怒吼出一句字正腔圆的普通话。

**Elon**　😤我从河北省来！

Dario 下意识看了一眼投影。字幕还没开。

**送餐员**　河北哪儿的？

**Elon**　……这句我没学。

**送餐员**　那我懂了。刚才电话里也是您？我问了四十八遍「送到哪个门」，您回了四十八遍「我从河北省来」。

实习生默默拔掉了测试手机。屏幕上还开着中文语音验收表，统共就一行。

`用户能否用普通话清楚表达来处？　通过 ✓`

**Dario**　Elon，人家问你送到哪个门。

**Elon**（接过笔）　东门。八个人。一个饼。

**送餐员**（冲走廊喊）　老刘！写「东门八人」嗰张先唔好烤！佢又落咗一单！

**Elon**（一掌把黑卡拍在桌上）　😤刷我滴卡！

**送餐员**　四十八张小票，全刷一张卡？

**Elon**　全刷！我今天就想趁热吃一口！

门外那位老刘探进半个身子，认认真真看了 Elon 一眼。

**老刘**　刚才听你喊「我从河北省来」，我还寻思这普通话学得挺生硬。这个「刷我滴卡」倒是真情实感。

送餐员刷完，撕下小票。Elon 总算拿起一块披萨。Dario 对着手机讲了半天，正逐位报信用卡背面的客服电话。

**Elon**　你又在干什么？

**Dario**　给你解冻。银行看见四十八笔一模一样的消费，怀疑你的卡被盗刷了。

Elon 把披萨叼在嘴里，一把抢过电话。

**银行客服**　先生，请问这四十八笔交易里，有几笔是您本人想买的？

Elon 嚼了半天。会议室里七个人都在等他答。

**Elon**（咽下去）　Dario，你记一下。我们做了三年 AI，整个系统里，第一个把问题问对的人在银行。

---

*片尾。会议室只剩半盒凉披萨，实习生还在收拾。*

**Elon**　哎，你从头到尾都没说话。要是让你设计，一开始该问我什么？

**实习生**　老板，八个人，一个饼，够吃吗？

Elon 看了看他。小伙子从十二点忙到现在，手上那一块只有饼边。

**Elon**（把自己那块分给他）　下次订两个。

门外立刻响起刷单机吐纸的声音。

**Elon、Dario**（同时冲门外）　**下次！！**
