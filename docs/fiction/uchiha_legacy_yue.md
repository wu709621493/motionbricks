# 宇智波的传承

木叶中考出过一道真题，题图系团藏只右手。点解出题老师会有张相，要由小南屋企部 PS2 讲起。

嗰晚鸣人连出三铺色诱之术。第一铺，佩恩六道共享视野，六双眼一齐望住，坐隔篱揸手掣嗰个长门笑到撳错暂停。到第三铺，团藏话等佢嚟，除开右臂绷带，十只写轮眼一齐睇，都系输。

「你净系识出呢招㗎？」

「你净系识中呢招，我换嚟做乜？」

小南将原本写好嘅「今晚十人观战」划咗，改成「一人」。团藏伸手攞翻九张飞钱，俾佢影低咗。

几年后，张相印咗喺数学卷最后一页。第一问，十只眼各自可开可合，一张相影得出几多种状态？第二问，十只眼逐只眨，每只眨一次，有几多种先后次序？

窗边有个细路，第一问唔识，喺草稿纸画两只眼。一开一合，同一合一开，佢初头当成一样。画到第二次，佢将其中一只加条眼眉，先睇出左右调转咗。于是佢由一只眼开始，每加一只，就将已有嘅图照抄两份，一份画开，一份画合。抄到第四只，佢停手，写低「2 的十次方，1024」。

第二问顺得多。第一只眼有十个拣法，眨完剩低九个，再眨剩八个。佢一路乘到一，写低 3,628,800。刚刚放低笔，一张擦胶碌到手边，纸套上面有四个字。

「你开眼啦。」

监考老师都睇见。个细路一抬头，两只眼各有两粒勾玉，仲转紧。老师俯低身，细细声问：「有冇睇过隔篱张卷？」

「阿 Sir，我连自己开咗眼，都要人哋话我知。」

隔篱位举手认领擦胶。老师将擦胶收起，翻过草稿纸，见到嗰两只一模一样嘅眼，其中一只俾人用铅笔郑重噉补咗条好粗嘅眉。佢笑咗下，叫两个都继续做卷。

后来个细路执好书包，喺校门口等到隔篱嗰个。「头先多谢你。其实你点知嗰个叫二勾玉？」

「我阿妈做监考嗰年都见过。佢仲留低张相。」

好多年后，个细路个女都去考试。临出门，老豆搵翻嗰张草稿纸畀佢睇。佢睇咗半日，最钟意有眼眉嗰只，问可唔可以剪落嚟，贴喺笔盒上面。

「咁神圣嘅家传之宝，都畀我剪？」

「算啦，反正系中考，无所谓噶。高考加油就得啦。」

阿女剪完，喺眼眉下面写咗「高考加油！」。老豆攞起笔盒细看。

「今次呢个叹号，唔使乘。」

老豆心里谂：「叼，当年中考性感情感密度果然是太高了。」
