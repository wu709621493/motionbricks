# 《扩编之前》：创作决定与续集留白

版本：v0.1 · 2026-11-10。配套[第一部文学剧本](before_the_squad_zh.md)。

本文件记录本次讨论最后采用的方向，供后续编剧、表演与剪辑接续。正文是待拍电影的工作稿，不把预期片长、演员参与或票房设想写成已经发生的制作事实。

## 第一部的范围

开头由“生支足球队，雄冠欧亚非！”进入：陈拓、林遥已有一个孩子，正在谈陈拓与许宁再生一个孩子的可能。米切尔作为退役后的架空邻居加入，先带来轻喜剧，再在搬家时送别。

林遥在原定四个月的海外项目期间与邵峥发生第一次关系，随后陷入严重危机，求助并接受照护，提前请假回国。陈林认真讨论并实施共同转队。转队并未切断人物的欲望与选择：陈拓重新靠近许宁，林遥主动联系邵峥并重逢，最后陈许走到一起，陈林分开。

本片不安排第二个孩子已经出生，也不把陈许的结合直接当作生育计划已经获批。第一个孩子的后续故事留给第二部。

## 已确认的创作选择

| 项目 | 本版采用的处理 |
| --- | --- |
| 出轨动机 | 可以是已有吸引、临场欲望和主动选择。用“记得他咖啡不加糖”等短细节表现，不加长夫妻失和的前置解释。 |
| 开放关系 | 陈林认可开放，但可能高估了自己对其后果的理解与承受力；正文同时保留他们关于坦诚与职业交集的约定。隐瞒是具体选择，不能被概念自动抹掉。 |
| 林遥的危机 | 危机是真实的剧情事件，表现求助与支持；不呈现自伤方法，不以危机换取陈拓必须原谅的承诺。 |
| 危机之后 | 不把一次崩溃写成已经永久改造了人物。林遥之后仍可能重新选择邵峥；不能倒过来把此前危机揭示为假装或操控。 |
| 转队 | 当时双方真诚尝试过，也有陈拓想逃离痛苦的成分。搬家不保证关系修复。 |
| 许宁 | 陈拓搬家时把她搁在脑后，没有完成一场体面的告别；之后重新靠近她。她接受陈拓，也可以保留自己的欲望、怨气和没有问完的问题。 |
| 关系落点 | 陈许先重新走到一起，陈林随后分开；不擅自改成所有关系都交代清楚、互相祝福之后才各自开始。 |
| 林邵重逢 | 转队后，陈许逐渐靠近的同时，林遥已主动联系并再次与邵峥在一起。她的行动不必由发现陈许、报复陈拓来触发。 |
| 两处晚餐 | 保留陈许的简短谈话；林邵一侧拉长到大堂、晚餐、门口、电梯和房间。长的是相处的当下，不是出轨的免责背景。 |
| 关键表演 | 邵峥的“你想好了？”要带诱惑的微笑，林遥回答“你明明希望我说想好了”。保留她主动整理袖口、主动靠近的动作。 |
| 亲密场景 | 采用最后确认的电梯与房间版本：吻、短暂笨拙、挪椅子、床沿谈话与切黑。首次海外关系保持短切；重逢是本片第一次充分展开的亲密场景。 |
| 交叉剪辑 | “还没定。你先睡。”一端掩住林遥的行踪，另一端让陈拓放下手机、继续听许宁说话。观众知道的比人物多。 |
| 米切尔的判断 | “他们不是搞足球的料”是这个角色没有说出口的个人判断。他想到自己失去同伴的经历，也承认自己可能看错；不把经历死亡立为职业能力门槛。 |
| 米切尔的告别 | 最后只说“祝你们好运”。他不替主角解决第三幕，也不以演说盖棺定论。 |
| 陈林分开 | 关系落点已定；第八场提供最短收束工作版本，具体如何让观众难受、冲突强度及信息揭露顺序仍可调整。 |
| 第一个孩子 | 保留日常存在与照护连续性。本片不展开其后续受伤、成长、立场或重大反转；第二部再写。 |

## 连续性时间线

| 阶段 | 明确发生的事 | 尚未发生或未确认的事 |
| --- | --- | --- |
| 家庭开场 | 陈林已有一个三岁的孩子；陈许讨论共同生育；林遥准备申请四个月外派。 | 许宁没有怀孕，没有三人共同育儿的既定安排。 |
| 外派前 | 陈拓开始调整工作照护安排；米切尔成为邻居。 | 米切尔的帮助没有解决关系问题。 |
| 外派第七周 | 林遥与邵峥发生第一次关系，并向陈拓隐瞒。 | 不补写一段必然导致出轨的长期婚姻失和。 |
| 约三周后 | 林遥危机求助、得到支持并坦白；之后提前结束外派、回家。 | “四个月”是原定项目长度，不能误写成四个月全部完成。 |
| 回家与转队 | 陈林谈工作、生活与信任，交接并共同搬家；陈拓搁下许宁的消息。 | 没有先与许宁完成正式分手、永久承诺或生育取消仪式。 |
| 新城数周后 | 陈许恢复联系；林遥看到行业行程后主动联系邵峥。 | 新城没有阻止行业人员出差，也没有实现绝对隔离。 |
| 两处晚餐当晚 | 孩子有熟悉的照护者陪伴；陈许吃饭；林邵重逢并留下。 | 不把孩子放入成年人的亲密场景，也不写成无人照料。 |
| 第一部末尾 | 陈许建立共同生活，陈林分开，部分事实仍未完全互相告知。 | 林邵的长期关系、任何新的怀孕、孩子的成长命运均未定。 |

## 仍可调整的电影语言

“前约三分之二到米切尔告别”是叙事结构意图，尚不是根据实际拍摄或剪辑测得的时长。小说式内心判断可在分镜阶段转为表演、画面或有限旁白，不要求角色把所有创作备注说出来。

陈林具体怎么分开，暂时不增加一整场审判、完整口供或所有秘密同时曝光。后续可选择观众比他们多知道多少、何时知道，以及分手场景的长度。本稿的第八场只负责给第一部一个可以阅读到结尾的落点。

## 第二部留白

保留创作原话的意思：先把第一部拍了，看看票房；第一个孩子那里，下一部再让观众难受。

目前仅保留“孩子的后续视角”这一入口，不预写悲剧、伤害方式、监护争夺、亲子对立或人物死亡。也不以续集彩蛋提前兑现这些事。孩子如何理解父母、与各个成年人维持什么关系，等第二部真正开始写时再决定。

“先拍、再看票房”是本项目的创作节奏，没有启动拍摄、上映安排或票房数据。
