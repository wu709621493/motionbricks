# 工程师两件套：修得了门轴，修不了常识

> **特别标注：本梗不能用于人体修理。Duct tape（布基胶带）和 WD-40 不是人体维修套装；Tide Pods 是洗衣凝珠，绝不能食用。**
>
> 本文是工程师冷幽默与互联网文化记录。“万能修理”是夸张，不是维修规范。下文剧场的人物、机构和对白均为虚构；真实事件另列来源。

创意与收录提议：吴孟城（Windy Wu）  
文本：AI 辅助创作  
整理日期：2026-11-08（北京时间）

## 一、工程学，被压缩成两个按钮

经典梗把世界上的故障分成两种：不该动的东西动了，用 duct tape；该动的东西不动，用 WD-40。连 WD-40 官方网站也收录过这个说法。[1]

完整的“梗版真值表”如下，**只解释笑话，不是操作指令**：

| 应该动吗？ | 实际动吗？ | 梗里的判定 |
| --- | --- | --- |
| 否 | 否 | 正常，别修出新问题 |
| 否 | 是 | Duct tape 登场 |
| 是 | 否 | WD-40 登场 |
| 是 | 是 | 正常，工程师可以去喝咖啡 |

它好笑在于：工程师学了材料、力学、控制与可靠性，最后在网友嘴里，毕业设计是一卷胶带和一罐喷剂。

真实工程可没这么省事。“动了”可能是正常运行，也可能是零件松脱；“不动”可能是卡死，也可能是制动器正在履行职责。先确认对象、故障和产品适用范围，才谈工具。刹车、承重结构、带电设备和人体，都不能被这张梗图自动派单。

## 二、万能维修部的一天（虚构短剧）

新人报到，师傅把一卷胶带、一罐 WD-40 放在桌上。

“这是初级工程师工具包。”

“高级的呢？”

“高级工程师知道什么时候把它们放回去。”

新人翻开《万能维修部手册》。第一页只有两行：

该动不动，WD-40。  
不该动乱动，duct tape。

“这么简单？”

“所以这一页负责招生。后面三百页负责让你毕业。”

上午九点，客户送来一个吱吱响的柜门。

新人刚伸手，师傅问：“材料、故障、说明书，看了吗？”

“不是万能的吗？”

“万能的是广告词。工单上签的是你的名字。”

上午十点，同事揉着膝盖经过。

新人低头看看工具包，又抬头看看师傅。

师傅直接合上箱盖。

“这里的关节，不归五金部。”

“人体也是机械系统的一部分吧？”

“你把人叫成系统，也不会自动给喷剂增加医疗适应证。”

师傅在手册封面加了一行大字：

**不能用于人体修理。膝盖不是门轴，皮肤不是胶带的万能安装面。**

中午，新人看到一段讲述 Tide Pod 挑战的视频。

“有人把洗衣凝珠吃了？”

“有过这种危险行为。”

“为什么？”

“我们这里修设备，不保证能给每一种决定找到合理需求。”

新人沉默片刻：“那第三件工具是什么？”

师傅指了指产品标签。

“阅读理解。”

下午，经理要求把维修成功率提高到百分之百。

新人提交了新版流程：

第一步，确认对象是什么。  
第二步，确认它本来应该做什么。  
第三步，确认眼前这个东西是不是工具，还是根本不该入口的洗衣用品。

经理不满意：“没有体现人工智能。”

新人在页脚补了一句：

**支持自动识别‘人体不是五金件’。**

经理终于点头。

师傅没点头。

“这条还需要人工复核。”

## 三、Tide Pod：人类经典，但不是人类食谱

这里有真实历史，不只是网友编段子。America’s Poison Centers 记录：2018 年初，青少年故意吞食洗衣凝珠、再将视频上传互联网的趋势，引起了毒物中心的关注。[2] 本文用大家熟悉的“Tide Pod 挑战”称呼这个网络事件；该机构的记录覆盖洗衣凝珠这一产品类别，不能一概当成 Tide 单一品牌的病例。

可以把它收进“人类经典迷惑行为档案”，但不能把所有洗衣凝珠暴露都算成主动挑战：幼儿误食等意外事件是另一回事；暴露报告也不等于全部确诊中毒，更不是互联网视频的总人数。[2] 这里讽刺的是把危险包装成娱乐的决定，不是拿意外受害者取乐。

危险也并非“味道不好”这么简单。毒物中心指出，洗衣凝珠可能造成严重呕吐、呼吸困难、食管损伤等后果。[3] **清洁衣服的用途，不会因为人也需要“清洁”，就自动变成口服用途。**

若给这段历史写一条展柜说明，可以是：

> 人类发明了洗衣机，把洗衣服交给机器；后来又有人跳过机器，把洗衣用品交给了消化系统。  
> 工程师看完，只在报告上写了四个字：接口用错。

这句话是本文的讽刺，不是对事件成因的研究结论。

## 四、这个梗留给 MotionBricks 的一句话

**先辨认对象，再讨论动作；先确认用途，再调用工具。**

模型里“能动”，不能直接证明真实设备“该动”或“安全”；语言里同样叫“关节”，也不意味着机器人维护方法可以迁移到人体。这是从笑话引出的设计提醒，不代表仓库已实现人体诊疗、设备维修或危险行为识别功能。

工程师的成熟，或许就是从“我有两件工具，可以修一切”，进步到：

**“我有两件工具，也知道这次一件都不该用。”**

## 安全注记与来源

- WD-40 官方明确否认其多用途产品能够治疗关节炎，并不建议将其用于医疗目的。[1] 不要把它用于关节疼痛、伤口或所谓“人体润滑”；普通布基胶带也不能按这个梗替代医用敷料或专业处置。
- 洗衣凝珠不是食品，不应为拍摄、模仿或“试一下”放入口中。若发生误食，应立即联系当地毒物咨询中心或医疗机构，不要自行催吐；出现呼吸困难、抽搐或无法唤醒等情况，应立即呼叫当地急救服务。[3][4]
- 来源用于核验梗的公开流传、真实事件与安全边界，不为虚构对白背书。本文未认定梗的最早作者，也未估计挑战的全球人数。
