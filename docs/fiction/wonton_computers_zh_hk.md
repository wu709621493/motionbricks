# 《雲吞電腦》

廣州冇落雨嗰晚，阿澄間房反而落咗一粒螺絲。兩個人聽住佢叮、叮、叮，跟住冇聲。阿澄趴低望床底，隔籬動畫公司做燈光嘅阿翹已經除咗拖鞋，成個人爬咗上佢張床。

「你張床褥斜嘅。」佢伸手入床架同牆中間，摸返粒螺絲出嚟，仲摸到三個一蚊銀。「嘩，你張床有找續。」

嗰年阿澄廿九，阿翹三十一。電腦城班老友叫佢「裝機屌絲」，叫佢「隔籬個美女」。兩個人都有真名，偏偏成層樓得收管理費個姨姨記得。

阿翹趕住交一條動畫，部舊機一算到魚缸嗰幕就熄。阿澄幫佢換火牛，佢自己改咗水面啲光。再撳開機，兩個人坐喺床沿，望住螢幕上面第一條金魚游過去。阿澄望條魚，阿翹望住佢。條魚游咗第二轉，阿澄已經望返阿翹。

「你想錫我就出聲啦。」阿翹話。

「我想。」佢答得快過部機著燈。

第一啖錫落鼻尖，第二啖兩個人終於夾啱。直到走廊個外賣員拍門，問咗三次「邊個叫兩碗細蓉」，先有人肯起身。

飯枱細，兩碗麵一放低就冇位。阿翹挾咗粒雲吞畀佢。阿澄好規矩咁將自己嗰粒挾返過去。

「做咩退貨？」

「我都想畀你食吖。」

阿翹諗咗一陣，覺得呢個人可以。食完佢坐上飯枱邊，勾住阿澄隻手，叫佢行近啲。兩個人又錫埋一齊。張摺枱咿呀一聲，阿澄即刻托住枱底。阿翹笑到伏喺佢膊頭：「聽日同我去買張實木嘅。」

夜深，阿翹入咗淋浴間，隔住門問：「一齊沖呀？」

阿澄行入去，迎面畀凍水淋到叫咗一聲。阿翹伸手撥返熱，將佢拉埋身。玻璃慢慢起霧。嗰夜兩個人相擁相愛，窗外天光嗰陣，部機已經算好成缸魚，床邊地下仲有一對拖鞋，左腳搭住右腳。

第二朝佢哋真係去買枱。後來搬屋、結婚、生女，張實木枱一路跟住。個女滿月嗰日，兩公婆圍住張枱包雲吞，阿澄每包一粒就爆餡。阿翹終於明白，同一雙手，可以準確插好底板上八支幼針，亦可以對一塊雲吞皮毫無辦法。

個女識行嗰年，兩個人喺海珠租咗間細舖，叫「雲吞電腦」。日頭阿澄替街坊砌機，夜晚阿翹接動畫散單。有次三個舊同事一齊趕片，問可唔可以淨租佢哋啲機算一晚。第一晚最貴嗰張顯卡空轉咗四個鐘，天光一睇，畫面入面隻金魚得對眼。原來客人漏傳貼圖。

阿澄對住兩隻浮喺水中嘅眼，唔知點開張單。阿翹笑完，免咗嗰晚錢，寫咗個上傳檢查，再畀客人先睇一格。慢慢客人識得自己交檔、睇樣、租機鐘。兩公婆喺機房租落第一個機櫃，舖頭繼續賣電腦，公司登記上多咗一項雲端運算服務。阿翹將第一張機鐘月結單釘喺枱底，隔籬就係當年張傢俬收據。

幾年後，個女帶同學上舖頭做功課。人哋問：「你屋企賣雲吞㗎？」

個女將枱上兩碗麵推開，揭起枱布，畀佢睇枱底嗰兩張已經發黃嘅紙。

「樓下賣雲吞，我哋賣電腦。呢張枱係我阿媽叫阿爸買嘅。點解要買，你問親佢哋，兩個都淨係識笑。」
