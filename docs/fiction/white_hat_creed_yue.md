# 《白客信条》

凌晨两点十三分，一只鸡向我申请法律援助。

我说：“我系黑客。”

鸡说：“咁啱啦，我试过揾律师。律师话，首先要证明只鸡系我。”

我们在游戏里蹲在油麻地街市后巷。它是只三黄鸡，左脚绑着红绳，说话时嘴不动，声音从屁股后面出来。它见我一直望，颇有尊严地转了半圈。

“收音嗰粒点摆错咗。十二年啦，冇人整。”

十二年来，全世界有九千万人玩过《不夜城》。玩家最爱从钟楼顶纵身一跃，落进街市的鸡笼，再从漫天鸡毛里拔刀。那段动作拿过七个奖。至于鸡为什么每次都恰好向两边让开，游戏公司说，这是自主群体智能。

“自主条命。”鸡说，“星期三晚我一个人睇六十四只，有时仲要兼埋条鱼。”

它叫罗碧珊，六十一岁，住深水埗。她说，当年应聘的是夜班街景演员，计时出粮。后来公司换了三次名，员工变成供应商，供应商变成“玩家社区贡献者”。旧员工后台还剩一个“离职”按钮，按下去，系统总让她先找人接更。

“我个女礼拜六结婚。婚宴七点，七点半要我返嚟做鸡。梁小姐，你可唔可以帮我走一次？”

“几时？”

“永久。”

我之所以进得去，是因为公司也请了我。礼拜六是《不夜城》十二周年，全网直播。公司给我的合同印着四个烫银字，**白客信条**。翻开第一页，写着“在授权范围内挑战系统的一切假设”。

我问制作人：“包唔包括你哋自己嘅假设？”

他顾着拣直播穿哪双波鞋，说：“随便。最紧要好睇。”

礼拜六晚七点零八分，制作人的刺客爬上钟楼。下面八百万观众等他跳。我站在鸡档门口，打开那份被大家当笑话看的初版游戏手册。十二年前，这个世界还有一条颇讲道理的规矩。街市收档之前，档主须清点家禽。少一只，门就关不上。

我问碧珊：“你怕唔怕佢哋听到你把声？”

耳机那头传来碗碟碰撞。有人喊，妈咪，影相啦。

她说：“等我除咗个鸡声滤镜先。上次我同外孙讲生日快乐，吓到佢成晚唔瞓。”

钟声一响，刺客跃下。

六十四只鸡齐整地向两旁散开。唯独绑红绳那只行到半路，掉头，啄开笼门，行出了街市。

制作人稳稳落地，起身，拔刀。身后的鸡档阿叔没讲那句用了十二年的“捉贼呀”。他弯下腰，数了一遍，又数一遍。然后他拿起街市广播的咪。

“收档差一只。边个带走咗？”

这是我改的唯一一句对白。原版只准档主问“边个偷咗”。我觉得“偷”字冤枉人。碧珊自己有脚。

全服等了四秒。

然后，罗碧珊用自己的声音回答：“冇人带。我自己走。仲有，我今晚嫁女，听日开始唔做喇。各位街坊，十二年，多谢关照。”

制作人还举着刀。直播导演切去海港，避开鸡档。偏偏今夜揸天星小轮的也是旧员工。他将船泊好，出来扶着栏杆说：“碧珊姐，新婚快乐。啊唔系，你个女新婚快乐。屌，直播添。”

全港九条渡轮一齐响笛。

接着轮到卖甘蔗汁的、补鞋的、在天桥底下拉了十一年同一首《月亮代表我的心》的。有人报了真名，有人只讲“礼拜三夜更阿莲”。也有人继续卖鱼。八百万观众里，一个玩刺客玩到世界排名第二的巴西仔把刀收起来，站在鸡档前，用刚学的广东话问：“阿叔，你又点称呼？”

鸡档阿叔张了两次嘴。他的对白库里没有这句。他背后那个人有。

“我姓何。”他说。

那晚最贵的一件虚拟装备，是刺客身上的限量白袍。制作人花了十七分钟，才发现直播画面里已经没有人望住他。

事后公司扣了我尾数。我拿合同去追，制作人问我：“你到底测到咩漏洞？”

“你哋请我扮坏人，查一个玩家可唔可以带走公司嘅财产。结果有件财产话自己要去饮。”

他瞪着我。财务倒是听明白了，低头把钱批了。

隔年我去碧珊家拜年。饭厅挂着她女儿结婚的大合照。她穿一件孔雀蓝旗袍，手里拿着半只乳鸽，笑到眼睛都不见。我问她，婚宴那么多张靓相，为什么偏偏放大这一张？

“因为影呢张嗰阵，我个电话响。平时电话一响，我就要返工。”她夹了只鸡髀给我，“嗰日我两只手都有油，费事听。”

门口茶几垫着我那本《白客信条》，烫银的“白”字被碧珊用黑色油性笔涂实了。旁边是她外孙的字，老师大概教过他要爱惜图书，歪歪斜斜写着“婆婆做乜改书名”。

下面是碧珊的回答。

**“因为白衫嗰个跳咗十二年，封面都应该轮到只鸡啦。”**
