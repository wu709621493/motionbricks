# 《扩编》两部电影与林遥外传

2026 年 11 月 24 日围读工作稿。先把两部电影各自拍到结尾，再把镜头交给林遥。米切尔在搬家那天和一家人告别；许宁腾出柜子，陈拓放进去一件换洗衣服。第二部用多年后的比赛和一段年轻时的旧录像，交代这家人走了多远。

| 阅读顺序 | 本次修订与围读位置 |
| --- | --- |
| [第一部《扩编之前》](../before_the_squad_zh.md) | 八场文学剧本。第一场试读角球图正反两面，第六至七场读两处晚餐，第八场留意林遥给箱子让出来的半步。 |
| [第二部《扩编之后》](../after_the_squad_zh.md) | 续集处理稿含关键分场。少年长子等一瓶水；成年后传出决胜的一球。第二次离婚结束正片，旧录像留到字幕之后。 |
| [第 2.5 部《呢位先生》](mister.md) | 粤语短片，独立回到决赛散场当晚。两人从一张合照讲到七人车，一直讲到升降机门又开。 |
| [林遥漫画第一话《后排》](back_row.md) | 六页分镜。开页在车行量后排，翻页进失球队的会议室。从阿朗的肩膀后面，再看一次正片的进球。 |
