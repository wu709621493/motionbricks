# 《林遥》第一话　后排

粤语漫画分镜工作稿 v0.1。开篇的车行发生在决赛之前，翻页后跳到决赛后的星期一。六页，阅读方向从左至右。阿朗是林遥队里的成年后卫。画面里的训练板与比赛录像一律沿同一进攻方向。

## 第一页　卷尺（四格）

1. 窄横格。法拉利展厅，镜头贴着副驾驶椅背。林遥伸手摸到扳手，把椅背翻前。Sales 的手还指着车头，词讲到一半，自己跟着她蹲下来。
2. 从后排往外看，两张脸一高一低。Sales 问：「林小姐，平时接几个小朋友？」林遥从包里拖出一把旧卷尺，带出来一颗棋子似的红磁石。她用鞋尖踩住它。
3. 手部近景。林遥：「帮我撳住。两块战术板，一部脚架。」Sales 把尺钩抵住窄口。她把板的尺寸写在自己手背，横着量一次，又斜着量一次。销售没抢着替她报数。
4. 页宽横格。卷尺回弹，她缩手，他仍按着尺钩。林遥低头拾起那颗红磁石：「几好。你有听人讲嘢。」她走出玻璃门，外头司机正把两块磨白了边的板靠在车旁。Sales 留在店里，低头看看按红了的拇指。

## 第二页　星期一（五格）

1. 翻页。同样大小的一块板推进会议室门框，边角磕出一声「笃」。林遥一个人抱两块。页角只标「决赛后　星期一」。
2. 远景。球员散坐。阿朗坐最前排，把伤后恢复用的冰袋捧在膝头。后排有人悄悄给自己的手机开静音。前墙停着失球的转播画面。
3. 林遥把赛前的板放左边，把空板放右边。她摸一摸手背，手背上当然早就没了尺寸。黑笔夹在耳上。
4. 阿朗：「林指，我嗰阵应该跟边个？」他问的时候望着左边板上自己的号码。那是一块可以随手挪走的蓝磁石。
5. 林遥拿起遥控器，又递给他。「你坐到你嗰个位先。」阿朗看看椅子，以为要站起来换座。她轻轻敲一下屏幕：「片入面嗰个。」后排有人笑。他也笑，攥遥控器的手松了。

## 第三页　停早三格（四格）

1. 电视转播视角。长子收球，弟弟已经跑进右侧。画出观众一眼能看见的传球通道。阿朗停在球出脚那格。
2. 林遥：「你几时决定跟队长？」他往回逐格按。一下，两下，三下。留下三声很小的「嗒」。
3. 换场边机，贴近后卫的肩高。同一个时刻，弟弟的躯干被另一位球员遮了，只露出一小截白袜。后排的队友侧了一下头，仿佛换个座位就能望到。
4. 阿朗：「呢度我听到有人嗌我个名。我望过去，佢已经起脚。」林遥站起来，拔掉左边板上预先画好的箭嘴。板上留着一条浅灰的墨痕。

## 第四页　谁喊的（五格）

1. 有人按了播放。小喇叭里，林遥自己的声音：「传啦。」阿朗顺着声音望她。
2. 林遥：「呢句系我。但你听到嗌你名嗰个呢？」她蹲下来，把喇叭的音量调高一点。整页最小的一格，无人开口。
3. 右后方有人举手，是门将。「系我。我喺你后面，见到跑嗰个。但系我嗌完你个名，就冇嗌佢喺边。」
4. 阿朗回头。门将坐在最后一排，中间隔着四个人。两人还想对话，前排一个高个子下意识把头低下去。阿朗第一次见到队友的整张脸。
5. 林遥把笔放低：「搬开啲凳。照当时企一次。阿朗，今次你去守门。」阿朗举起冰袋。她拿过来替他放椅上：「行住嚟就得。」

## 第五页　换个位（四格）

1. 俯视。椅子围边，留出一小块地。球员用折好的外套当门柱。林遥自己抱住战术板做挡住视野的那个人，板刚好遮住跑动者的腰。
2. 从门将位置看，阿朗能看见两个人。球一动，他喊：「右边呀！」前头两个队友同时向各自的右边扭头，差点撞到一起。
3. 一片笑声。门将搭住其中一个肩膀，把人扶稳。林遥也笑。阿朗伸手要再来一次：「畀我讲埋名先。」
4. 相同构图，这次他提前一步开声：「阿晋，守入面。阿朗，跟波。」连自己的名都喊出来，他才想起此刻是谁扮他。队友已经照着动了。林遥放低块板。板后露出一直被遮住的那双白波鞋。

## 第六页　散会（四格）

1. 球员抬椅归位。阿朗用蓝磁石压住赛前的图纸：「呢张可唔可以畀我？」林遥：「拎啦。下面帮我写低你嗰阵见到乜，听日借我影印。」
2. 空会议室，手机上的冠军合照终于下完原图。她把儿子的耳朵放大，又缩回去，把全队连同两边举相机的人一齐留下。她回：「收到。只手嗰个我估中咗。」
3. 走廊外。阿朗在纸背写完第一个字，抬头发现自己还拿着遥控器。隔着玻璃递回去。林遥两手都是战术板，只能用下巴指一指外套袋。
4. 大横格。阿朗把遥控器塞进她外套袋；它在里面误按了播放。两人走远，空房间传出门将细细声嗌「阿朗」。这次不用谁调高音量，读者已经认得把声。

**第一话完。**
