# 王室人物疾病史：亨廷顿病证据核查与人物描写

研究提问：吴孟城（Windy Wu）。资料核查、整理与文字：AI 辅助。
初检 2026-11-03，合并前复核 2026-11-05。适用于本次公开资料的有限范围，不是临床诊断或全球王室病例登记。

## 先说明核查结果

本次没有找到足以列入**已核实王室亨廷顿病（HD）患者**的公开个案证据，因此
[结构化记录](../data/ding_rao/royal_hd_review.json) 的 `confirmed_hd_patient_ids` 保持空列表。
这不证明历史上或所有王室中没有 HD，也不等于这些人的 HTT 检测阴性。

四位人物均因其疾病经历有可追溯的材料而入选。下表区分了史料记载的病程与后人提出的病因解释。
四人都未达到本次 HD 病例的纳入标准。表中的每个研究问题都可以在保留诊断不确定性的前提下探讨。

| 人物 | 病程或生活经历 | 病因证据 | 疾病史本身的研究价值 |
|---|---|---|---|
| 亨利八世（1491–1547） | 从狩猎、比武到腿部溃疡反复疼痛，晚年借助移动工具 [S3] | Kell 相关生育史与 McLeod 综合征是两个分别评估的回顾性假说 [S4, S5] | 追踪慢性疼痛如何改变日常行动与对辅助工具的需要。 |
| 乔治三世（1738–1820） | 反复发作，家人与医师记录了他的言语、身体不适和受约束的经历 [S6, S7] | 回顾性诊断有争议；对其书信的分析比较了不同时期的语言特征 [S7, S8] | 结合本人书信与照护者记录，研究发作和当时的治疗如何影响他的生活，并区分不同观察者的视角。 |

## 1. 亨利八世：身体活动能力变化，不能反推舞蹈症

他年轻时参加狩猎、比武等活动。到了晚年，反复的腿部溃疡和疼痛、明显增重限制了
他的行动；Historic Royal Palaces 还介绍了他使用名为 *tramme* 的辅助移动工具。
这幅有来源的人物轮廓，是从活跃到活动受限，而不是一段可重建的舞蹈样动作记录。[S3]

Whitley 与 Kramer 提出两项假说：Kell 血型不合可能解释部分妊娠结局，McLeod 综合征可能解释亨利中年后的变化。[S4]
Stride 与 Lopes Floro 认为部分生育史仍可与 Kell 假说相容，但并非典型过程。他们认为现有史料不足以支持对亨利的 McLeod 诊断。
两篇文章均未提供本人的分子检测结果。[S5]

McLeod 综合征可以出现运动、认知和精神表现，但其相关基因为 **XK**，不是 HD 的
**HTT**。即使一个历史人物的表现与 McLeod 相似，也不能把他列为 HD 患者。[S1, S2]
本版不把处决、宗教政策或婚姻选择编码为神经退行性疾病症状；政治行为需独立解释。

**对丁饶算法的意义：**“行动受限”应保留原因未定的状态标签。不能自动生成不自主
运动，也不能给亨利八世补写 CAG 重复数、舞蹈症评分或 HD 起病年龄。

## 2. 乔治三世：疾病发作、家庭处境与档案中的不确定性

宫殿策展资料记载了反复发作的疾病、长时间说话、身心痛苦及遭受约束治疗的经历。
这些记载有助于描绘一个在疾病、照护和君主身份之间失去自主空间的人；它们不构成
“不规则、不可预测的舞蹈样运动”的规范检查记录。[S6]

皇家档案介绍显示，医师来信记录了睡眠、饮食和行为，家属来信则提供关系与照护的
不同视角。该机构同时明确指出：资料可能缺失，症状还可能与当时的治疗有关，后世
诊断不能脱离这些局限。[S7]

2017 年研究分析了他不同阶段的书信，发现语言特征差异，并在躁狂解释下讨论结果。
这种研究没有检测 HTT，也不能把文本分类结果当作分子诊断。王室档案仍保留卟啉病
与双相障碍等解释的争论，不能简单换成另一种确定诊断。[S7, S8]

**对丁饶算法的意义：**言语增多、手杖使用、约束造成的活动减少，须分别记录为
言语/行为、功能状态和照护干预。馆方将需要手杖行走与疼痛联系起来。[S6]

## 3. 克里斯蒂安七世：行为记录与“谁实际作决定”

丹麦皇家收藏馆记述了他早年容易紧张、难以集中注意力的情形；也记载国王签署
文件，而 Struensee、后来的执政集团及王储在不同阶段掌握实权。人物描写应同时
看见疾病与制度：文件有他的签名，不等于所有政务判断都由他本人完成。[S9]

关于 Struensee 1772 年回忆文字的现代研究摘要，介绍了医生当时的错误病因观念，
以及后世精神分裂症、卟啉病等回顾性解释。这里引用它是为了记录解释史，不采纳
某个解释为确诊，更不把旧文中带有污名的词语用作当前诊断标签。[S10]

**对丁饶算法的意义：**“签署”“命令”“由他人代行”应保留主体与代理关系。
这些档案没有给出足以供本版使用的 HD 确诊证据、HTT 重复数或运动捕捉数据。

## 4. 阿列克谢：从婴儿期出血记录到凝血机制

阿列克谢是尼古拉二世之子、俄国皇位继承人。[S12] Rogaev 等人的研究回顾了其
婴儿期即出现严重出血的病史，并分析罗曼诺夫家族遗骸。研究者在阿列克谢的样本中检出半合子的 F9 变异，并在体外实验中观察到该变异导致异常剪接。两项证据共同支持严重血友病 B。[S11]

因此，对他的疾病描写应围绕出血和凝血问题。**F9 的结果不能改写成 HTT 的结果。**
本文没有找到可核实的个人舞蹈症记录，也不凭照片补造异常姿态或认知变化。

研究还报告其母亚历山德拉携带该 F9 变异。维多利亚女王处于文献讨论的家系链上，
但这项实验并未直接检测她本人的遗骸；不能把家系推断等同于本人检测。携带者身份
也不能改写成 HD 患者身份。[S11]

**对丁饶算法的意义：**“严重患病”“需要照护”“活动受限”都缺乏疾病特异性。
阿列克谢于 1918 年遇害，不应把他的死亡时间当作未经治疗的自然病程终点。[S11]

## 与亨廷顿病本身如何区分

HD 是与 HTT CAG 重复扩增有关的常染色体显性遗传病，可有运动、认知、精神表现；
个体间差异很大，不能要求人人按同一顺序出现所有症状。[S1]

| 证据 | 可以支持 | 本版禁止的跳步 |
|---|---|---|
| 历史文字记载情绪或行为改变 | 这项表现曾被某来源记录 | 直接诊断 HD |
| 文献记载动作异常 | 保留具体动作、观察者与时间 | 把所有抽搐、手抖或失衡都写成 chorea |
| 后世论文提出诊断 | 有人提出过该假说 | 升级成患者确诊 |
| 检测到另一基因的变异 | 对该疾病的对应证据 | 把 F9 或 XK 当作 HTT |
| 亲缘关系或王室身份 | 家系/社会角色信息 | 推断个人基因型、发病或无病 |
| 没有查到 HTT 结果 | 当前证据未知 | 填成阴性或 CAG=0 |

四个案例都是核查对象，不是健康对照，也不能拿来训练“HD vs 非 HD”分类器。
目前没有这些人的可用 UHDRS 分数、标准化步态、关节轨迹或统一病程序列；字段留空。

## Repository 中如何保存和继续使用

本 PR 是资料与结构化证据补充，没有更改模型或诊断代码。

- [royal_hd_review.json](../data/ding_rao/royal_hd_review.json)：四位主要人物、两位家系相关
  人物、逐项来源、阅读深度及当前纳入状态。`null` 明确表示未提供/未核实，不是阴性。
- [royal_huntington_search_log.md](royal_huntington_search_log.md)：中英文检索式、来源筛选、
  无关命中与检索局限。空的患者集是可复核的阶段性结果，不是全球“零病例”统计。
- 与 [丁饶算法](ding_rao.md) 共享“主体—行为—状态—出处—不确定性”的思路。
  现有 `ding_rao.py` 的来源类型为 `lyric/official_history/synthetic`，尚未提供病历
  和档案类型；本数据作为独立 sidecar，不把欧洲档案伪装成中国正史输入。

今后如找到明确公开的王室 HD 个案，应分别核查人物身份、临床诊断出处、是否有分子
证据、检测主体与时间，以及是否有后续修订。历史上缺乏基因检测的临床个案不能仅因
年代早而一概否定；但“疑似”仍须保持疑似。确认携带致病扩增而尚未发病的人，应与
有症状患者分列。不要为了填数据而推断在世王室成员的健康或后代遗传状态。

若未来制作视觉描绘：可以展示有授权的历史肖像或有标记的示意图；静态画像不能证明
动态舞蹈症，本次不生成这些真实人物“发作”的虚构影像。
