# 没有拍下的照片——读杜拉斯《情人》

> 我们有很多时刻并没有拍下照片，因为情况不允许拍照，拍照会毁掉整个场景，所以我们拿着几张另外时刻的照片，心里却会记得那个没有拍照的时刻
>
> ——吴孟城，读《情人》时谈到渡船上的照片

读到湄公河上的渡船，很容易以为杜拉斯手边就摆着一张照片。十五岁半的姑娘，男式毡帽，金色的鞋。我们几乎可以伸手指给别人看。可杜拉斯告诉读者，当时谁也没有按快门。吴孟城说的“另外时刻的照片”，让我想到这样一顿饭。

席间拍过一张菜单。快散席时，有人等桌上的笑声过去，才低声把刚才只说了一半的话讲完。你要是在这时候掏出手机，他大概会抬起头来问：“做咩影我啊？”那半句话也就收回去了。过几年，你翻到菜单，多看了一会儿。旁边的人凑过来，以为你还惦记那家的菜。最有意思的是，把菜单发回给当晚那个人，他也许记起另一件你早忘了的事。

这让我想到《恶心》和《情人》里的两段音乐。罗冈丹临走再听一遍那张爵士唱片，生出一点动笔写作的希望。《情人》里，船上的肖邦圆舞曲让姑娘想起留在岸上的男人。她哭了。杜拉斯写她这时才拿不准，自己当初会不会爱过他。眼泪来得比这个念头快了一步。读《情人》觉得暖，我想自己暖在这一步上。

《女客》里，弗朗索瓦丝和皮埃尔惯于说“我们”。等第三个人真的来了，这个亲昵的代词听起来便有点冷：两个人商量得再周全，也没法替另一个人决定她在这段关系里是什么滋味。《情人》也有一桌叫人心冷的饭。华人情人请客，姑娘的兄弟们埋头吃，连看都不看他。多年以后，叙述者记得，在家人面前，她自己也没有同他说话。那顶男帽她记得，这一笔她也肯留下。

昆德拉在《生命不可承受之轻》里写特蕾莎靠着托马斯的肩跳舞，又替读者细辨她的幸福和悲伤。杜拉斯把最后几行留给一通电话。隔了那么多年，她一下就听出他的声音。他说还爱她。小说停在那里。读者能知道他终于说了什么，至于她听见那句话时究竟想起哪一天，谁也不能替她填上。这是我读到的诚实。回头再看渡船，连一个很小的问题都值得留给他：她记得自己的帽子，他先记起的，又会是什么？

## 相片背面

吴孟城读罢补了一句：

> 杜拉斯连“船面发挥”这种烂梗都能忍住不写😏很克制了呢

好彩当年冇影相。否则张相传到你手上，背面一定多咗一行批注——「少女临场发挥，作者全程克制。勘误：临场应为船面。」
