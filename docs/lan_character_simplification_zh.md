# 中华文明是世界文明大花园中一朵璀璨的鸡扒

*——从初中政治老师的一声「奇葩」，谈「蘭」怎样写成了「兰」*

整句话里，最经不起老师口音的，其实是那个量词。既然是「一朵」，后面理应开花。偏偏耳朵抢先上了一块鸡扒，于是等了这么多年，这堂政治课还没忘。标题照你的课堂记忆写。能核到的九年级思政复习材料，用的是「中华文化」和「世界文化大花园」的说法，落脚确实是「璀璨的奇葩」。[^class]

那就从花园里挑一株兰。把「蘭花」和「兰花」并排写，后一个「花」好端端顶着草字头，前一个字却连草都不见了。更有意思的是，翻回1955年的汉字简化草案，**这五笔「兰」，当时竟是分给「藍」的。** 一年后正式方案出台，它才在字表里成了今天的兰花。要评这笔账，得看看当年桌上究竟有几种写法。[^study][^scheme]

## 一株「蘭」，原本给读者两条线索

许慎《说文解字》释「蘭」为「香艸也。从艸，闌聲」。上面的「艹」告诉你，往草木里猜。下面整个「闌」提示读音，至今「蘭」与「闌」在普通话里都读 *lán*。所以，看见门里仿佛养着一株幽兰，自然很有画意。可要认这个字，古人留给读者的线索其实更实用。认得草字头，再碰巧认识「闌」，即使头一回见「蘭」，也有机会把意思和读音各猜中一半。[^shuowen]

这里本来有一条很顺的简化路可走。既然「門」可以写成「门」，「闌」可以写成「阑」，那就让草字头照旧，下面写个「阑」。**这条路真有人走过。** 《宋元以来俗字谱》所收《目连记》里，就有上「艹」下「阑」的写法。按草字头三画计，原来的「蘭」二十画，这个俗写十五画，今天的「兰」只剩五画。前一种省下五画，读者还看得出它属于草木、跟「阑」同音。后一种又省十画，代价是头一回见它的人，单看那一点、一撇、三横，很难猜出原来是哪株花。[^study][^strokes]

## 这五笔，唱大鼓的人比字表用得早

晚清有两件材料，摆在一起尤其好看。大鼓书《新出白蛇借伞》的唱词抄本，把「玉蘭」写作「玉兰」。远在新疆伊犁惠远，一块官地界碑却把「正蓝旗」刻成了「正兰旗」。**同一个「兰」，在唱本里是一株花，在界碑上是一面蓝旗。** 唱词可以凭声音接下去，旗名也有当地人熟悉的语境。等到要替全国的小学生编同一张字表，编表人可就得回答，说书先生笔下这五笔，到底该给谁？[^study]

再追问这五笔最初是谁写出来的，证据就没那么整齐了。冯延缜、李文亮在《汉字汉语研究》的专文里比较过历代草书。「艹」连写会接近「䒑」，复杂的下部也可能被几道横笔带过。「蘭」和「藍」的快写都有通往这个轮廓的可能。晚清唱本和界碑能坐实当时的人已经这样写。至于今天的「兰」直接脱胎于哪位书家的哪一笔，现在还指认不了。[^study]

## 1955年给了「藍」，1956年为什么又给「蘭」？

1922年，钱玄同已经举过「蘭作兰」的例子。到了1955年，公开征求意见的草案却拟用「兰」简写「藍」。1956年正式方案选择了另一种分工。「蘭」写成「兰」，而「藍」随着「監」简化为「监」，写成「蓝」。看看旁边几个字，就能明白这次调整的好处。[^study][^scheme]

| 放在一起读 | 简化后，眼睛还能看见什么 |
| --- | --- |
| 藍、籃 → 蓝、篮 | 上面一个是草字头，一个是竹字头，下面仍共用「监」。蓝草和竹篮各有来处。 |
| 蘭、攔、欄、爛 → 兰、拦、栏、烂 | 五笔「兰」进了另外三个字，成了好认的声旁。「拦、栏」读 *lán*，「烂」读 *làn*。 |
| 闌、瀾 → 阑、澜 | 这一支仍看得见门框。「波澜」保留了「阑」，可见繁体里的「闌」要按具体字来认。 |

这些对照也说明了「兰」最有意思的得失。它自己丢了草字头，少了一条表义线索，却给「拦、栏、烂」提供了一个五笔就写完的声旁。一个刚学会写自己名字里那个「兰」的孩子，转头去认「栏杆」的「栏」，这五笔立刻又派上用场。[^scheme][^pairs]

## 广州人读一句，就知道简化该在哪里收笔

试读一句粤语，**「一籃藍色嘅蘭花。」**「籃」同「藍」都读 *laam4*，收尾要合唇。到了「蘭」却是 *laan4*，舌尖收住，嘴唇不用合上。普通话里三个字都读 *lán*，广州人念到最后那株花，嘴上还留着一道区别。[^cantonese][^pairs]

1977年的第二次汉字简化草案曾想再走一步，把「蓝、篮」也并进「兰」。照那条路走，「一篮蓝色的兰花」便成了「一兰兰色的兰花」。意思大致还能猜，可读者得停下来，把第一个「兰」还原成容器，第二个还原成颜色，第三个才轮到花。1986年，国务院正式废止了这份草案。**写字的人省下几笔，读字的人要多猜几次，到这句话里，双方的工夫都算得出来。**[^second]

所以我赞成今天这个「兰」，也觉得教它的时候，值得顺手在黑板上写一次「蘭」。让学生自己擦一遍就明白了。擦去繁体「門」的几笔，草木和读音都还在。再擦到只剩五笔，手上确实痛快了，眼睛也确实少了一点东西。至于该留多少，花店老板最有发言权。客人发来一句「帮我留一篮蓝花」，他可以回一句，「咩花都得，蓝色就得？」客人要是写「帮我留一篮兰花」，老板就知道，该问的是「要咩颜色？」😏

回头看，你那位政治老师也给文字学留了个好例子。耳朵听见「鸡扒」，幸好前头还有个「一朵」，把大家从茶餐厅领回了花园。
