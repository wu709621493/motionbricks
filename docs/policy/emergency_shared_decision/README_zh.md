## 核心原则

> 这是我们的医学建议和依据，这是目前的不确定性；请帮助我们理解患者本人会希望怎样，我们一起承担判断的过程。

医生还应说明：什么必须现在决定，为什么不能等，什么可以先稳定病情再讨论。

本资料包提出的是沟通与责任原则，不是抢救操作规程。它不改变患者自主权、合法代理权限、临床专业责任或当地紧急救治程序。没有真实患者资料，也未进行疗效、费用或心理结局测量。
