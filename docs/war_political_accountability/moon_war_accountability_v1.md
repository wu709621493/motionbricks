# 登月之后为何仍有中东战争

从罗马与十字军到文革责任及冷战军需政策的批判

历史评论与文学二创  2026年11月16日

“人类都能上月亮了怎么中东还在打？自己打自己的吧别嚯嚯全世界了！”

这句愤怒的质问，逼着我们衡量文明的两种能力。1969年，阿波罗11号已经把人送上月球；可把战争限制住、让普通人免于被牺牲，至今仍是一项艰难的政治任务。登月证明了知识、工程和组织能够抵达的高度，却无法自动让掌权者克制。我们能够精密计算航天器的轨道，也必须认真追问：谁有权把别人的生活变成战场？[12]

但“中东还在打”不能被解释为当地人从古至今天生好战。中东的漫长历史包含贸易、共处与文化创造，也反复受到域外帝国和远征军的介入。今天的战争须按各自起因解释，不能压缩成一场延续两千年的民族或宗教争斗。

公元70年，罗马军队攻陷耶路撒冷，第二圣殿被毁；罗马随后发行纪念征服犹太地的货币。这是一场帝国统治与反抗中的战争。征服者不仅摧毁城市，还把他人的失败铸成自己可以流通、可以展示的胜利。把这样的历史归结为“中东人又在自己打自己”，连罗马从哪里来都略去了。[13]

1095年，教皇乌尔班二世的号召推动第一次十字军东征；1099年，来自西欧的十字军攻占耶路撒冷，屠杀包括穆斯林和犹太人在内的居民。宗教承诺与土地、财富和统治欲望在远征中交织。一个事业被宣称神圣以后，城里具体的人仍然会流血；受害者的信仰更不能成为杀戮的豁免理由。[14][15]

到近代，1916年的赛克斯—皮科协定又显示，英法曾秘密商议奥斯曼帝国部分领地的势力范围；1917年的贝尔福宣言则显示，英国对巴勒斯坦的政治安排作出了影响深远的承诺。后来的冲突还有各自的发展与选择，不能全由两份文件解释；但文件足以说明，域外强权长期参与了这一地区的秩序塑造。它们没有资格只以无辜旁观者自居。[16][17]

因此，“别嚯嚯全世界”的要求，首先应当落到发动、资助和扩大战争的决策者身上。停止把当地人的土地当作战略筹码，停止把别人的伤亡包装成自己的声望和商机。让地区冲突降温，也包括让域外力量承担约束战争的责任。

同样的追问，也应当越过国界，指向美国对战后日本的政策。1945年接受日本投降之后，美国曾推动非军事化；朝鲜战争爆发后，日本又成为美军及联合国军的重要采购、修理和后勤基地。日本亚洲历史资料中心展示的档案，记载了纺织品、机械、金属制品采购，以及车辆修理和运输服务。这些构成了所谓“朝鲜特需”的具体内容。[6]

军需生产的政策转向也有美国自己的文件为证。1951年3月9日，美国国务院函件承认，一些日本军需工厂已经为朝鲜战场生产物资。6月22日的函件表示，对日本为驻日占领军及朝鲜战场生产包括作战装备在内的军用品，没有政治异议；但同函也承认，当时作战成品尚未形成显著生产。因此，不能把政策许可直接写成从战争第一天起就已大规模生产所有武器。[7][8]

到1952年3月3日的函件，美国官员已支持提前在日本下达面向其他友好国家的作战装备订单，并把加强日本工业动员基础列作目标。文件把限制如何放宽、订单如何安排，以及怎样避免当时的国际纠纷，都写得相当清楚。[9]

这为批判提供了坚实的落点：反军国主义的承诺，在冷战需求面前被重新划定了适用范围。对曾受日本侵略与殖民统治的亚洲人民而言，昨日被要求拆解的战争生产能力，转眼又能因供应新的战场而获得扶持，这种政策反转理应受到质问。日本部分产业的复苏由邻国的战争需求拉动，更让“经济恢复”几个字背负了沉重的伦理账目。

“从战争主理人变成军火贩子”，可以作为针对这种角色转换的尖锐概括：战争参与能够经由生产和采购合同延续。不过，这是一种政治修辞。它不能抹去战后日本政体的变化，也不能把日本普通民众统统写成军火商。更准确的批判是，美国为自己的战略需求重新动员日本的军需工业，削弱了对战争能力的约束；把这种做法称为对军国主义遗产的姑息，是本文据此提出的伦理判断。

国内的群众迫害与国际的战争供应，有各自的历史起因和责任主体。将它们放在同一篇文章里，是为了坚持同一条评判尺度：任何政府都应当说明，它如何处理受害者的生命，又允许哪些政治目标凌驾于生命之上。批判文革，不能在换了国旗以后，就宽免另一套权力对战争能力的利用。

把目光从国际战场转回国内，政治责任同样不能躲进宏大口号里。对于文革这场政治灾难，我们必须继续追问：红卫兵杀人的消息，有没有传达到周恩来那里，又是否经过所谓审核？

文革是一场必须明确否定的政治灾难。追问红卫兵杀人有没有传达到周恩来那里，是在追问权力怎样接收死亡的消息。但“报告”“知情”“批准”必须分开：截至本次核查，未找到证明红卫兵杀人须由周恩来逐案事先审核的材料，也未找到老舍受迫害事先经他批准的证据。与此同时，已有研究记载，致死暴力的消息曾上达毛泽东、周恩来。不能把未能证明逐案批准，写成高层全然不知情。

王友琴的研究转引江渭清回忆录，记述南京师范学院李敬仪、吴天石夫妇遇害后，江曾当面向毛、周报告。这是研究者援引回忆录的材料，尚须与原书及当时记录继续核对；它支持的是死亡消息上达，不能据此推定任何具体杀人命令。中共中央党史和文献研究院刊载的研究述评，也记载周恩来在1966年八九月反对打人、主张文斗，并通过联络机构接触红卫兵。[1][2]

这些材料使责任问题更加具体。周恩来的劝阻和保护工作应当如实记载；随后也必须追问，在政治动员压倒日常秩序的环境里，劝阻为何没有变成人人都能依靠的保护？对于掌握不同权力的领导者，应逐一查明其得到的信息、采取的措施和能够承担的职责。个人的善意不能替代约束暴力的制度，局部的救助也不能为整场灾难结账。

“有没有送总理审核”这个问法还照出了更深的病灶：一个普通人免遭殴打的权利，竟仿佛要靠消息能否抵达最高处来保障。人正在挨打，能够制止的人就应当制止；有人被杀，就应当留下证据并追究责任。生命安全倘若依赖熟人递条子、名人受关注和领导特批，数不清的无名者便被留在保护之外。

老舍的遭遇使这一点格外刺痛。1966年8月23日，他在北京孔庙和市文联遭到批斗、殴打与侮辱；通常记述为翌日投太平湖自尽。具体末日行踪仍有研究争议，但受迫害后死亡的基本脉络已有多方记述。这里无须虚构他的最后一句话，更不应把死亡写成作家完成尊严的必然方式。应受谴责的是把人逼入绝境的迫害。[3]

后来报道转述，北京市文联曾在证明函上使用“自绝于人民”的说法。按照这种措辞，一个遭受暴力的人，死后还要承担离弃人民的罪名。组织替人民发言，又把受害者排除出人民。这道语言手续，使施暴者有机会从追责现场退场，让死者继续接受审判。[3]

读到这里，再回头看虎妞。她强势、自私，对祥子有控制，也曾伤害小福子。老舍没有把她写成一个完美的受难者。可到了难产之夜，她只是一个急需救助的人。小说写到求神问卜、救治延误和无力承担医疗费用，最后是母婴死亡；下一章，祥子卖车料理丧事，赖以生活的根基随之丧失。[4][5]

虎妞的不讨喜，丝毫不能降低她获得救助的资格。文革的政治暴力恰恰破坏了这个底线：给人贴上一个足够恶劣的标签，旁观者便被鼓励先判断他配不配得到同情。老舍的文学要求读者看见人物复杂的处境；迫害者却企图用一个身份名称取消整个人。一个社会若只肯保护经过赞美的人，保护随时可以被撤回。

虎妞死于小说所写的贫困、迷信和救助困境，老舍死于现实中的政治迫害，两者有不同的因果。把他们并读，是为了追问一个贯穿文学与历史的问题：当一个具体的人已经需要帮助，社会为什么仍有那么多理由让他继续等？老舍在虎妞之死前写道：“愚蠢与残忍是这里的一些现象。”这要求读者继续寻找造成它们的条件。[4]

以下为借用动物庄园设定的原创二创。骆驼是新增角色；场景与对白均非奥威尔原文，也不是历史人物言行的记录。原著中的拳击手是马，本杰明是驴。[10]

庄园新来了一只骆驼，负责驮送文件。

左边的袋子装着伤亡报告，右边装着采购合同。走到风车下面，两边一样重。

一只母羊拦住它：“我家里有人被打死了，报告送进去了吗？”

“送进去了。”

“那门外为什么还在打？”

骆驼低头看了看收条。收条上只有收件日期。

这时，外贸猪来取另一袋文件。母羊认出了合同上的印章。

“那家铁铺，以前不是替旧主人造刀的吗？”

“现在替我们造。它已经接受和平了。”

“造什么？”

“刀。”

外贸猪把合同夹好，催骆驼去装下一车货。骆驼没有动。它想起拳击手留下的空马厩，又看了看母羊手里的收条。

有只小羊抬头看着月亮：“听说已经有人到过那里了。我们的医务室，什么时候能开门？”

它第一次问：“这些文件里，有没有一张，是来得及救谁的？”

骆驼提出的这个问题，应当留给所有掌权者。对于文革，毛泽东发动和领导这场运动的主要责任，不能被“群众失控”四个字遮蔽；对周恩来及其他领导人的具体作为，也应当依据材料分别追问。1981年历史决议已明确指出毛泽东对文革这一严重错误负有主要责任。今天继续研究，尤其需要把受害者的姓名、报送渠道、制止措施和责任处理放回记录中。[11]

老舍写过一个人怎样被生活压垮，后来自己遭受了政治暴力。虎妞的难产、祥子失去的车与太平湖畔的死亡，要求我们追问报告到了哪里，更要求普通人在报告抵达最高领导人的书桌以前，就已经受到保护。

从罗马的征服纪念币，到十字军的神圣许诺，再到现代的政治运动与军需合同，历史中的人不断被写进别人主持的事业。抵抗这种安排，需要具体的约束：保护平民，追究暴力责任，让援助服务于生存，让政治谈判拥有结束战争的权力。判断文明，除了看它把人送到了多远，还应当看它能让多少人安稳地留在自己的家。

战争的账，不能只记夺取了多少阵地、摧毁了多少目标。还要记下谁再也没有回家，谁余生都要带着伤，谁在一纸捷报之后失去了原本可以继续的生活。掌权者应当说明，这些代价究竟保护了什么，又有哪些本来可以避免。

人类都能上月亮了。我们有理由要求，地上的权力学会珍惜人。

珍宝岛战役没找到珍宝。歼灭战又歼灭了什么？
