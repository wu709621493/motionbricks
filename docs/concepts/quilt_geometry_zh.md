# 卷被流高手偶遇抱被流贤者

两个人睡得都很好，床单独露了半宿。

卷被流高手靠翻身收被，每翻一次，身上就多绕半圈。抱被流贤者就一个习惯，睡前要把被角搂进怀里，一只膝盖搭上去，舒服了就再也不动。

凌晨两点，高手向外一翻。按往日经验，这一下被子就该跟过来。今晚只过来三寸。他闭着眼摸了摸，发现被子那头还挺沉，于是使出了练了二十年的补招——**自己往被子里钻。**

贤者睡梦中觉得，咦，今晚个被角点解暖咗咁多。顺手搂紧。

第二天朝早，两个人挤在床沿一尺宽的地方，背后空出大半张床。

「老婆，你昨晚系咪一路揽住我？」  
「我记得我揽住张被咋喎。」  
「咁我点解喺你怀里？」  
「你自己谂下，你平时卷到最后，最里面嗰层系咩？」

高手沉思良久。**原来卷被流练到最高境界，自己就系个被芯。**

## 尾声

> 其结构之精妙，文案之精简堪比非欧几何🤔

欧几里得漏咗一条公设😏

**两个人平行瞓低，只要共用一张被，天光就可能相交。**

成段我最钟意嗰三个字系「三寸」。被角再过来三寸，高手就卷赢咗，故事到此为止。偏偏张被只肯行到呢度，剩低嗰段距离，唯有个人自己行埋去。

贤者由头到尾都冇郁过。佢条平行线，自己送上门。😌
