# 《繁花》粤语演员读本｜一张台，两个冇到场嘅人

> 声明：含有戏剧性理解。

## 爷叔同金花点样散场

爷叔去外滩二十七号谈牛仔裤订单，等咗一下午。金花叫佢投标。读到呢度，可以试下收场：金科长办完一件公事，下一位可以入嚟。再读一次，留返金花讲诚信、爷叔回「没大没小」嗰一下。第一转已经讲完嘅生意，点解第二转仲有戏？

试畀金花一个念头：换作第二个客，我会唔会讲多呢句？再畀爷叔一个念头：如果我真系净系嚟谈生意，有咩资格话人「没大没小」？「你办事其实没有做到公私分明」可以系爷叔听出嚟嘅弦外之音。轮到佢开口，佢自己都用返长辈把声。排到呢度，畀观众自己拣，究竟边个先将私情带入间房。

话爷叔为宝总呢个「养子」、金花为小汪呢个「养女」操碎心，个「养」字系读戏人畀嘅。爷叔肯坐冷板凳；金花肯畀小汪一本可以换本钱嘅集邮册。本册当初又系爷叔畀金花嘅。演金花嗰个可以记住，自己都试过系收礼物嗰个后生。至于「没大没小」要几嬲，留到对手讲完先决定。

## 一条底裤点样读出两段感情

> 阿宝为左小汪先蚀到底裤穿窿😏跟住为左李李直接从底裤厂家降到韭菜级消费者咯

先畀大家笑完。再问演阿宝嗰个，两个「蚀」字有咩分别。为小汪蚀，你仲识揾厂、识计布，心里可以答到「呢笔我肯出」。去到李李，个价牌已经唔喺你手上，你几时先肯起身离场？「底裤厂家」个笑话要留，佢讲得出阿宝失去咗几多话事权。

## 李李问出口，雪芝留喺心入面

> 从果句“认识A先生吗？”😏就注定两人解不开辣

> 偏偏阿宝心入边😏仲藏住个逝去左噶雪芝

照呢个读法，A先生系枚硬币沉落去嗰一面。李李见过一个人失势之后，生意场仲剩低乜，佢先会令我哋问当年值钱嘅究竟系边一份真情。雪芝认识嘅阿宝早过「宝总」这个称呼。满场人都肯叫佢宝总，唯独佢曾经想畀边个亲眼睇一睇，嗰个人已经唔喺度。

排练时，畀李李嘅任务好具体：要知道对面呢个人认唔认识A先生。畀阿宝嘅默念可以系「你又认唔认识雪芝？」呢句系排练新写嘅心声，全场留喺演员心里。两个人各自有挂住嘅人，唔等于佢哋已经互相知底。若果一开本就写低 *trauma bonding*，演员好容易预先演出一种亲密，反而冇咗头一次听见人哋开口嗰阵嘅好奇。

## 打本｜同一句，做两转

两张凳，一枚硬币。硬币系今次排练加嘅道具。李李讲「认识A先生吗？」两转都只讲呢五个字同一个字母。阿宝每转都有一次接话嘅机会。

1. **第一转，交代一单生意。** 李李放枚硬币喺台面，眼望阿宝，等一个答案。阿宝照自己对人物嘅理解即答。读到双方都觉得呢次问答结束，就停。
2. **第二转，畀阿宝一个秘密。** 开始前，导演只同演阿宝嗰个讲「雪芝」。李李照上一转问，阿宝可以等一等，亦可以照答。几时觉得对方已经听明，李李就收返枚硬币。阿宝一旦想追问，畀佢自己决定讲唔讲得出口。
3. **落本之后分开问。** 问李李「你几时想伸手收返枚银仔？」问阿宝「佢伸手嗰阵，你原本想讲边个字？」最后问旁观者「你喺边个动作开始，觉得佢哋讲紧一单生意以外嘅事？」如果旁观者只见到两个人望住枚银仔，就抽走道具再做一次。

呢度讲嘅「莎士比亚大智慧」，可以攞《哈姆雷特》第三幕第二场做个读本参照。戏中戏演到落毒，哈姆雷特等紧睇国王点反应；国王一起身要光，原先坐定定睇戏嘅人成咗全场俾人睇嗰个。演员逐个演自己眼前要做嘅事，观众就有机会同时睇见两出戏。返到《繁花》，畀李李认认真真问佢嗰个问题，畀阿宝保住自己嗰个名字。最难演嘅亲近，可能就系听人讲完，忍得住冇补一句「我都系」。
