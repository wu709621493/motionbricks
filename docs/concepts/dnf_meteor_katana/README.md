# 我同美女师傅结婚前那些事儿

DNF 六十年代，赫顿玛尔。夜晚十一点半，剑魂师傅发咗条私聊过嚟。

「瞎仔，月光酒馆门口等我。装备栏留一格。」

徒弟清咗三格。跟师傅咁耐，照经验，一格系正经嘢，另外两格多半系师傅唔舍得掉、又嫌摆仓库阻埞嘅垃圾。

点知今次，交易栏入面净系摆咗一把太刀。

师傅企喺索西雅门口，身上一阵粉光，打出嗰句明显喺肚里面练过好多次嘅对白。

「我决定要靠我噶+15泰拉石光剑和+13无影剑去驰骋pk场辣 哩把+11流星落比你拿去玩辣」

徒弟望住个交易栏，半日冇㩒确定。

「师傅，你上个礼拜先话，边个敢问你借流星落，你就将边个踢出师门。」

「所以我宜家送。你有冇问我借啊？」

「冇。」

「咁咪冇犯门规啰。㩒啦，师傅只手攰啊。」

徒弟一㩒，嗰把见咗成年、一直挂喺人哋腰间嘅长刀，就落到自己手上。佢装备起身，行前两步，又行后两步。把刀真系长，企喺酒馆门口，刀尖几乎够得着索西雅张枱。

师傅问：「睇够未？」

「未。」

「咁入场慢慢睇。房名叫『师徒切磋』，密码四条一。」

第一铺，师傅拎泰拉石光剑。倒数一完，瞎仔仲喺度欣赏自己个拔刀姿势，已经畀人一记上挑送咗上天。落地嗰阵，条血得返一截。

第二铺，师傅换无影。瞎仔今次识走位，不过望住师傅只手净系得个剑柄，始终估唔到几时斩埋身，又输。

第三铺打到大家都剩少少血。师傅退咗半步，喺公屏打字。

「头先教你嗰样，记唔记得？」

瞎仔冇答。一刀扫过去。师傅以为自己已经退开，啱啱好畀刀尖掂中。偏偏就系嗰一下，天花板跌咗粒陨石落嚟。

画面定住。师傅瞓低。个房静晒。

过咗一阵，公屏弹出师傅一句。

「……我以前用咗成年，想佢落嗰阵，佢一次都冇咁准时过。」

徒弟笑到差啲踢甩拖鞋。「师傅，头先你想教我乜？」

「想教你，PK嗰阵咪挂住打字。」

「我冇打喔。」

「所以你赢咗啰，衰仔。」

嗰晚两个人打到成间网吧净返收银阿姐同佢哋。临落机，徒弟终于问：「师傅，点解真系舍得比我啊？」

师傅除低耳机，探个头过隔离部机，指住徒弟个画面。

「你以前用短剑，我一退半步，你就追。追咗成年，次次都食我上挑。今晚最后嗰刀，你企定定就斩到我。」

佢伸手，帮徒弟将张胜利截图存好。

「把刀长咗，你终于肯少行一步。咁咪啱你使啰。」

第二晚，师傅果然开咗个公开房，房名叫 **「+15泰拉光／+13无影，欢迎高手」**。

瞎仔一入房，发现琴晚两点几仲话要驰骋 PK 场嗰个师傅，已经喺房间公告加多咗一行细字。

「瞎仔，阵间打完咪走。把刀借师傅玩返两铺。」

徒弟：「师傅，你寻晚话，边个敢问你借流星落，就踢出师门㗎喔。」

师傅：「系啊。宜家我问你借。你收过我做徒弟咩？」

徒弟：「叫声师傅，借你两铺。」

隔离部机静咗好耐。

「……师傅，开房啦。」
