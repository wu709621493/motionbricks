# 四个廿蚊，一枝玫瑰

「数数问题搞掂，要整啲法国人嘅浪漫。」——吴孟城

## 数学堂上，两份满分答案

巴黎花档开价 *quatre-vingts euros*。阿晴译「八十欧元」，阿城译「四个廿蚊」。对白前文已经交代币种。请写出两种讲法各自嘅算式，解释两个人点解听到同一个价；如果观众要听得出法国人点数，你会拣边句？

数学占两分。能写出或讲清楚八个十同四个廿各得一分，摆硬币、画图同列式都接受。翻译占一分，按场景讲得出理由就得：「八十」方便读者即时认价，「四个廿」保留数词节奏。法国常用数词保存咗中世纪逐廿计数嘅痕迹；写成 80 时，用嘅仍然系十进位。[法兰西学术院](https://www.dictionnaire-academie.fr/article/QDL078)

## 畀每张凳一道真题

| 传统同证据 | 学生落手做 | 答案要交代嘅事 |
|---|---|---|
| 基什书吏嘅六十进制平方表 | 用 24.5² 验算表中「10、空位、15」。 | 10×60＋0＋15/60＝600.25。中间个位有占位记号，据此可以判读该行；独立数零嘅一般运算法则仲需要其他证据。 |
| 玛雅《德累斯顿抄本》金星表 | 表内一个金星周期取 584 日，几多个周期首先对齐整数个 365 日历年？ | 584 同 365 嘅最大公因数系 73，所以 5 个表算周期＝8 个历年＝2,920 日。等式精确，天文周期用咗近似值。 |
| 阿拉斯加 Kaktovik 学生嘅数字 | 按五个一组拆开 19 同 12，再试 15 减 9。 | 第一题剩一组五、两个一。第二题要将一组五拆开，15＝两组五加五个一，减去一组五同四个一，得 6。传统 Iñupiaq 数词启发咗学生喺 1994 年创制新字形。 |

泥板有馆藏编号 1924.796+，平方表释文见第 28 件。金星表同 Kaktovik 编码提案都留低可以逐项复算嘅记录。[泥板释读](https://sciamvs.org/files/SCIAMVS_05_003-065_Robson.pdf) · [玛雅金星表研究](https://revistas-filologicas.unam.mx/estudios-cultura-maya/index.php/ecm/article/view/1005/1634) · [Kaktovik 数字提案及学生算法](https://www.unicode.org/L2/L2021/21058r-kaktovik-numerals.pdf)

「四大文明古国」答唔到一页数学教材点分篇幅。墨西哥一项初中教材研究更实际：作者区分某位人物有冇带出数学活动，抑或只作装饰。研究嘅初一样本中，泰勒斯出现九次，「巴比伦人」作为集体出现三次。数字量度教材呈现；要解释编者动机，需要另外取证。评审一本书时，我哋会问：学生最后识用边个嘅方法？署名写到几仔细？用另一种有效方法解同一道题，可唔可以攞同分？[教材研究，表 2 及编码方法](https://doi.org/10.29333/ejmste/106056)

## 收档前，巴黎

雨停咗。花档个遮仲滴紧水。佢拣好一束玫瑰，问几钱。

「*Quatre-vingts.*」

佢数咗四张廿欧元。花档个姑娘认得佢。三个月前，佢第一次帮衬，听到呢个价仲要拎部电话出嚟㩒。

「你法文学快咗喎。」

「练过。仲有一句练咗成个礼拜。」

佢请姑娘拆开花束，抽一枝出来。姑娘另外裁咗张纸，包得好仔细，问两份分别送去边。

「大束嗰份送畀我阿妈。细嗰份……」佢将嗰枝花推返过柜面。「*Celle-ci est pour vous.*」

姑娘手上仲攞住支铅笔。佢扯出一截包花纸，写咗个电话号码，下面加多一句：*Après sept heures.*

今次佢听明。七点后。佢望一望对面间咖啡店。

「我等你收档，好唔好？」

姑娘将枝玫瑰插入自己饮水嗰只玻璃杯。「七点就得。张遮留畀听朝先收。」🌹
