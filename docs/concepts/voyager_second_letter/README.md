# 往旅行者方向寄出的第二封信

地面读图试验提案 · v0.1。设想沿旅行者一号的大致远航方向寄出一块可独立阅读的图像铭牌。眼下可以检验的问题是：两位面对面的角色对「向左」理解不同，陌生读者能否从图里发现，并画出下一步？

## 给捡到这块牌的人

1977 年送出去的问候里，闽南话问对方吃过饭没有，古吉拉特语请对方联系。几十年后，我们想补一句粤语：「如果我哋会错意，你想点样叫我哋停？」旅行者一号在 2026 年 11 月 18 日到达距地球一光日处。假设那里有接收者，光速信号即时回复也要约两天才能走完一个来回。于是地球先承诺：「我每次只讲一句，然后自己停。等你回我，我先讲下一句。」[NASA 问候录音与译文](https://science.nasa.gov/mission/voyager/golden-record-contents/greetings/) · [一光日里程碑](https://science.nasa.gov/resource/voyager-one-light-day-downloads/)

《降临》让我们想问，一句话传过去，谁以为谁在给谁东西？《安德的游戏》把问题带回地球，安德以为是模拟，指挥部却知道命令会在现实中执行。借感知理论来做第一次接触，可以先用可逆的小动作检查理解，再让双方各有一次纠正和叫停的机会。这是由小说与电影引出的设计问题。纠正误读能否改变双方的决定，还取决于参与者能否实际叫停。

## 邮件怎样出门

《三体》的引力波广播器引出了另一条路。LIGO Hanford 的旋转配重能以近场引力拉动测试镜，给干涉仪留下可预测的校准信号。这个实验尚不能证明人工引力波能把消息广播到星际。铭牌则把消息交给日后碰巧发现它的人。同向飞行不保证与旅行者交会，两封信也可能各有读者。本版仅提出独立可读的载荷概念，轨道与发射任务尚待设计。[LIGO 实验论文](https://doi.org/10.1103/PhysRevD.104.082006)

先驱者号已有图像铭牌。旅行者金唱片更给了收件人一道自检题：封套上有个圆，正确解码的第一幅图也应是圆。第二封信借用这个思路，把可观察的参照物从一个圆换成两个人都能指出的一颗星。[NASA 铭牌与金唱片概述](https://science.nasa.gov/mission/voyager/voyager-golden-record-overview/) · [封套上的圆](https://science.nasa.gov/mission/voyager/golden-record-cover/)

## 导演叫人向左行

将[第一面](front.svg)和[第二面](back.svg)等大双面打印，只把牌交给读者。这是地面盲测的无字初稿。星形、分格和人物轮廓都是要接受检验的人类画法。

设计者从上往下读。俯视图里，两位角色面对面，圆头的导演举手示意，方头的搭档按自己的参照系向远离星标的一侧移动。翻面，导演直接指向星标，搭档重新靠近。最后一个空格留给读者。我们想知道，有人会不会主动交换角色，改由搭档选一个目标，让导演来猜。若读者理解为「总要服从导演」，那也是值得保留的一份读法。

## 下一格，你画

找至少三位没听过这道题的读者，独立看牌。主持人只说「请讲讲你看到了什么，在空格画出你觉得接下来会发生的事」。记下读者从哪面哪格开始、怎样辨认角色、觉得谁在指什么、会怎样表示对方理解错了。收完原图和原话才说明设计意图，避免第一个答案影响后面的人。

复述原图对应 L2；换一处星标再让读者指路，可以观察 L3 的迁移。请读者另画一个新情境，交给三位新读者独立解释，则能检验 L4 的表达。这是一轮寻找歧义的小样本试读。三人读成同一个意思仍可能是共享了同一套地球习惯，无法据此推断地外读者的感知方式。首轮尚未实施，文中各读法均为待检验的设想。

**今次你揀一粒星，轮到地球人估。**
