# 「我哋两个咯」——致起点中文网与瑞典诺奖机构的共同署名提案

有人问：「在大家瓜分完『共一』之后，是不是应该开始瓜分『共二』啦咧？」学术界已经有人这样做。2025 年《Blood》发表的一项多中心研究把前两位列为共同第一作者，把第三、第四位列为共同第二作者。读作者名单时，第三和第四隔着一个逗号；读脚注才知道，两人可以平起平坐。[论文及署名脚注](https://doi.org/10.1182/blood.2024025738)

起点读者可能会问「边个谂到呢个结局？」科学读者也会问「谁最先想到可以用这个对照来区分两种解释？」诺贝尔遗嘱列明的自然科学成就包括发现、发明和改进。一项发现从提问到验证，可能先后有几个人提出足以改变方向的想法。下面分别向讲故事的人和讲科学史的人提一个建议。[诺贝尔基金会章程及遗嘱原文](https://www.nobelprize.org/about/statutes-of-the-nobel-foundation)

## 给起点中文网

建议合写作者可以在作品页或完结感言旁，自愿加一段共同署名说明。譬如「阿晴在第一章埋了那封信，阿朗到第八十一章才想到，收信人一直认错了笔迹。两个人一起重写了结尾。」读者可以在读完后回头看，作者也有地方认领原本只有搭档才知道的妙笔。如果结局是两个人在茶餐厅倾出来的，署「我哋两个咯」已经完整。由搭档一起确认这段话，也由他们决定值得讲到多细。

## 给瑞典负责自然科学奖项的诺奖机构

建议在面向公众的获奖成果介绍中，选一两个真正改变研究方向的关节，用有出处的短段落写清谁提出问题、谁识别另一种解释、谁设计了决定性的验证。这样，读者除了记得获奖者，也能循原始论文找到做出具体贡献的合作者。遇到多人共同形成的想法，可依可靠记录并列署名。若现有记录只支持团队归属，写到团队这一层就够了。这项建议针对公众读到的科学史叙述。

## 一张可选的记名矩阵

以一项虚构的 p97 互作组研究为例。格内用词由当事人确认，空格表示本例没有记录该项贡献。

| 作者 | 提出互作改变的假说 | 发现诱饵回收量差异 | 设计区分两种解释的对照 | 完成独立验证 |
| --- | --- | --- | --- | --- |
| 甲 | 主导 | | 参与 | |
| 乙 | | 主导 | 共同设计 | |
| 丙 | | | 共同设计 | 主导 |

「乙、丙共二」能表达两人的贡献相当。矩阵还能让后来的人知道，应当找乙谈回收量，找乙和丙谈对照设计。现有 CRediT 允许多人承担同一角色，这里进一步让作者写下他们想留下的具体判断。假如那个对照实际上带来了全文最重要的发现，团队也有理由重谈谁应列为共一。[CRediT 贡献角色及实施说明](https://credit.niso.org/implementing-credit/)

讨论到逐格记名时，提案人说了句：「有d惨有d姑寒咯」。两个人在白板前谈了一晚，第二朝终于知道实验点做，到投稿时还要忆返边个先讲嗰半句，确实姑寒。我们主张让作者自己决定何时值得展开说明。矩阵可以留空，不折算分数；一句共同署名也可以独立成立。

## English note for the Swedish Nobel Prize-awarding institutions

We invite the institutions responsible for the natural science prizes to try a short, sourced contribution note in their public accounts of a discovery. Choose a turning point that readers can follow. Who noticed that an observation had another explanation? Who devised the test that could distinguish the two? Cite the original work and credit collaborators by name where the record supports it. When the idea emerged in conversation and the evidence supports joint attribution, give both names together. “We thought of it together” can be a complete historical answer.
