# 如果我是共和国的总理，我会如何游兰州？
## 第二集《桂姨，给您寄一分钟的甘南》

外景设在甘南州碌曲县尕海湖，故事发生在夏天。全片约六分钟。

### 第一场｜出兰州，车内

车刚开，桂姨发来一条语音。

桂姨　照片收到了。你们去高原，替我录一分钟，我想听听那儿什么动静。

我按住语音键。

我　桂姨，这次我们将从兰州出发，前往甘南藏族自——

小满把我的手指从屏幕上抬起来。四秒钟，已经发出去了。

桂姨秒回　孟城，你什么动静我昨天听过了。

### 第二场｜尕海湖，午后

第一眼只给草。一阵风从画面左边过去，草尖翻出浅色的背面。镜头等它走远，才慢慢抬起来。后面还有草，再后面是一线水。云影过湖，近处亮，远处暗，同一片水看起来像是分了深浅。

小满站在开放栈道上举起录音机。红灯亮了十一秒。嘎吱。她低头看自己的鞋。再来，十七秒。嘎吱。全组低头看鞋。

收音师把耳机扣到我头上。左耳是风，右耳有人隔一会儿就捏一下塑料袋。我循声望过去，一直望到自己手里。出门前买的半张饼，我一路舍不得吃，这会儿让全国人民都听见了。

我　停机两分钟。总理得销毁一点证据。

我们把饼分了。吃着吃着，湖上的亮处已经挪到了另一边。摄影师的手下意识去摇镜头，又停住。让那一点亮自己出去。

### 第三场｜湖边，一分钟

导演问我，还等不等一群鸟飞起来。他的分镜本上画了七只，连队形都有。

我　你这张图，鸟看过没有？

他把本子合上。小满第三次按下录音键。这回就用一个固定广角，从红灯亮起到熄灭，足足六十秒。风吹草，水面起皱。有人扶了一下栏杆。鸟若飞过，就让它飞出画框。这一分钟里发生多少，观众就看多少。

回放时，小满听见中间还有一声很轻的“哎哟”。是她蹲久了，站起来膝盖响。她想再录一遍，我的手机已经显示“发送成功”。

### 片尾｜回程，天色还亮

桂姨打来电话。

桂姨　后面那个“哎哟”是小满吧？

小满　妈，给你听那么大一个湖，你就听见我膝盖了？

桂姨　我又没去过，我哪认得湖的声音。你这一声我认得。

过了一会儿，她又问，水是什么颜色的。

我正要答“蓝的”，小满把手机转向车窗。云开了一条缝，刚才还灰着的水面亮了一下。桂姨在电话那头轻轻“哦”了一声。小满就这么举着手机，一直到公路转弯。
