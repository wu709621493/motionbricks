> 从法律意义上讲，先打跛你个认知能力只脚，然后再趁机诋毁你噶成就，偷过黎自己用，然后再做烂你成个招牌一脚踢飞你，这个连招法律上完全行得通，但系真系一d人性一d学术常识一d底线都冇啊
