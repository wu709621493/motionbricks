# 富爸爸、富妈妈，想传啲乜畀下一代？

一位单亲老豆，家底丰厚，穷带个仔；一位单亲阿妈，同样有钱，用同一笔低月数养女。边个难啲？净睇月底本账，答唔到。个仔可能知道阿爸有钱，父子倾好悭边笔、使边笔。个女亦可能以为阿妈真系冇钱，连想去毕业旅行都冇开过口。两个细路调转，一样讲得通。想知边个辛苦，要问埋个细路：有几多次，你以为屋企负担唔起，连问都冇问？

新马师曾个仔邓兆尊讲过，自己读书时打暑期工赚零用，廿几岁前都唔知自己有钱。呢段回忆讲到个仔当时知道几多；父母究竟点同佢讲家境，报道冇交代。研究上亦有人问过细路点睇「买唔起」：中国中部五间中学共971名学生嘅问卷显示，记得父母讲过越多种金钱谎言嘅学生，自报焦虑亦越高。一次问卷仲判唔到因果，更加判唔到父子、母女边家难带。[邓兆尊访问报道](https://www.hk01.com/article/60362992)；[学生问卷研究](https://doi.org/10.3389/fpsyg.2022.1021355)

等佢哋成年，同一笔月数之外，仲有两把尺。个仔带个搵得少过自己嘅女朋友返屋企，讲句「我哋计过，够生活」，老豆可能觉得佢有担当。个女带男朋友返嚟，逐字讲同一句，阿妈可能问：「如果有一日你要停工，边个顶你嗰份？」呢个担心值得两个人坐低计，亦值得对个仔照问一次。昆明有研究畀替仔女相睇嘅家长同亲属拣随机生成嘅对象资料，收入同物业会影响佢哋点拣女婿，拣新抱就冇见到同样效应。[昆明相亲研究](https://cepr.org/publications/dp16035)

中国发展得快，人口同家教嘅压力又叠埋一齐。2020年人口普查，20至40岁男性比女性多1,752万人。即使同龄人数啱啱一比一，想结婚、想有人陪、想发生性关系，仍然要两个人自己讲得拢。一个后生仔可以未有条件成家但想亲近人，一个后生女亦可以经济独立、钟意一个人，同时冇打算嫁。两个人愿意做炮友，讲得清楚期望，守得住私隐，一方想停，另一方尊重，呢度一样睇得到人品。[国家统计局就七普年龄数据嘅说明](https://finance.people.com.cn/n1/2021/0517/c1004-32105488.html)

我嘅主张系：「富爸爸富妈妈适当放松仔女私生活，允许‘下嫁’‘下娶’‘下炮’。考察一个仔女噶伴侣宜从人品出发。」家长当然可以关心。如果真系想帮眼，有一句比问人工更值得问：「你唔顺佢意嗰阵，佢点对你？」至于想讲几多，留畀成年仔女自己决定。

我用「脱轨恐惧」形容一种发展焦虑。白手起家嘅人，试过错过一单生意就交唔出租；守家业嘅人，知道自己判断错一次，伙计可能出唔到粮。呢啲经验值得传。问题系，当个女决定行另一条路，阿妈肯唔肯揭开当年本账，讲畀佢听自己点计、点同人商量，再听个女讲今日条数点解计得过？当个仔拣咗收入低过自己嘅伴侣，阿爸又记唔记得，当年自己未发迹嗰阵，都有人肯睇佢点做人？

「重要的传承是技能和品格，唔一定系金钱。」如果个仔个女学识独立判断，有一日真系会揀一条父母冇行过嘅路。到嗰日，一家人仲坐得埋同一张台，各自讲得出自己点谂，我愿意叫呢样做传承。

> 世代传承的意志，时代的浪潮，人的梦想…
