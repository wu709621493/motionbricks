# 于右任、吴三连、赵元任

> 台湾的地狱笑话还是可以自慢的

用粤语讲都得，去到人名就用国语念。孙中山喺天堂遇见蒋介石，问起行宪以后，边个做第一任总统。老蒋认得爽快：「我。」孙中山自然有下一问。

| 孙中山问 | 老蒋答 | 台下听到 |
| --- | --- | --- |
| 第二任呢？ | 于右任 | 余又任。我又做。 |
| 第三任呢？ | 吴三连 | 吾三连。我连做三届。 |
| 第四任呢？ | 赵元任 | 照原任。照旧，嗰位继续。 |
| 第五任呢？ | 赵丽莲 | 照例连。连任已经成例。 |

孙中山听见书法家于右任、报人吴三连、语言学家赵元任，仲有教育家赵丽莲个个都有机会做总统，真心替个共和国高兴。讲到赵元任，要俾孙先生高兴一阵先。成段笑话入面，最需要一个语言学家帮手嗰位，偏偏就系听到「赵元任」嗰位。

「余又任」同「吾三连」仲有个「我」。到「照原任」，连主语都悭埋。个口吻好似秘书攞住张表入房：「今年呢栏填边个？」「照旧啦。」

## 第六任呢？

有个流传版本再追多一问。老蒋报出「伍子胥」，借近音讲「吾子续」。孙中山今次终于起疑，春秋时代嘅人点样赶得切做总统？老蒋话撞名啫。

前面几届，台上一路换名，张凳上坐嘅始终系同一个人。到「吾子续」，终于换咗个人，个姓都仲未换。

按实际届次，蒋介石当选行宪后第一至第五任总统。佢喺第五任内去世，副总统严家淦依法继任，完成余下任期。到第六任选出蒋经国。「吾子续」借到父子先后执政呢层意思，中间仲有严家淦做完嗰一届。[总统府历任总统名录](https://www.president.gov.tw/Page/42)
