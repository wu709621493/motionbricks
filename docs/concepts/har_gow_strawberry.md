# 最后一只虾饺

*茶楼。两双筷子伸入蒸笼，一双夹到虾饺，一双夹到张纸。*

**我**（吞咗先开口）：「老婆，我系怕你食得太饱咋。😘」

**老婆**（望住个空笼）：「哦，咁我系咪仲要多谢你啊？」

**我**：「咩叫『得了便宜还卖乖』啊？」

**老婆**：「你啱啱食嗰啖叫『得了便宜』。你吞完专登同我讲嗰句，就叫『还卖乖』。」

**我**：「但系但系，人地食左嘴你先有力喔～」

**老婆**：「哦～原来你食咗虾饺，先有力嘴我呀？😏 咁你嘴完，我系咪仲要赞你一句『辛苦晒』啊？过嚟，等我验下货先。😘」

**我**：「货真价实珍珠都冇咁真😘」

**老婆**：「啜～😘 嗯，呢啖系真嘅。下笼虾饺我食晒，等我都有力嘴返你。你教㗎嘛。😏」

*伙记送嚟一碟草莓。佢摊开张点心纸，写低 strawberry，每数到一个 r，就喺我面珠墩锡一啖。*

**老婆**：「三个。到你验货。」

**我**：「草莓英文数r边个唔识姐😏」
