# INTP&ENTJ：长周期J短周期P同上班P日常J噶火星撞地球，究竟系边个带坏左边个😏

星期五晚十一点四十，阿程改咗两个人嘅阿勒泰行程表。佢将「朝早八点食早餐」改成「瞓醒食」。十一点四十一，阿乔将份表嘅权限改成「只供检视」。当时两个人瞓喺同一张床，件事本来可以开口讲。

阿程系 INTP。三年前佢已经决定，三年后要喺一个落雪嘅地方，过一个唔使睇钟嘅星期六。旅费逐个月储，假期提早半年攞。家阵连朝头早几点食只蛋都有人管，照佢自己盘数，过去三年嘅投资算系失败咗。

阿乔系 ENTJ。佢返工嗰阵，星期三仲肯畀两个产品方案一齐行，等星期四听完第一批客点讲，先决定星期五交边款。下属好欣赏佢肯留余地。阿程就想知，点解公司班客有咁好待遇，自己想晏半个钟食蛋都要申请。

「公司两个方案，各有一个人跟。」阿乔答。「你上次话去到先算，系边个企喺雪具铺，逐个码问仲有冇你对靴？」

阿程谂咗阵。「嗰次辛苦你。」
「唔辛苦。嗰朝啲雪靓唔靓？」
「靓。」
「我咪就系冇睇到囉。」

呢盘数终于对得上。阿程储足三年钱，买到自己一个自由嘅朝早。至于阿乔嗰个朝早，原来佢一路当咗系包埋。阿乔份表亦有一笔漏账。佢订房嗰阵肯加八十蚊拣可以取消嘅房价，明白迟啲先决定系值钱嘅。一到编行程，十分钟空白佢都觉得嘥。酒店识得向佢收八十蚊，男朋友暂时未谂到点开发票。

第二朝七点九，阿乔自己醒咗。八点钟张餐枱系佢钟意嘅窗边位，寻晚删嗰行字之前，阿程其实冇问过。佢着好衫落楼，发咗张相畀佢。八点三个字，阿程落到嚟，手上拎住两对雪靴。寻晚瞓之前，佢自己打咗电话留起，今朝顺路去攞。阿乔推只蛋畀佢，仲暖。

食到一半，窗外开始落雪。阿乔原先排咗九点搭车，望咗一阵，自己打畀司机改迟半个钟。阿程叫多壶奶茶。两个人终于坐喺同一边睇雪。

究竟边个带坏咗边个？阿乔先教识阿程，想即兴，可以提早一晚打个电话。阿程就教识阿乔，下次编预算，车费底下可以加多一项叫「场雪实在太靓」。论输赢，司机收足改时费，系全篇唯一唔使检讨性格嘅人。

返广州之后，阿乔喺两个人嘅日历加咗个约会。星期六，瞓醒饮茶。阿程望住个画面笑：「咁都要入日历？」

「间茶楼你拣。」阿乔话，「我净系想问，下个礼拜六仲预唔预你？」

阿程伸手过去，亲自揿咗「每周重复」。😏
