# 廣東話嘅三個 mou

「冇」、「無」、「毋」用粵拼寫，聲母都係 m，韻母都係 ou。讀出聲，雙唇先合埋發鼻音，再圓唇讀 ou。「冇」讀 mou5，係陽上。「無」同「毋」都可以讀 mou4，係陽平。

| 寫法 | 例句 | 聽者點理解 |
| --- | --- | --- |
| 冇問題 | 「可唔可以換張枱？」「冇問題。」 | 講者答應咗對方。 |
| 冇得講 | 「呢間舖嘅手工，真係冇得講。」 | 喺讚賞嘅語境，話自己冇嘢好挑剔，就係畀手藝一個好高嘅評價。 |
| 毋須 | 「小童入場，毋須購票。」 | 通告免除購票嘅需要。當面講，一句「唔使買飛」就得。 |

有人寫「無得講」，讀字時「無」可以讀 mou4。日常口語講「冇得講」，開頭係 mou5。做演員讀本，可以請人先照字讀一次，再望住對手講一次，聽下聲調同語氣喺邊度變。

字音見[香港中文大學《粵語審音配詞字庫》](https://humanum.arts.cuhk.edu.hk/Lexis/lexi-can/pho-rel.php?s1=m&s2=ou)及[香港語言學學會粵語拼音方案](https://jyutping.org/jyutping/)。「冇得」嘅讀音見 [CantoDict](https://cantonese.sheik.co.uk/dictionary/words/39957/)。
