# 基准考古学：菩萨的体重没变，视觉模型改口了吗？

研究提案 · 2026-11-24 · 尚未采集样本、运行视觉模型或验证假设。配套方法见[返学（Anti-Scoop）](../../../skills/anti-scoop/SKILL.md)。

## 问题与范围

从部分高棉、印度和唐代造像的细腰与微凸下腹出发，比较希腊、罗马等传统中相似姿势、角色的圆雕。分别检验两件事：现存样本的腹部造型如何随时代、地区、题材变化？同等质量下，腹部造型能让视觉模型给出的 BMI 估值改变多少？研究保留“某些作品如此”的起点；各地区出现频率须由样本决定。

第一阶段仅纳入圆雕。二维画像和浮雕可作背景。圆雕的照片是观测资料；深度指标要求可复核的侧视或三维扫描。仅有正面照时登记待补。记录衣饰、残损、修复与背面未完成的部位，逐指标判断可测性。把正面宽度比、侧面凸度和真正围度分别命名；围度须有完整截面。坐像通高不能替代真人站高。雕像重量受材料、底座及空腔影响，视觉 BMI 也缺少古代模特儿实测值。

## 执行顺序

1. **编目与冻结样本。** 先选定馆藏目录和检索词，登记全体候选及筛除原因。每件存馆名、藏品号、原始链接、许可、产地及依据、年代区间、角色、姿势、工坊或同模关系、视图与修复情况。产地与收藏地分列；同件多图共用编号。按保存情况和视图覆盖报告各组缺失率。
2. **定义几何读数。** 在统一躯干方向的标准侧视中，以胸骨下端和耻骨区可重复定位的前表面标志点连线为基准，取脐下腹前轮廓至该线的最大有向垂距，除以标志点间距。正值表示向前凸。两名标注者隐藏地区年代后独立定位，报告重复测量差。标志点遮挡、躯干扭转或透视无法校正则记缺失。先以试标检验定义并冻结规则，再开展组间比较。
3. **造数字对照。** 在多个基础人体网格上，把腰侧体积逐级移至腹前。固定站高和平均密度，逐件用闭合网格核验体积、质量和设定 BMI。另设同身高、同密度且体积确实增加的阳性对照。保存网格、单位、生成参数和体积残差。每轮换站立、盘坐、单腿站立与正侧视角；变姿后重查体积。以同一姿势内的配对结果估计形变效应。
4. **盲测视觉模型。** 随机化编号和顺序，隐藏标签与预期值，固定模型版本、提示、渲染尺度、相机和光照。混入重复原图检查一致性，记录不可判读与模型拒答。预留从未参与调参的基础人体，按基础网格划分训练与测试。分别保存估值、输入图和设定值。
5. **分析。** 数字对照主读数为同一基础人体、同一姿势与视角下，形变前后的模型 BMI 估值差。分别报告重复原图的波动、形变效应和阳性对照的响应；模型若永远报同一个数，同样不能通过校准。按基础人体汇总，避免把多个视角计为多个个体。先导试验据重复测量和最小关注差异确定误差容限与正式样本量，冻结后再测试。
6. **比较历史样本。** 以实测几何比例为主要结果。在同地同时期比较不同角色，在相似角色与姿势内比较地区，在同地同题材内比较时期。同模或同作坊作品成组处理；报告组间差及不确定区间，并检查年代不明、着衣、复原和取样偏差。分层后缺少可比对象时只作描述。用年代区间与散点呈现作品，另附数字校准曲线，保证两类证据可分别复核。

## 判断与改判

若历史样本的模型估值差落入受控形变能产生的范围，可陈述“造型差异足以产生同量级读数”。这无法确定古代作品的成因。若差异更大，应检查新姿势、材质、风格和视图覆盖。独立作坊反复作出相似选择，才进一步讨论特定角色的比例偏好；推广到社会审美需结合委托记录或同时代文字。从圆雕不能确证当地人群体型、模特儿 BMI 或遗传差异。

交付顺序为候选与排除表、冻结的标注手册、带真值的合成样本与盲测清单、解盲后的校准报告、历史圆雕比较表。当前交付为研究设计。

|---|---|

本轮公开检索尚未发现将恒身高、恒质量的腹部形变误差用于解释跨时期圆雕差异的完整研究。检索无法覆盖全部未数字化专著与未公开工作。若发现其他题材已用相同干预、对照和读数，应更新方法新颖性判断；若已有圆雕跨群组应用，则同时更新应用判断。
