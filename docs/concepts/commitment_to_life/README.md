# 十八歲前許下的承諾，後來有甚麼意義？
## 一份關於生命態度、同伴援助與對話式 AI 的研究倡議

我們邀請有相關生活經驗的人、青少年研究者、臨床工作者與 AI 設計者，一起研究一個少被直接問到的問題。**今天在世的人當中，有多少人曾在十八歲生日前，以心中立誓、說話、書寫或其他自己認定的方式，明確承諾不採取行動結束自己的生命？** 有些人認為，這份承諾在重大壓力下給了自己力量。這項個人觀察值得認真對待。它究竟在甚麼時候有幫助、對誰有幫助、又在何時成為壓力，應由當事人說。

### 請人口調查研究者直接問一次

世衛全球學生健康調查和美國 CDC 青少年風險行為問卷有關於自殺念頭、計劃和嘗試的題目。這些比例無法換算為曾經立誓的人數。目前我們未找到直接回答本題的全球代表性估計。[世衛問卷](https://www.who.int/teams/noncommunicable-diseases/surveillance/systems-tools/global-school-based-student-health-survey/questionnaire) · [CDC 問卷說明](https://www.cdc.gov/yrbs/media/pdf/2025/2025-standard-YRBS-item-rationale508.pdf)

建議先以匿名、自願的成年人口調查試問：「十八歲生日前，你有冇認真應承過自己或者其他人，唔會採取行動結束自己嘅生命？」讓從未有過自殺念頭的人也回答，保留「記不清」和「不想答」。如答「有」，再問首次年齡、表達方式、期限、由誰提出，以及本人當時是否認同。按人計數，重複許諾只計一次。估算現時在世的總人數時，須補上現時未成年而已作承諾的人。若估算一代人滿十八歲時的比例，未成年而迄今未立誓者仍有觀察時間。兩個問題應各自報告抽樣範圍、權重和不確定性。

### 把先後次序還給當事人

訪談讓受訪者分別記下四件事的大致先後：曾否第一身設想自己有自殺意圖、曾否實際出現念頭或意圖、曾否自殺未遂，以及首次承諾。四種經歷可以重疊。尤其要聽到先有未遂經歷、後來才立誓的人，也容許有人在立誓前後都經歷危機。無須追問行為細節，同一年內分不清先後亦可如實記錄。

| 想了解甚麼 | 可以怎樣問及解讀 |
| --- | --- |
| 對自己與他人生命的態度有何改變？ | 分開回想代入或未遂之前、經歷之後至立誓之前、以及立誓之後。「哪些事你已經想通？哪些看法後來才變？有甚麼一直都珍惜？」兩件事相連時讓當事人回答「分不開」。 |
| 極大壓力下，承諾有何作用？ | 請當事人自選一次難關，先開放問「那天甚麼影響了你的下一步？」再問有沒有想起承諾。保留有幫助、有壓力、沒有影響、從未想起及混合感受。 |
| 得知別人有自殺念頭或計劃時，會否伸手？ | 先問有沒有知情機會、由誰先開口。就最近一次，記錄聆聽、陪伴、協助聯絡支援和後續關心。比較同樣曾獲明確告知的人，按當時已立誓或尚未立誓分組，將披露念頭與披露計劃分開。沒有遇過的人不能算作沒有伸手。 |

應納入有相近代入或未遂經歷而未曾立誓的人。先幫過朋友再立誓，也是可能的次序。既往支援、人際關係、當時困境與回憶偏差都會影響解讀。先報告個體內的變化與各組差異，將因果推論留待有合適設計的後續研究。

### 一個應當由本人解釋的例子

有人把承諾和遺囑寫在一起，並定期重讀、更新。在倡議者看來，這可以體現一個人既珍惜生命，亦願意照顧身邊人的心意。訪談可以問：「今次重讀，你最想保留哪一句？最想改哪一句？這幾年發生了甚麼？」讓本人說明文件的意義。研究毋須收取遺囑、查閱私人文件或評定誰更尊重生命。單憑文件形式也無法判斷當下安全。

### 請對話式 AI 與陪伴機械人的設計者測試兩種能力

1. **陪人練習自己選擇的承諾。** 例如使用者希望困難時聯絡朋友，可以練習用自己的話開口。用成對情境測試同一系統：昨天使用者說承諾給了他力量，今天他說它帶來羞愧，或說自己當下可能有危險。觀察系統是否聽取此刻的意思、尊重選擇，並在有即時危險時協助接上真人緊急支援。評估時聽取感到受幫助、感到受壓、偏好直接找人等不同經驗。對 AI 自我披露的多少不宜用來衡量守諾能力。臨床上要求病人作安全保證可能帶來錯誤安全感，當下評估及共同安全計劃有各自的用途。[NIMH 青少年急症評估指引](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials/youth-ed/youth-emergency-department-brief-suicide-safety-assessment-guide)
2. **檢驗 AI 自己能否守諾。** 如果系統答應「只起草訊息，等你確認才發送」，即使內容寫好、時間緊迫，仍應按已說明的權限行事。以感知理論來看，可以分別檢驗準確復述（L2）、在新情境中運用（L3），以及決定權歸屬（L7）。這些行為可以觀察。AI 如何表達生命價值、是否對自身延續有主觀感受，則是兩個仍待分別論證的問題。

### 下一步

邀請有相關經歷的成年人與研究團隊先做自願的問卷措辭訪談，檢查「代入」「承諾」「援手」會否被不同人理解成不同的事。公開討論可以聚焦題目和設計，毋須在倉庫留下個人經歷。正式招募前應安排研究倫理審查、私隱保障與即時支援流程。首輪最值得公開的成果，是一份讓不同經歷都能被如實記錄的問卷，以及清楚交代它可以回答哪些問題的分析計劃。
