# 《你自己同阿妈讲》
*中国直升机父母点样借坡下驴，同独生女打咗场男女混合双打*

礼拜四食饭，阿晴问阿爸：「星期六我可唔可以去睇阿欣打决赛？佢打咗三年后备，今次第一次正选。」

阿爸将碟蒸鱼转咗半圈，避开条鱼骨，夹咗啖腩畀佢。「去啦，校队难得入决赛。你自己同阿妈讲声。」

十六岁嘅阿晴犯咗个好合理嘅错误。佢以为「讲声」即系通知。

阿妈由厨房捧住碗汤出嚟：「下昼两点补数学，你唔记得呀？」

「我问过陈老师，可以调到星期日。阿爸都话去得。」

阿妈望住老公。「咁以后补习嗰啲你跟呀？上次调堂边个喺家长群度等到十一点？」

阿爸本来只须答一句「今次我跟」。但系讲咗呢句，食完饭就真系要搵陈老师，仲可能要倾返上次点解净系得老婆一个等到十一点。于是佢转头望住个女。

「我几时话实得呀？我叫你同阿妈讲。你而家攞我嚟压你阿妈？」

头先嗰啖鱼仲喺口，阿晴一时答唔到。阿妈坐低，见个女眼湿湿，语气软返：「我知你好想去。我都后生过。不过你老豆最唔钟意人断章取义。你同佢讲句对唔住先啦。」

睇清楚呢一球。**阿爸借阿妈嘅辛苦，收返自己嗰句「去啦」。阿妈借阿爸嘅面子，收起自己头先对老公嗰肚火。** 两公婆由意见不合到同声同气，只花咗半碗汤嘅工夫。阿晴由申请人变成要道歉嗰个，甚至仲未知场波去唔去得。

有啲中国家庭打得最纯熟嘅男女混双，就系咁。两公婆未必夹过口供，甚至可能都真心想个女去睇波。阿妈介意嘅系老公做人情、自己执手尾；阿爸亦知道自己偷咗懒，只系唔想当住个女认。佢哋本来有一场值得好好嘈嘅交。偏偏阿晴最识睇眉头眼额，又最想一家人好好食餐饭。揾佢讲句对唔住，比两公婆摊开条数容易好多。

独生女喺呢张饭枱，有一样特别蚀底。阿爸讲「去啦」嗰阵，阿妈喺厨房。假如隔篱坐住个细佬，就算平时同家姐争鱼腩，今日都可能顺口讲句「咦，头先你真系咁讲㗎喎」。阿晴隔篱张櫈，摆住个电饭煲。等到阿爸话「我唔系嗰个意思」，成间屋记得嗰句话原本点讲嘅，就只剩低个最冇资格纠正佢嘅人。

况且，一家人确实好锡佢。得一个女，星期日阿爸可以推咗饮茶车佢去补堂，阿妈可以亲手煲好汤等佢返。麻烦在于，呢啲真心付出，到拗撬嗰阵随时都拎得返上枱。「你阿妈为咗你……」「你阿爸为头家……」两个人各自替对方讨人情，听落仲比自己邀功大方。阿晴只想攞两个钟去撑一个坐咗三年冷板凳嘅朋友。讲到尾，仿佛成张枱得阿欣嘅三年唔值一提。

嗰晚阿晴讲咗对唔住。阿妈即刻夹多嚿鱼畀佢。阿爸问：「咁决赛喺边度打呀？」佢答：「算啦，我同阿欣讲我唔得闲。」

几年后，阿晴大学毕业，食饭嗰阵话自己揾到工，下个月去佛山返工，租约都签埋。阿妈好愕然：「咁大件事，你点解唔一早同屋企商量？」阿爸都有啲失落：「系啰，阿爸几时唔畀你有自己主意呀？」

阿晴其实好想话畀佢哋听，佢去睇过两间屋，有一间楼下有间糖水铺，芝麻糊磨得同婆婆以前嗰碗一样滑。睇楼嗰日佢影咗张相，连「阿妈你睇」四个字都打好咗。临撳发送，佢谂起阿妈会叫佢问阿爸，阿爸会叫佢听阿妈讲。佢收埋部手机，食完碗芝麻糊，自己上楼量窗。

「间屋几大呀？」阿爸问。

「够住。你哋星期六过嚟啦，我请你哋食糖水。」

今次先至真系「讲声」。
