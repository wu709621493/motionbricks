# 《去呗，跟你妈说一声儿》
*一户北京人家的男女混合双打*

礼拜四晚上，小晴她爸正搁那儿剥蒜。小晴问他：“爸，周六我想看欣欣打决赛去。她坐了三年板凳，这回教练让她打首发。您说行吗？”

“去呗。人家坐板凳那会儿你场场去，好容易上场了，你倒不去了？跟你妈说一声儿。”

小晴冲厨房喊：“妈，周六下午我看球去啊！”

她妈端着两碗炸酱面出来了。“两点半的数学课，你打算让陈老师也上球场找你去？”

“我问过了，能挪礼拜天。我爸也说行。”

她妈把面往桌上一搁，看了她爸一眼：“你说行，那你送？上回说好了你送，临出门儿你们单位老张来个电话，最后谁穿着拖鞋开的车？”

她爸手里那瓣蒜剥得干干净净，又低头搓了半天。

“你这孩子也是。我说去呗，后半句呢？跟你妈说一声儿。你怎么净捡爱听的听啊？”

小晴挺纳闷儿：“我这不正说呢吗？”

“还敢回嘴是吧？”

小晴把嘴闭上了。她妈把醋往她手边推了推：“你爸问你话呢。”

这句尤其要命。她妈刚还等着她爸给个交代，看闺女不吭声，又替他接上了：“你爸跟你说话呢，你非得句句顶回来是吧？”

到这儿，两口子的配合才算看出点儿门道。刚才妈妈问的是丈夫，礼拜天谁送。轮到爸爸张嘴，答的却是闺女，你怎么听话的。妈妈要是接着问谁送，上回那双拖鞋就得接着往下说。眼下有个现成的台阶，她顺势一拐，管起了闺女的口气。爸爸也松了口气，伸筷子给媳妇儿碗里添了点儿黄瓜丝。**这场男女混双，原先那球明明是冲搭档去的。**

小晴是独生女。这时候她特别盼着自己有个弟弟，哪怕是个讨人嫌的，能一边偷她碗里的肉丁一边秃噜一句：“爸，您刚才可比我姐还来劲呢。”可惜他家饭桌第四把椅子上，坐着一袋还没拆封的五常大米。

她也知道她妈那天穿拖鞋开车是实情。更难办的是，她爸刚才替欣欣高兴，也是真高兴。她要说“爸您明明答应了”，像是非要亲爸当着她妈的面儿认栽。要说“妈您甭送”，她妈准得问“你觉得妈连这点儿事都不乐意给你办了？”十六岁的小晴端详了半天，满桌子就她自己最好说话。

“妈，我刚才口气不好。爸，您吃面吧。我周六照常上课。”

她妈把炸酱碗底下那点儿瘦肉都给她拨过去了。她爸还惦记欣欣：“那孩子打几号位来着？”

“四号位。”小晴说。这个倒没听岔。

十一比零。小晴回屋给欣欣发微信：“我们家这场打完了，我到现在也没摸着拍儿。”

礼拜六中午，小晴拎着书包在门口换鞋。她爸从报纸后头探出脸来：“不是两点半上数学吗？这才几点？”

“课挪礼拜天了。我自己坐车去，您二位都不用送。”

她妈在厨房里听见了，手上还沾着面，拿胳膊肘给她指了指门后：“围巾。昨儿晚上洗的，干了。”

体育馆里，欣欣正蹲在场边系鞋带。一抬头，瞧见小晴侧着身子往第三排里头挤，赶紧冲她招手：“你不是来不了吗？”

小晴坐下，把书包往膝盖上一搁：“我后来把他俩的话从头捋了一遍。问了半天谁送我，愣没一个人问我认不认识道儿。”

哨响了。欣欣站起来，把热身服脱了。三年了，小晴头一回看见她把外套递给别人。

终场哨一响，欣欣隔着半个场子冲小晴喊：“你瞧见我那个三分了吗？”

“瞧见了！你投完还往我这边儿看，差点儿漏了人。”

“我找你呢。”欣欣把湿刘海往后一捋，“以前坐底下，一扭脸儿就知道你在哪儿。今儿头一回在场上看你，找了半天。”

小晴心里一动。原来那三年，她在看台上瞧着欣欣，欣欣也从板凳上找过她。不知怎么，这事儿比刚才那个三分还让她高兴。

散场以后，俩人并排往地铁站走。风直往袖口里钻。过了一个路口，欣欣用手背轻轻碰了碰她的手：“哎，我能牵吗？”

小晴把手递过去：“您这人，投三分出手那么快，牵个手倒瞄一路。”

欣欣乐了：“那我不得问问你乐不乐意啊？”

“乐意。”小晴握紧了点儿，“这事儿我说了就算。”

好几年以后，小晴在天津找了份工作。还是吃炸酱面的时候，她说房子租好了，下礼拜搬。她妈举着漏勺愣了一下：“这么大的事儿，你怎么也不跟家里商量商量？”她爸也有点儿委屈：“你倒是言语一声儿啊。爸还能不让你去？”

其实看房那天，小晴路过楼下早点铺，买了个糖油饼。边儿焦脆，中间那块儿糖厚，正是她妈挑油饼的那个讲究。她当时拍了张照片，连“妈您瞧这个”都打好了。又一想，她妈准问你上天津干吗去了，她爸准说看看行，定之前跟你妈商量。小晴把那行字删了，腾出手，趁热把油饼吃了。

“妈，您跟我爸周六来呗。早点儿来，楼下有您爱吃的糖油饼。”

她爸问：“这回还用我开车接谁吗？”

“不用。您二位到站给我打个电话，我接您去。”

她妈低头捞面，过了会儿说：“那你把地址给我发一个。上回你爸说他记得路，我们俩在北广场站了四十分钟。”

小晴笑了，当着他俩的面儿，把定位发进了三个人的群。这回她懂什么叫“跟你妈说一声儿”了。
