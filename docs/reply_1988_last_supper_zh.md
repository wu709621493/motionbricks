# 戒指递给德善，最后一句却给了东龙

*《请回答1988》第十八集的酒局，与福音书中耶稣的最后晚餐。含剧透。*

吴孟城看完正焕告白，问了一句：“怎么狗子这么拉，告白完了还收趴”。这个“收”字抓得准。只听告白的前半段，没人比德善更有资格接下一句。可正焕刚讲完喜欢她，就转向了东龙。把这顿酒和耶稣的最后晚餐放在一起，可以留意一个很小的动作：东西递到谁手边，接下来的一句话又说给谁听？

## 两张桌子

| 看桌上的哪一刻 | 双门洞朋友的酒局 | 《路加福音》22:14–23 的晚餐 |
| --- | --- | --- |
| 谁先开口 | 东龙说想亲眼见一次正焕告白。朋友的一句起哄，给了正焕开口的机会，也预先替他备好了退路。 | 耶稣主动告诉使徒，自己一直盼着在受难前与他们吃这顿逾越节晚餐。席上的人从开头就听到了它为何重要。 |
| 递出了什么 | 正焕拿出空军士官学校的毕业戒指，放到德善面前，又说起她送他的生日衬衫。只有她能从自己的记忆里认出送礼那天。 | 耶稣祝谢、擘饼、递给门徒，说到自己为他们舍身；饭后的杯则连着他以血所立的新约。 |
| 接下来谁能做什么 | 正焕转向东龙，问他的心愿可算满足了。朋友可以笑着接话；德善若想认真回答，倒得先当众问清楚刚才算不算数。 | 耶稣嘱咐门徒往后也这样做来纪念他。听者即使一时难以领会，也知道席间哪个动作可以再做。 |

## 一句玩笑怎样改写了刚才的几分钟

正焕最动人的一句，是讲自己从前为了和德善一道上学，早早就在门口等。德善原来只须记得两个人一道走过的那段路，现在却有机会重新理解那段路开始以前、她根本没看见的一个钟头。戒指再贵重，也替他说不出这个细节。[《每日新闻》对第十八集的报道](https://www.imaeil.com/page/view/2016011117442517897)

偏偏他把最后一句给了东龙。德善微笑了，朋友也吃了一惊；这些表情容得下几种意思。正焕用一个玩笑替整桌人挑了最容易接下去的那种。说他怯，也该承认这一退有体贴的一面：德善免于当众表态。但她若当真，就得由她先冒把玩笑当真的风险。这才是这场戏让人替她意难平的地方。[NewsPim 播出当日对收尾的记录](https://www.newspim.com/news/view/20160109000089)

## 门徒也有听不懂的时候

《路加福音》把擘饼和纪念连在一起。门徒往后再坐到桌前，手里有饼，就有一个具体的动作可以回应这顿晚餐。紧接着，耶稣说出卖他的人也在席上，门徒便彼此追问是谁。经文把这两件事放得很近：人可以领到一份清楚的托付，同时对眼前正在发生的事满腹疑问。[《路加福音》22:14–23](https://bible.usccb.org/bible/luke/22)

换读《约翰福音》，误会甚至有了一个很日常的模样。耶稣把蘸过的一口饼递给犹大，催他去做将做的事。席上有人以为，掌钱袋的犹大是出去买节期用品，或去周济穷人。熟人同桌，各有各的理解。这里的饼在《约翰福音》的这一段用来指认出卖者；上表中嘱咐门徒擘饼纪念的文字出自《路加福音》。两段分开读，才看得出各自写活了什么。[《约翰福音》13:21–30](https://bible.usccb.org/bible/john/13)

## 散席

正焕和耶稣这两桌，能比到“一个人怎样让同席的人接住他的话”这里。再往前走，爱情里德善有自己的选择；福音书里的饼与杯则关乎受难、立约和纪念。硬替双门洞找一个犹大，会把两边都读窄了。

至于狗子到底欠了几分魄力，我倒想替他把账算小一点。他当然有勇气，连当年在门口等了多久都肯当众讲。偏偏轮到德善开口时，他先替东龙把包袱抖了。如果能替他改一句台词，我只添一句：“德善，我刚才讲的都算数。你想哪天回答都行。”然后让他把酒喝了，安静一会儿。德善怎么选，那句台词归她。
