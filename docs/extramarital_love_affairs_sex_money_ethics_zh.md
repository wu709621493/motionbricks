## 二、先把四个词写清楚

本文“婚外”的描述起点是：相关情感或行为发生时，至少一方处在尚未解除的婚姻中，对象不是其配偶。事件时间、分居时间、关系约定改变时间及婚姻解除时间分别记录。未婚伴侣之间同样可能发生承诺被违反的情况，但不因此改称“婚外”。

| 词语 | 本文操作性含义 | 必须另问的问题 | 不能直接推出 |
|---|---|---|---|
| 婚外恋 | 对配偶以外的人产生、表达或经营恋爱情感；区分单方爱慕与双方建立关系 | 仅有内心感受，还是已表达、持续互动、作出承诺？ | 有性行为、有金钱交换，或仅凭感受就完成了违约判断 |
| 婚外情 | 日常语言的宽泛关系标签，可指情感、性及持续关系的组合 | 说话人具体指什么？持续多久？是否隐瞒或违反约定？ | 存在统一可统计的行为，或它与“婚外性”完全同义 |
| 婚外性 | 婚姻存续期间与非配偶发生的性行为；研究须事先说明纳入哪些行为 | 行为类别、时间窗、当事人有效同意、关系约定分别是什么？ | 一定相爱、一定收付款，或一定背着配偶发生 |
| 婚外金钱交易 | 与上述婚外亲密关系相关的财物或经济利益往来；此处是宽口径总称 | 是赠与、借款、共同开支、商业报酬、持续供养，还是以性为对价？ | 所有往来都是性交易，或所有转账都无效 |

“婚外情”适合作为提问的起点，进入研究和法律分析后应拆开。普通友情、一般工作合作和正常市场交易，不因参与者已婚就自动属于本文的婚外金钱交易。

“恋”“性”“钱”也不构成从轻到重的阶梯。没有发生性行为的持续欺骗仍可能损害承诺；有钱往来的关系也可能有真实感情。承认感情真实，与判断行为责任，是可以同时完成的两件事。

## 三、用独立维度描述，避免一个标签代替全部事实

每段关系至少分开记录：情感、性行为、财物、当时的关系约定、各方知情与自主性、照护及资源影响。某一维度“有”，不能代替另一维度的证据。

以下全部为虚构的成年人情境，仅用于说明分类；表中“无”只表示情境已明确没有该项。

| 情境 | 恋爱情感 | 性行为 | 财物往来 | 需要判断的伦理问题 |
|---|---|---|---|---|
| 已婚者单方心动，未表达也未发展 | 有，单方 | 无 | 无 | 如何处理感受与既有承诺；不把未付诸行动的思想当作行为事实 |
| 两人持续表达爱意、秘密规划共同未来，没有性接触 | 有，双方 | 无 | 无 | 是否违反情感排他约定，是否欺骗配偶或对方 |
| 在排他约定下隐瞒一次自愿性行为 | 未知 | 有 | 无 | 行为同意与关系违约分别判断 |
| 配偶事前自愿协商允许一定范围的婚外性，当次行为也获参与者同意 | 可有可无 | 有 | 可有可无 | 是否超出范围、是否仍可自主退出；法律后果另核查 |
| 持续恋爱与共同旅行，其中一人支付费用 | 有 | 未知 | 有 | 开支性质、资金归属和处分权限，不能据付款推定买性 |
| 一名已婚者付费购买性服务，没有建立恋爱关系 | 无 | 有 | 有，性对价 | 同意、交易规制与婚姻责任各自审查 |
| 自称单身者以恋爱承诺取得大额财物 | 至少一方未知 | 未知 | 有 | 身份与承诺是否虚假、财物性质；不能只因分手就认定诈骗 |
| 已婚者与他人发生普通业务往来，无亲密关系 | 无 | 无 | 有，业务 | 不纳入婚外关系统计；如另有利益输送，按其事实审查 |

性暴力、强迫和无法有效同意的行为须独立识别与处理。遭受侵害不应被编码为受害者的“自愿出轨”。研究对同意情况不清楚时保留未知，不能强行填入自愿关系类别。

## 四、婚外金钱交易要继续拆开

| 往来类型 | 应查明的事实 | 伦理或法律分析的重点 |
|---|---|---|
| 日常共同开支、餐费、旅行费 | 谁实际消费，是否代垫，是否约定分担 | 开支不自动证明性对价或恋爱关系 |
| 一次性礼物与无偿资助 | 赠与目的、资金归属、数额和家庭负担 | 表达感情不能代替处分他人或共同财产的权限 |
| 借款、代偿、担保 | 真实借贷意思、履行和债务用途 | 恋爱关系不自动把借款变成赠与，也不自动让配偶共同负债 |
| 持续供养、住房及生活费 | 是否附带陪伴、排他、性或其他条件，能否拒绝 | 分别查经济支持、依赖、控制与实际选择余地 |
| 性行为作为对价的支付 | 是否存在性与利益之间的交换安排 | 与赠与分开编码；法律依行为地及适用法确定 |
| 工作机会、股权、合同或其他非现金利益 | 是否有真实工作与对价，是否存在权力干预 | 不能因有恋爱便否定真实劳动，也不能用恋爱遮蔽利益输送 |
| 涉及欺诈、威胁或勒索的财物要求 | 哪些陈述虚假、哪些压力存在、有哪些可靠证据 | 独立处理侵害；不把胁迫美化为普通协商 |

“包养”一词可能混合多种安排，不能只凭标签完成认定。也不能把所有商业性行为直接等同于人口贩运，或因声称自愿就排除剥削与胁迫的核查。

伦理上，赠与、供养或付款都不购买一个人的身体、永久陪伴或继续关系的义务。拒绝性接触的权利不应与钱款纠纷捆绑；既有财物争议仍需按其性质另外处理。

## 五、纳入常规伦理，意味着把责任讲到具体的人

以下是本文的规范立场。婚姻承载陪伴、育儿、养老、经济互助等多种意义，这给继续共同生活提供了讨论空间，也使资源和照护责任更需要清楚。它不能单独证明婚外关系必然应被接受，或婚姻必然必须结束。

**对自己与配偶：** 辨认欲望、表达变化、履行或重新协商承诺。某人可以提出非排他安排，另一人可以拒绝。沉默、害怕失去住所或经济支持、事后被迫接受，不能自动等同于事前自由同意。后来达成的新约定也不自动抹去过去的欺骗。

**对婚外关系中的另一人：** 不隐瞒足以影响其选择的婚姻状态、关系范围及重大安排。配偶对一种关系模式的同意，不能替代该人的身体与关系同意；第三者也不是婚姻内部矛盾的无条件解决工具。

**对共同资源与需要照护的人：** 分开核查个人财产、共同财产、债务、时间及照护变化。不能以“爱是真的”代替财产权限，也不让孩子承担保密、传话或站队。子女的权利与照护需要不因成年人关系的道德评价而减损。

**对选择结束的人：** 可以停止具体亲密行为，可以要求重新协商，也可以选择退出关系。撤回同意不意味着获得对他人身体的控制权；怎样继续或结束既有关系，需要同时处理资源、居住与照护安排。面对暴力或报复风险，沟通方式应优先考虑当事人安全，而非要求当面对质。

评价应针对承诺、信息、同意和后果，适用于不同性别及性取向。重视排他关系的人无需证明自己“落后”，选择自愿非排他安排的人也不应被迫承受人格羞辱。本文的伦理立场不承诺这些安排在各法域具有同样法律效力。

## 六、中国大陆：忠实义务、财产处分及性交易分别处理

本节限所列现行条文的内容，不将日常“出轨”标签直接转成一个统一法律责任。

- 《民法典》第1042、1043条分别涉及禁止重婚及有配偶者与他人同居，以及夫妻忠实、尊重和关爱义务。第1091条的离婚损害赔偿有其列举情形及其他重大过错条件，不能写成每次婚外心动或性行为都自动触发赔偿。[中1]
- 婚后工资及部分收益通常进入共同财产范围，另有个人财产与书面财产约定规则；借款是否构成共同债务也有独立条件。钱在个人账户里、由自己挣得，都不能单独完成财产归属判断。[中1]
- 2025年2月1日起施行的婚姻家庭编解释（二）第7条，规定了为重婚、同居或其他违反忠实义务等目的，赠与或以明显不合理价格处分共同财产时的无效及相关救济。其目的、财产性质与处分方式等条件不能省略。[中2]
- 2026年1月1日起施行的修订《治安管理处罚法》第78条规定卖淫、嫖娼的处罚。它与一般婚外恋、情感往来、赠与不是同一个法律概念；不能仅凭转账推定已经满足全部事实条件。[中3]

上述规定使“感情”“性”“钱”成为相互关联但必须分别证明的问题。对关系安排的私人同意，不自动排除共同财产、法定照护义务或其他适用规则。

## 七、法国：忠实义务与赠与效力可以得到不同处理

法国很适合展示法律判断的层次。这里的“谨慎”是本文对限定适用范围这一方法的评价，不是对法国社会或全部法律的总评。

| 法国材料 | 核对所得的最窄结论 | 比较价值与限制 |
|---|---|---|
| 《民法典》第212条 | 配偶之间仍负尊重、忠实、扶助与协助义务。[法1] | 不能从私人关系的多样性推出法律已取消忠实义务 |
| 第242条 | 可归责于配偶、严重或反复违反婚姻义务，并使共同生活难以容忍的事实，可以成为过错离婚请求依据。[法2] | 保留条文门槛，不能把每次心动写成自动准予过错离婚 |
| 最高法院全体庭2004-10-29，03-11.238 | 婚外关系背景下的无偿给予，不仅因该背景就以违反善良风俗为由无效；原案具体涉及遗赠。[法3] | 这是历史判例的特定法律判断，不是婚外转账或遗赠一律有效的保证 |
| 《民法典》第1422条 | 在共同财产制相应范围内，一方不能独自作出生前无偿处分共同财产等行为。[法4] | 须先查财产制度；不能用2004判例跳过共同财产权限 |
| 《刑法》第611-1条 | 向从事卖淫者以金钱、报酬承诺或实物利益等换取性行为，受到该条处罚规制。[法5] | 亲密关系赠与与购买性服务仍须分别认定 |

2004年判例撤销的是下级法院对遗赠效力的判断；它不表示法院赞许背叛，也不表示成年人的感情能够排除其他财产限制。该判决援用当时的法条，本文没有把旧合同法条号冒充现行法。

法国的启示可以表述为：忠实义务是否被违反、离婚请求是否满足条件、财物处分是否有效、是否购买性服务，分别寻找法律依据。本文据此提出比较分析，不从一个判例推演整个社会的性伦理。

## 八、美国州法：同一件事可能进入不同法律通道

以下选三个州，而不制作未经核验的全美“通奸地图”。表格不是同一诉因在各州的完整对照；每行标明实际核对的法律问题，未列制度不能读成不存在。

| 州 | 本次核对的问题与材料 | 可以说明什么 | 不能说明什么 |
|---|---|---|---|
| 加州 | 州法院指南：离婚不要求证明另一方有错；财务披露及隐瞒财产另有后果。[美1][美2] | 无过错离婚与经济责任可以并存 | 无过错等于所有欺骗、财产转移或其他行为均无后果 |
| 纽约州 | A4714于2024-11-22签署为第462章，废除通奸罪；现行《家庭关系法》第170(4)、170(7)仍分别保留通奸与一定条件下关系无可挽回破裂的离婚路径。[美3][美4] | 去除刑事处罚，与民事婚姻制度的调整不是同一件事 | 废罪等于删除全部民事后果或等于赞许行为 |
| 北卡罗来纳州 | G.S.52-13仍规定 alienation of affection 与 criminal conversation 两类民事诉因的程序限制；2009-400号法明确其民事性质。[美5][美6] | 某些针对第三者的婚姻相关请求仍有法律入口 | 名称含 criminal 就是刑事指控，或知道婚姻受损便必然胜诉 |

北卡第52-13条限制的是相应诉因：排除法定永久分居条件成就后发生的行为、规定从最后相关行为起的三年时限，并将被告限于自然人。[美5] 具体构成要件、抗辩、管辖和法律适用仍需查对应判例，不能把这个程序条款当成完整胜诉清单。

纽约的例子尤其清楚：刑法废除一个罪名，民事离婚条文仍可能保留相近的行为概念。加州则说明解除婚姻无需先裁判谁道德上更差；法院对财务披露的要求仍然存在。本文未据此判断任何一州所有婚外行为的合法性，也未比较三州全部性交易法规。

跨州或跨国事件还须分别核查行为地、住所、法院管辖、法律适用及事件当时版本。结婚登记地或某一个网页不能包办所有问题。

## 九、接续 PR #94 的 OpenIRB 操作：怎样提问和统计

本轮没有新的人体研究、问卷招募、个体数据分析或审批审计。下表是拟议研究的定义检查清单，未投入调查。

| 应分列的变量 | 最低限度的提问与编码 |
|---|---|
| 事件与婚姻时序 | 当时是否已婚、分居、改变关系安排或已离婚；分别记录时间窗 |
| 情感与关系 | 单方感受、双方表达、持续关系和承诺分别问；不凭研究者猜测填“相爱” |
| 性行为 | 在提问前定义范围；线下接触、线上性互动等分列；不把仅有亲吻与性交混算为同一口径 |
| 各层同意与信息 | 当次行为的有效同意、配偶间关系约定、婚外对象知情情况分别记录；不从研究同意推定关系同意 |
| 经济往来 | 类型、方向、时间、金额区间、对价及资金归属；“对价不清楚”保留未知 |
| 承诺与改变 | 约定内容、是否实际达成、何时改变、是否有胁迫；不从“没被发现”推定被允许 |
| 子女及照护 | 另问育儿身份、子女知情、冲突及照护变化；不把已婚样本当父母样本 |
| 拒答与缺失 | 肯定、否定、拒答、不知道、不适用分别编码；不把拒答填成肯定 |

四种标签有交集，不能把四项比例相加叫“总出轨率”。若要报告“任一行为”，必须先约定纳入范围，在同一分母和时间窗内按人去重，再报告交叉分布与不确定性。不同来源、不同年份或不同问法不能直接拼成一条趋势。

PR #94 已记录的中国历史调查仍保留原出处、拒答编码及抽样限制。本篇没有重新估计那些比例，也没有把婚外性数据扩写为婚外恋、性交易、父母行为或子女知情率。

如果未来调查这些问题，应由适用制度下的机构核查审批、豁免或其他认定；区分参与研究、使用数据与关系中的同意。采用必要最少的信息、可跳答和退出安排，避免共同设备通知暴露参与，不默认收集姓名、账号、原始转账截图或第三者身份。公开材料采用去标识汇总；研究批准也不能为某种婚姻模式签发道德许可。
