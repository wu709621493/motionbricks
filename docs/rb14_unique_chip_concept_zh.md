## 1. 目标与本次交付

将两组各 7 个铷原子的空间分布，通过纳米机械谐振器转换为频率响应，用于两种独立实验：每轮生成一个原始随机样本，或将一次形成的结构稳定保存为器件指纹。用户将后者命名为“孤品芯片”。“孤品”是设计目标，不是绝对唯一、物理不可复制或密码学安全的认证结论。

本次交付是概念架构、物理近似、拟议数据契约和实验验收计划；没有新增驱动、仿真器、PUF 实现或随机数生成服务，也没有流片、沉积原子或连接仪器。未来的软件模拟必须标为 `SIMULATED`，不能用伪随机位置证明量子随机性或实物不可克隆性。

软件基线是已合并的 [PR #83](https://github.com/wu709621493/motionbricks/pull/83)，合并提交 `157b4ff99289cf32c15345ff1f6bc7e6ddd0f7a0`。相关现有说明：[旧 CPU 兼容](pyignite_legacy_cpu_zh.md)、[温度与检查点](pyignite_thermal_checkpoint_zh.md)。

## 2. 讨论中的数字分别表示什么

| 参数 | 本设计中的含义 | 不能据此推断 |
|---|---|---|
| 7＋7 个原子 | 初始目标为 14 个铷-87 原子；两组标签属于制备协议 | 已经捕获、沉积或保留全部 14 个原子 |
| 7×7＝49 | 可构造的跨组配对量／实验通道数 | 49 个独立量子位或每轮 49 bit 新熵 |
| 300×300 nm | 候选接收区，面积 90,000 nm²＝0.09 µm² | 完整芯片、支撑、电极和封装都能放进这个面积 |
| 32 nm | 讨论中的候选加工特征尺度，尚未选定代工平台 | 32 nm 定位精度、读出分辨率或成熟逻辑工艺 |
| 12 英寸 | 行业常用的 300 mm 晶圆规格；严格 12 inch＝304.8 mm | 单个原子器件需要整片晶圆，或晶圆面积增加随机熵 |
| 49 位输出字 | 可选的软件封装长度 | 输入不足时可以凭哈希补足 49 bit 熵 |

国内超分辨光刻研究曾报告 50、45、32 nm 成像光刻及 22 nm 单次曝光线宽分辨率，应用侧重微纳光学等结构；不能直接等同于同数字的逻辑制程。[2] 国产 300 mm 硅片已有规模化销售。[3] 这些是工艺背景，本设计尚未取得满足悬空结构、材料、良率与读出要求的制造方案。

中国空间站报告了铷原子云 9.7 pK 的等效膨胀温度及 7 秒自由演化窗口。[1] 这并不意味着硅片或接收器处于 pK，也不代表从原子云挑出 14 个原子、约束到 300 nm 尺度后仍保持相同动量分布。重新俘获、局域化、表面相互作用与吸附都要另算能量和噪声预算。pK 不是本原型的先决验收条件。

## 3. 两种模式的生命周期

| 模式 | 制备与保存 | 每轮读出 | 复位／失效 |
|---|---|---|---|
| `RANDOM_SAMPLE` | 重复制备、重新落点或经过验证的随机化 | 一次完整频移向量编码为一个原始整数样本 | 必须验证清除／更换接收单元或再随机化过程，不能重复读取旧样本冒充新熵 |
| `DEVICE_FINGERPRINT` | 随机形成一次，再稳定保存最终结构 | 对注册过的驱动条件重复测量，形成容错指纹 | 不主动清除身份结构；不可逆漂移、原子损失或结构改变后隔离并重新评估 |

两种模式共享读出技术，但没有证据支持同一组持续扩散的原子同时提供稳定身份和独立新随机数。若同芯片实现两者，优先使用分开的感测单元、状态与数据流。

身份模式的核心缺口是稳定保存。候选研究包括稳定吸附位点、封装以及将落点转写为持久结构；目前均未验证。转写后，应以最终结构为指纹来源重新注册，不能继续声称器件保留了原始的 14 原子量子态。铷的扩散、脱附、表面化学和污染必须实测；无需宣称长期保存叠加态。

## 4. 从“计算纹路”到频率传感器

候选结构为硅基工艺上的悬空纳米梁／薄膜，加驱动、位移读出和频率跟踪电路。“芯片频率”在本文指机械谐振频率，不是 CPU 主频。普通硅片上刻导线并不会自动得到原子质量灵敏度；材料、厚度、边界条件、残余应力、电极和电路仍待设计。碳纳米管也可作为比较平台，不默认其性能可移植到硅。

已有约 150 nm 长、近 2 GHz 的碳纳米管谐振器达到 1.7 yg（1 yg＝10⁻²⁴ g）质量分辨率，并研究氙原子吸附。[4] 多模态纳米机械实验可以从频移获得吸附质量与位置信息。[5] 这些是相关技术证据，不是 Rb-14 实验结果。

在小质量负载、线性振动、点状吸附、模式形状近似不变且忽略刚度／应力变化时：

$$
\frac{\Delta f_k}{f_{k,0}}\approx-\frac{1}{2M_{\mathrm{eff},k}}\sum_{i=1}^{N_{\mathrm{captured}}}m_{\mathrm{Rb}}|\phi_k(\mathbf r_i)|^2.
$$

`φ_k` 为无量纲模式形状，约定最大绝对值归一为 1；`M_eff,k` 必须使用同一归一化定义。`f_k,0` 是该模式的基线频率；`N_captured` 是经测量或模型约束的捕获数，不自动等于目标值 14。频率用 Hz，质量用 kg，位置在模型接口中统一用 m。

原子质量相同，落点通过模式形状影响频移。若响应只取决于总质量，每轮完整接收 14 个原子会给出几乎相同的质量贡献，无法读取落点随机性。若模式具有镜像对称性，也会存在不同落点产生相同响应的退化。

单一频率是高维分布的压缩观测，不能据它唯一重建全部落点。多模式可增加观测约束，但模式数不等于独立信息位数。14 原子同时落下时，更不能把单颗粒多模态定位的实验结论直接套用；应比较逐个到达与同时到达的可辨识性。仅用于随机采样时可以接受多对一映射，但必须针对最终输出评估熵。

表面力、吸附引起的刚度变化、扩散、质量流失和读出反作用可能使上述纯质量近似失效。[6] 在获得模式仿真、有效质量、品质因数、频率稳定度及给定积分时间的噪声数据前，不承诺频移大小、单原子灵敏度或每秒输出速率。

## 5. 随机数、准随机序列与指纹

每个原子只做一次二值内部态读出时，14 个读数最多形成 2¹⁴ 种串；这不是包含运动自由度后的一般上界。若仅由这些二值读数构造 `C_ij = A_i XOR B_j`，同时翻转全部输入不改变矩阵，因此矩阵至多有 2¹³ 种值。49 个格子并不带来 49 个独立随机比特。

若测位置或频率，多结果读出允许不同的熵预算。应由分辨率、概率分布、相关性、探测噪声和可获得的旁信息决定有效熵；不能按连续变量的小数位数计数。对于单次离散输出，最小熵为 `H_min(X) = -log2(max_x P(X=x))`；存在历史或攻击者旁信息时需要相应条件最小熵，而非仅统计边际分布。哈希不能创造输入没有的熵。[8]

随机样本模式先保留原始频移、噪声与质量标记，再做固定版本的量化及经过评估的提取。量化边界和输出位数由独立校准数据决定，不能为了让测试通过反复调参。熵不足时积累更多有效轮次或不输出；一次采样不保证立即得到一个均匀的 49 位数。

量子随机性还需要区分制备和测量贡献、热运动、吸附动力学及电子噪声，并说明所依赖的可信模型。统计测试通过不构成量子来源认证。只测到不规则频率不能直接标为 `QUANTUM_CERTIFIED`。

数学上的 quasi-random 通常指 Sobol 等低差异序列。[9] 可将验证后的熵用于随机化 49 维 Sobol 采样；这种输出是有结构的采样点，不能宣称每一点含有同等数量的新物理熵。保存种子用于复现实验时也要与秘密身份材料分开。

## 6. 孤品注册、读取与身份边界

机械谐振型 PUF 已有研究：CMOS-MEMS 频率梳实验使用驱动频率作为挑战，并量化频率梳响应。[7] 我们将 Rb-14 定义为候选物理指纹平台，不沿用其他器件的安全指标。

1. **注册：** 对最终固定结构，在预先声明的温度、电压、压力和积分时间范围内重复测量多模式响应；记录器件、仪器、挑战和校准版本。
2. **稳定性选择：** 使用训练／校准数据确定稳定特征、量化边界及拒绝区；在独立测量、不同日期和重新上电的数据上评估，不把同次测量拆分后当成独立验证。
3. **容错：** 有需要时设计安全草图／模糊提取器，计入辅助数据泄露和偏差带来的熵损失；不能直接哈希带噪浮点数期望每次一致。本文未实现纠错或密钥派生。
4. **匹配：** 测量条件有效、记录新鲜、版本匹配且距离在预先固定阈值内，才返回候选匹配；其他情况返回未知或拒绝，不自动放宽阈值。
5. **认证：** 静态指纹匹配与抗攻击认证分开验收。公开频谱、复制模板或软件仿真都可能仿冒读数；需要额外设计可信采集、访问控制及抗重放协议。仅给旧频谱拼接 nonce 再哈希，无法阻止持有频谱的人仿冒响应。

“随机形成”和“物理难复刻”不自动保证响应不可预测。需要测试查表、回放、建模与电子替代读出；线性频移模型尤其不能靠增加挑战数量自动获得安全性。14 原子或一个长哈希值都不能证明 128／256 bit 安全强度。

## 7. 与 PR #83 的实际边界和拟议接口

| #83 已有能力 | 本设计可复用的部分 | 尚需新增／验证 |
|---|---|---|
| 显式 CPU 构建档与独立 smoke | 测量控制主机的计算预检与证据记录 | 仪器接口、真实旧硬件和完整依赖兼容性 |
| `FCBlock(max_batch_rows=...)` | 可选的小批量特征变换 | 经过训练和独立验证的补偿／匹配模型；不默认神经网络优于简单模型 |
| `TemperatureGuard` | 控制主机 CPU 温度与故障锁定 | 谐振器温度、压力、电压及各自有效工作范围；不能用 CPU 温度替代 |
| `CheckpointStore` 与完整 FC 输出保存 | 原子写入与检查点校验的机制参考 | 原始频谱、原子计数、基线、挑战及校准的完整采集事务 |

默认 CPU 规则是同一传感器严格高于 100°C 至少 10 秒且至少 3 次有效采样时锁定，硬件 critical alarm 立即锁定。它是控制机的软件边界，不是铷、封装或谐振器的容许温度。器件工作温区尚未获得数据，应单独监测；该温区未知时不能认可真实指纹注册。

`FCBlock` 使用 FP32。高载频上的微小频移应先在采集层用有足够分辨率的计数／数值格式求差并记录原始值，不能先把绝对频率压成 FP32 导致信号消失。归一化特征进入 PyIgnite 前需评估量化误差，并与独立参考实现比较。PyIgnite 不会凭计算补回丢失的测量信息。

以下为拟议数据契约，尚无对应 API 或验证器：

| 字段组 | 最小内容 |
|---|---|
| 来源 | `schema_version`, `evidence_origin`（`SIMULATED`／`MEASURED`）, `run_id`, `device_id`, `mode` |
| 制备 | 同位素、目标原子数、捕获数及其证据；未知捕获数用 `null`，不填 14 |
| 挑战 | `challenge_id`、驱动频率／幅度、模式标识、积分时间、仪器时钟参考 |
| 测量 | 基线与读出频率（Hz）、频移、单位、频率不确定度、原始数据引用 |
| 环境 | 器件温度、电压、压力及传感器来源；CPU 温度另列 |
| 版本 | 制造批次、模型／量化／校准版本与代码提交 |
| 完整性 | 序号、UTC／单调时刻、质量标志、持久化状态与失败原因 |
| 结论 | 原始样本编号或匹配结果；未评估熵／安全强度保持 `null`／`NOT_EVALUATED` |

当前检查点只保存完整 FC 输出和 CPU 温度，不是整个实验状态。新采集器应先保留完整原始测量，再接受派生结果；断电、传感器过期、保存失败或模式丢失后不返回成功。恢复旧检查点只用于追溯／恢复流程，不能把旧输出当作新认证或新随机样本。

校验和用于发现文件损坏，不是防篡改签名。身份模板、辅助数据、模型和挑战访问需要按认证协议管理；生产秘密、原始敏感指纹和可复用密钥不应提交到公开仓库。CPU 温控不能安全强行中断正在运行的 C／NumPy 调用，也不能保证全机失效后补写。

## 8. 分阶段验收计划

以下都是待执行项目。数值门槛须在独立验证前确定并版本化，不能把本表当作已通过记录。

| 阶段 | 要回答的问题 | 应保存的证据 | 当前状态 |
|---|---|---|---|
| 器件预算 | 300×300 nm 接收区的模式、质量、应力和读出是否可行？ | 几何、材料、有限元假设、有效质量、噪声与频移预算 | `NOT_RUN` |
| 空白读出 | 无原子时能否稳定追踪模式？ | 不同积分时间的频率噪声／Allan 偏差、漂移、温压电压扫描 | `NOT_RUN` |
| 可控吸附 | 频移是否来自吸附且与位置有关？ | 空白、已知负载、捕获／损失证据、逐次与同时吸附比较 | `NOT_RUN` |
| 结构保存 | 固定后能维持多久？ | 多日、热循环、断电重启、封装前后及表面变化记录 | `NOT_RUN` |
| 指纹识别 | 同颗重复差异是否小于不同颗差异？ | 多颗多批次数据、固定阈值、误拒率／误受率及置信区间 | `NOT_RUN` |
| 仿冒评估 | 能否回放或学习响应？ | 留出挑战上的查表／建模／电子模拟结果与威胁模型 | `NOT_RUN` |
| 随机模式 | 每轮新增多少可提取熵？ | 复位有效性、跨轮相关、条件熵预算、故障与后处理记录 | `NOT_RUN` |
| 软件接入 | 错误时是否拒绝新结果并保留最后完整记录？ | 仪器丢失、过期、存储失败、版本不匹配和恢复测试 | `NOT_RUN` |

初期可用有限样本寻找问题，但不能以几颗样片的零误判证明量产唯一性；错误率应附统计区间。模拟数据和真实数据分开报告。不得把 #83 的历史软件测试当作本器件的热学、物理或认证验收。

当前下一步是完成器件与噪声预算，并用明确标记的模型检查可辨识性；是否保留 300×300 nm、选用硅还是其他材料、需要多少模式以及是否坚持恰好 14 个原子，由这些结果决定。
