# 消獨，或者西太平洋的一碗枸杞

兩公婆夜晚食飯，一個煎緊蛋，另一個撕開包枸杞，一言不合就往碗裏倒。

「是藥三分毒喎，你落咁重手？」
「消獨啫。」
「叼，原來都唔使食肉，我还以为抢我鸡蛋呢！」

煎蛋嗰個護住隻碟。倒枸杞嗰個挪張凳過嚟，冇搶蛋，攞咗對筷子。蛋黃先至慢慢分開兩邊。

## 飯桌考據

- **枸杞**。雄鼠食枸杞多糖二十一日，研究員睇交配錄影，記到射精次數增加、射精潛伏期縮短。另一項人體試驗搵咗八十名精索靜脈曲張患者，量精液同激素。想知兩公婆今晚有冇興致，兩篇都未答到。[雄鼠研究](https://pubmed.ncbi.nlm.nih.gov/22523540/) · [人體試驗](https://pubmed.ncbi.nlm.nih.gov/41032943/)
- **生蠔**。有研究用蠔肉酵素水解物，喺性功能障礙模型雄鼠身上觀察到性行為指標改善。由實驗室嗰份水解物到飯桌嗰半打蠔，中間仲欠人體食用試驗。[原始研究](https://pubmed.ncbi.nlm.nih.gov/41399856/)
- **羊腰子**。查羊腎、羊腰子、羊腎萃取物同勃起或性慾，今次未搵到直接對照研究。倒有一篇係畀公羊補充精氨酸，再觀察隻羊嘅性行為。睇清楚，食嗰個係羊。[公羊研究](https://doi.org/10.3389/fvets.2022.899434)
- **關元同氣海**。兩個都喺臍下。有人喺包括呢兩穴嘅區域揀點做熱敏灸，比較服中藥同服中藥加灸嘅勃起功能障礙患者。研究冇單獨驗證兩穴配搭，亦冇測健康人當晚嘅性慾。[臨床試驗](https://pubmed.ncbi.nlm.nih.gov/38373758/)

講完考據，蛋都就快凍。兩個人收埋手機，坐埋食。以下係席間祝酒辭，個杯入面裝咩，悉隨尊便。
