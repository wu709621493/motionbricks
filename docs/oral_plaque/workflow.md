# 牙菌斑面积 × 产酸能力：采样、清洁与牙面 pH 联合研究流程

版本：0.1；日期：2026-11-03。状态：研究设计，未完成设备、方法学或临床验证。

用户提出的研究核心：比较木糖醇、尼古丁及其组合，关联菌斑面积与产酸能力；清洁时回收菌斑；贴近牙面记录 pH。本文将这些问题转为可审查的工作流，工程细节与统计方案为待验证建议。

这是 MotionBricks 用户 fork 的独立研究文档扩展，不是 NVIDIA 原项目的牙科功能或背书。没有传感器驱动、机器人口内操作、药物配制或临床诊断功能；不需要加载模型或 GPU。配套 [数据字典与空白模板](data_dictionary.md) 用于后续采集软件开发。

## 1. 研究问题与证据边界

1. 菌斑覆盖面积与原位酸化是否相关？
2. 在可比菌斑面积下，各处理组的体外净产酸速率是否不同？
3. 清洁移除量与实际回收量是否一致，回收是否保留代谢活性？
4. 贴近天然牙面的传感器能否重复记录局部 pH，且不明显改变原来的微环境？

木糖醇已用于部分尼古丁戒烟口香糖的辅料；这一事实不证明组合具有防龋协同作用 [1]。木糖醇和尼古丁对变形链球菌生物膜的体外研究不能直接推出混合后的净效应或人体防龋收益 [2,3]。无糖口香糖的唾液刺激效应也必须与成分效应分开 [4]。

主张层级：设备测量可行性 → 分析方法有效性 → 生物学效应 → 临床结局。不得跳级。pH 上升、生物膜减少、体外矿物损失下降均不能单独证明临床龋齿减少。

## 2. 分阶段实施与职责

| 阶段 | 工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| A：台架 | 校准 pH 系统、验证刷头回收与污染控制、模拟数据检查 | 预先确定的误差、漂移、回收率和重复性要求达标 |
| B：离体研究 | 匹配胶基的四组比较、产酸测定、成分与缓冲干扰检查 | 可重复结果、方法定量范围成立；完成相关机构生物安全审查 |
| C：受监督口内方法学 | 自愿参与者的定位、舒适性、原位 pH 与取样一致性 | 伦理审批、知情同意、牙科人员与设备负责人签署具体 SOP |
| D：临床产品研究 | 如有必要，针对已有尼古丁使用者的戒烟用途研究口腔结局 | 独立药物/器械与伦理审查、药代和安全评估、预注册临床方案 |

牙科负责人决定牙位、采样可接受性和停止条件；仪器负责人验证传感器；实验室负责人验证样本运输和测定；统计负责人冻结主要终点和分析计划。C 阶段不需要为了测量而给予尼古丁。不得招募非使用者仅为防蛀而开始使用尼古丁。本文不授权自行进行口内装置实验。

## 3. 工具清单与成熟度

| 工具 | 用途 | 方法状态与验证项目 |
| --- | --- | --- |
| 标准化口内相机、定位架、尺度标记 | 重复成像、确定牙面 ROI | 验证距离、角度、照明、反光及遮挡；平面投影面积不等于曲面真实面积 |
| 经验证的菌斑成像方法与分割软件 | 计算覆盖比例、保存原图与掩膜 | 显色/荧光信号须与人工参考比较；显色剂影响需另验 |
| 无菌无蜡牙线、标记采样管 | 邻面菌斑移除并回收 | 有采样先例 [5]；记录具体邻面，不能代表整颗牙 |
| 无菌牙科刮匙 | 专业人员定位采样参考 | 有研究先例 [6]；不将不同牙位回收量直接互比 |
| 可拆卸采样刷头、独立收集仓 | 清洁并回收附着物/冲洗液 | 新原型；验证残留、回收率、唾液混入、清洁力与活性保持 |
| 口内适用微型 pH 探头、参比电极、温度读出 | 局部原位测量 | 微电极/ISFET 有研究先例 [7–9]；具体设备需验证 |
| 定制可摘式固定架 | 探头重复定位 | 检查保持力、咬合、唾液流通、组织接触与易取出性 |
| 校准缓冲液、独立参考 pH 仪、时间记录器 | 校准与事件同步 | 缓冲液不得用于口内；记录批号、温度、原始读数 |
| 经验证的活性保持介质、移液器与运输记录 | 样本转运与分样 | 介质须与产酸检测兼容；DNA 保存液不能自动替代活菌介质 |
| 台式 pH-stat/微量滴定或有机酸定量平台 | 独立测定产酸 | 验证空白、线性、检出/定量限及基质干扰 |

完整回收系统设计：限定牙面的一次性刷头 → 密闭转运 → 已知体积的洗脱 → 分样。记录刷头、收集仓与液体三个位置的残留；不可把刷后吐出的液体称为纯菌斑。采样刷头应与标准牙刷/专业取样比较，不能预先宣称清洁效果更好。

## 4. 贴牙 pH 测量设计

### 4.1 明确被测对象

每条数据必须带 `measurement_target`：`natural_plaque`（天然牙面菌斑）、`saliva`（局部唾液）或 `sensor_biofilm`（传感器表面生物膜）。三者分别分析；传感器表面长出的菌斑不自动代表天然牙面菌斑 [8,9]。

优先评估固定架定位的固态微型探头方案。传感面须暴露于目标区域；粘接剂不得盖住测量面。ISFET 也需要稳定参比系统和电气读出，不是贴一枚芯片即可。具体封装、参比体系与固定方式由器械和牙科团队决定。

### 4.2 台架与口内检查

- 使用覆盖预期测量范围的至少两点校准；另用独立检查液验证，记录温度。是否采用三点由设备规格和范围决定。
- 记录响应时间、迟滞、重复性、漂移及清洁/灭菌后的变化；用参考仪比较。
- 测前与测后检查；超出预注册容差的数据标记失败，不事后平移数据来制造通过。
- 记录采样间隔、时钟偏差与缺口上限。采样频率根据实测响应时间设置，不能把高频采样当成高时间分辨率。
- 比较有/无载体及不同定位方式对唾液流通、菌斑扰动和读数的影响。
- 设备封装需检查生物相容性、液体侵入、电气隔离、松脱/误吞风险及回收方式。不得用裸露普通实验室玻璃电极自行入嘴。

待冻结的验收参数见数据字典。所有容差必须在正式采集前由负责人填写；本文不编造已经验证的医疗器械性能数字。

## 5. 研究设计与混杂控制

四组优先用于 B 阶段的离体研究：匹配胶基、胶基＋木糖醇、胶基＋尼古丁、胶基＋二者。各组需记录实际释放到检测体系的浓度，不能只看包装含量。胶基、其他甜味剂、碳酸盐/碳酸氢盐、香料、起始 pH 与缓冲容量尽量匹配，并记录无法匹配项。

区分两种问题：

- 产品整体效果：保留配方原有酸碱特性，比较实际总效应。
- 成分生物学效应：另设 pH/缓冲匹配与无细胞配方空白，估计成分引起的代谢变化。

两类结果分别报告，不通过调平 pH 消掉产品作用后仍称为产品总效应。实际口内研究需同步记录唾液流量/缓冲指标、牙位、菌斑厚度或生物量代理、最近清洁/进食、含氟产品、相关用药与尼古丁暴露。由获批方案规定准备时间，不要求参与者自行停药或长期停刷牙。

优先在同一供体样本可充分均匀分样时做配对离体比较；检验分样代表性。口内重复研究采用随机顺序或经论证的交叉设计，预先验证洗脱期。左右牙位不保证等价；同一牙位采样会破坏菌斑，不能把后续测量当作未受扰动重复。

## 6. 一次完整研究访视的操作顺序

以下为专业团队完成具体参数后使用的流程骨架，不是可直接开展临床试验的获批 SOP。

1. **建档与确认。** 使用匿名研究编号；确认同意版本、牙科检查、牙位及表面、纳排标准、用药/口腔护理记录和设备检查。身份关联表留在授权机构，不进入 GitHub。
2. **固定分析区域。** 为每个 ROI 建立唯一 `site_id`，记录牙位编号体系、表面、边界和定位照片。图像、pH 与采样使用同一个 `visit_id/site_id`。
3. **基线成像。** 在改变菌斑前采集标准图像。若只有显色法能可靠识别面积，必须先验证染料不影响 pH/代谢；否则采用匹配独立访视或分开的成像牙位，并明确不再属于同一现场的一一对应测量。普通白光照片不能默认看见所有菌斑。
4. **原位基线。** 安装经检查的探头，记录稳定性、位置和唾液条件；标注接触/压迫或菌斑脱落。若安装改变 ROI，应重新记录并按规则剔除或改为设备干扰研究。
5. **标准化挑战与时间记录。** 按获批方案统一底物、剂量、接触时间和观察窗口；准确标记挑战及干预事件，连续保存 pH、温度和质量标志。对照与处理条件必须有相同事件安排。本文不规定人体糖挑战或尼古丁剂量。
6. **完成原位观察后取样。** 移开探头并记录对菌斑的扰动；使用预定方法限定在同一 ROI 清洁取样。先进行短暂标准化无牙膏采样，随后完成正常护理；不是长期无牙膏刷牙建议。牙线、刮匙、刷头的方法效应分别记录。
7. **回收与转运。** 将回收物转入已知体积、已验证的介质。记录采样、洗脱、运输、接收与检测时间、温度和介质批号；加入器具/介质空白。保持活性的运输 SOP 需实测验证，不能根据 DNA 保存成功推断代谢未变 [5]。
8. **清洁后成像。** 用相同 ROI 和成像条件复测残留覆盖；记录反光、出血、缺失区域及无法比较原因。完成牙科人员认可的常规清洁，检查器件全部取出。
9. **样本分流。** 按预定顺序保留代谢测定份；另分生物量/细菌定量与可选分子分析份。代谢份不得先固定、加入裂解液或经未验证冻融。
10. **离体产酸。** 在固定检测体积、底物、温度、气体环境、起始 pH、缓冲体系和时间窗内检测；运行配方无细胞空白、介质空白、无底物对照及方法阳性参考。记录回收样本已受口内挑战，不能称为未经刺激的基线菌斑。
11. **数据封存。** 保存原始文件、校准、掩膜、处理参数、样本链和排除原因；完成双人核对及盲态分析后再解盲组别。

如果研究问题是未经挑战的基础代谢，需要另设随机顺序的独立访视或独立匹配牙位；不要在同一 ROI 先取样再测“原始”pH。

## 7. 产酸能力测量与计算

### 7.1 两种不同输出

- 原位 `pH(t)`：反映酸生成、唾液清除/缓冲、扩散和配方自身酸碱性质的合成效果。pH 为对数尺度，无量纲；不能直接换成总产酸量。
- 离体净可滴定酸生成速率 `R_net`：例如 pH-stat 在固定设定点下测得的碱耗量，扣除匹配无细胞空白；是该检测条件下的操作性指标，不等同于所有代谢酸总量。另用经验证的乳酸或其他有机酸检测交叉核验；单测乳酸不能代表所有酸。

pH-stat 示例计算定义（不是试剂配制说明）：

`n_net(t) = C_base × [V_sample(t) − V_blank(t)]`

若浓度以 mol/L、体积以 L 计，结果为 mol；乘 10^6 转为 µmol。使用同时间点、同基质空白；预定义线性时间窗拟合斜率，得到 `R_net`（µmol H+ equivalents/min）。记录设定点、有效体积与稀释因子。分析小份时先按其占整个回收液的比例换算；无法证明均匀分样时不得外推到整个 ROI。

空白扣除后的负值保留并检查误差/净碱化，不能强行截断为零。非线性曲线报告完整时间过程或预定义分段速率，不能挑选最有利斜率。

### 7.2 面积、清洁与回收

`coverage_pct = 100 × plaque_pixels / evaluable_tooth_pixels`

`removal_pct = 100 × (A_pre − A_post) / A_pre`

前后需相同 ROI、有效区域和面积定义。`A_pre` 低于定量限时，移除比例为缺失并附原因；清洁后面积增大时保留负值并复核成像。二维投影面积只能标记为投影面积；转换 mm² 需要经过校准的尺度和几何方法。覆盖百分比不是菌斑重量或厚度。

`recovery_fraction = recovered_reference_amount / known_input_amount`

回收率先在台架用可追溯输入量或经验证物质平衡测定；不能仅用前后图像面积推断回收到管中的生物量。应分别验证总量回收和活性保持。只有回收校正已验证且适用于该样本时，才报告校正估计，并保留未校正结果。

`R_area = R_net / A_pre_mm2`

此值应称“每单位采样前菌斑面积的回收样本净产酸速率”；未经回收校正不能称为牙面真实总产酸强度。分母须超过面积定量限；缺失/零分母不加 epsilon、不替换成 1。面积百分比只能另报“每覆盖百分点”，不可冒充每 mm²。可另按回收生物量标准化，作为不同的次要指标。

## 8. 曲线、统计与解释

必备输出：

1. 同一牙位的 pH—时间曲线，标记挑战、干预、取样和缺口；不同测量对象分面。
2. 菌斑面积—净产酸速率散点图，组别着色、参与者/供体配对可追溯，显示不确定性。
3. 清洁前后覆盖及回收率/活性保持结果，分别报告。
4. 可选单位面积速率分布；不能仅凭比值相关性断言机制。

pH 次要终点包括最低值、下降幅度、恢复至预定基线容差所需时间，以及 `integral max(0, pH_reference − pH(t)) dt`。后者单位为 pH·min，是预定义参考线以下的酸化暴露代理，不是酸的摩尔量，也不是通用龋病阈值。参考线、恢复容差和持续时长需预注册；未恢复标记右删失，不能填零。缺口超过上限不跨越插值积分，报告有效覆盖时间。

面积与产酸先作散点探索；只有数据支持才拟合非线性。以供体/参与者为生物学重复，牙位和访视属于嵌套/重复测量，不能把每秒 pH 读数当独立样本。技术重复先按预定规则汇总。正式比较可用参与者随机效应模型，含面积、木糖醇、尼古丁及其交互项，并报告效应量与置信区间。面积是处理后变量时，面积调整结果与总体处理效应分别解释，不自动作因果结论。

样本量根据先导研究的方差、组内相关和最小有意义效应确定；不预填任意人数。预先固定主要终点、排除规则、多重比较策略、缺失机制分析和盲态步骤。小样本先报告可行性与不确定性。

## 9. 质量控制、停止与故障处置

| 问题 | 处置 |
| --- | --- |
| 探头松脱、疼痛、出血或封装损坏 | 立即停止口内测量，由牙科人员检查并取出器件；记录事件 |
| 校准失败或测后漂移超标 | 保留原始数据并标记无效；不可用于主要 pH 终点 |
| 唾液/血液/牙膏污染 | 标记类型与程度，依预先规则排除或分层；不要改标为纯菌斑 |
| 样本少、面积低于定量限 | 原始值保留；派生比值为缺失及原因 |
| 运输超出验证条件 | 不用作活性主要分析；分子结果也需其自身质量要求 |
| 传感器菌斑与天然菌斑不一致 | 分开报告，不用一个替代另一个 |
| 显色剂干扰或无法可靠分割 | 暂停同位点联测，先完成方法验证或采用明确标记的独立设计 |
| 人体研究同意撤回 | 按同意书和机构方案处理停止、已采样本及数据，留存审计记录 |
