# 点解分推叫 131、41，唔叫 12111？

提问与创意：吴孟城（Windy Wu）  
整理：AI 辅助  
日期：2026-11-07

## 一句问到教练落场

> 「老婆，点解 LPL 分推叫 131 和 41，不叫 12111？」

哈哈，因为呢啲数字数嘅系「分成几组，每组几个人」。

| 叫法 | 人数 | 通常意思 |
| --- | --- | --- |
| 131 | 1＋3＋1＝5 | 上下边线各一人，中间三人形成主队 |
| 41 | 4＋1＝5 | 四人一起施压或牵制，另一人边线单带 |
| 12111 | 1＋2＋1＋1＋1＝6 | 若每一项都代表互不重叠的一组人数，就多咗一个人 |

「老婆，教练都落埋场啊？」😂

呢句系人数加总产生嘅玩笑，并非真实比赛事件。131、41 系《英雄联盟》常见分推简称，唔系 LPL 独有，亦唔系上单、打野、中单、ADC、辅助五个职位嘅编号。41 描述四人主队加一人单带，唔固定规定主队一定喺中路。

## 三个人唔使贴住企

如果想讲「两边各一人，中间两人，另一个喺附近野区接应」，人数就系 1＋2＋1＋1＝5。呢种写法可以用嚟描述某一刻嘅位置，但必须先讲清楚每一项代表乜，唔应当作一个已经约定俗成嘅战术名称。

当野区嗰个人持续围绕中间两人做视野、保护或接应，仍然可以用 131 概括整体分工。判断依据系实际牵制与支援关系；单凭「有人喺附近野区」并不足以断定系 131。人员转线、回城、抓单时，阵型亦会改变。

因此，战术简称系对整体分工嘅概括，并非五个英雄瞬时坐标嘅完整清单。

## 留给 MotionBricks 的一个表达启示

以下系本次讨论提出的设计类比：描述多人场景时，可以分别记录「角色身份」「当前空间位置」「协作分组」。同一个角色可以离开队友几步去接应，而仍然属于同一协作组。

如果未来制作五角色分组示例，应检查每个角色在同一分组层级只被计算一次，而且各组人数之和等于参与人数。这个文档只记录表达方法，未新增游戏控制器、分推算法或多人运动执行功能。
