## 作者原话

> 中国参与“极光行动”驱逐谷歌的黑客本质上是在背离改革开放政策。以非法的形式、非法的行为行事，就算结果可能短期内显示是正义的，其实是不正义。

原话逐字保留于 [original_statement.txt](original_statement.txt)。其中“中国参与”及“驱逐谷歌”属于作者对事件的概括与评价；下文分别列出公开归因和业务调整的证据范围。

## 宣言正文（依据作者观点拟写）

我反对以所谓正义的结果，为非法的手段开脱。

对于参与“极光行动”的行为者，凡经证据证明实施了非法侵入、窃取资料或其他违法行为，就应当承担与其行为相应的责任。技术能力、政治立场和国家身份，都不能成为免于追问的理由。短期内取得利益，不能把违法行为追认为正当；自称维护国家利益，也不能代替对行为本身的审查。

我认为，损害跨国技术交流与合作信任的非法网络攻击，背离了改革开放应当坚持的开放、交流与可信规则。中国的发展需要有能力参与世界，也需要让合作能够建立在可预期、可追责的规则之上。把破坏这种信任当作功劳，是对改革开放方向的伤害。

即使某种结果在短期内被描述为“胜利”，也必须追问：它以什么方式取得？谁的权利受到侵害？谁承担了代价？行为者是否接受与他人相同的规则约束？结果的宣传，不能取消这些问题。

因此，我的判断是：以非法的形式、非法的行为行事，不能仅凭短期结果看似正义，就获得正义之名。对于经查证的违法行为，应当依法调查、公开说明并追究相应责任；对国家与公共利益的辩护，也应当经得起事实与程序的检验。

以上为作者立场的扩写，未被标为作者逐字原话。“背离改革开放”是本文的政策伦理评价。
