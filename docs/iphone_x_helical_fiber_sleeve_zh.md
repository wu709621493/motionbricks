# iPhone X 螺旋纖維套：簡短概念

創意：吳孟城（Windy Wu）；AI 輔助整理。日期：2026-11-08。

> 經典值得欣賞，也值得保護。戴個套，係常規操作。

## 構想

以 iPhone X 為造型對象，提出可拆式螺旋纖維手機保護套。這是設計草案，尚無實物、力學模擬或性能測試，也不是 Apple 官方配件。

## 結構提案

- 內層：柔軟、可清潔的接觸襯層，設計目標是避免纖維直接磨擦機身。
- 中層：纖維帶沿手機長軸左右旋交叉纏繞，形成雙向螺旋網；纖維端部包覆固定，不留下鬆散線頭。
- 外層與四角：以柔性包邊固定網層，四角預留緩衝結構；螺旋紋理同時作為外觀元素。
- 開口：保留螢幕、鏡頭、按鍵、充電口、揚聲器及麥克風位置；尺寸與公差須依實機量測後確定。

## 第一版候選

先以聚酯纖維編織帶與 TPU 邊框作為打樣候選。比較纖維相對長軸約 ±30°、±45°、±60° 的排列，角度僅為試驗變量，未認定最佳值。矩形機身四角的實際纖維路徑需另行調整，不能直接視為圓柱螺旋。

希望藉由纖維排列與柔性邊框協同限制局部變形；是否能分散衝擊、改善握持或延長壽命，均屬待驗證假設。纖維抗拉能力不能直接換算成整機防摔能力。

## 最小驗證清單

1. 使用等尺寸模型檢查裝卸、開口對位、包邊固定及四角翹起。
2. 與相近厚度的普通保護套比較滑移、磨耗及反覆裝卸後的鬆脫情況。
3. 先用配重假機進行相同高度、方向與落地表面的跌落對照，記錄損傷與套體脫落；假機結果不等同真機防護認證。
4. 實機另行檢查充電、溫升、訊號及按鍵操作；不得僅由材料名稱推定相容性。
