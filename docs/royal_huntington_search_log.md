# 王室与亨廷顿病：检索记录

日期：2026-11-03（Asia/Shanghai）。问题：公开资料能否支持一个可核实的王室 HD
患者名单，以及如何在不混淆诊断的前提下描写相关王室人物？

## 方法与纳入边界

先进行中英文开放网页检索，再到论文原站、PubMed/PMC、皇家档案及博物馆机构
交叉核验。使用两个搜索引擎；第二引擎出现大量 Huntington 姓氏、收藏馆和 Monarch
数据库的无关命中，随后以第一引擎和疾病全称复核。没有执行完整的 PubMed/Embase
数据库系统综述，也没有调查私人病历；不报告虚构的数据库去重数量或 PRISMA 流程。

证据优先顺序：个人明确诊断/分子证据 → 个案原始研究 → 原始历史假说论文 →
档案机构和博物馆的说明。疾病科普只用于定义疾病，不能作为人物确诊来源。
搜索摘要只在标明阅读深度后使用。未确认确诊个案时仍保留空列表，不用新闻人物
性格评语或家系图填充。

## 实际使用的检索式

以下记录本次检索式与用途，不把未返回相关结果解释成不存在病例。

## 结果与限制

本次未核实到可纳入的王室 HD 患者。选择亨利八世、乔治三世、克里斯蒂安七世和
阿列克谢作为四个**鉴别/证据分层案例**；另记录亚历山德拉与维多利亚的家系角色。
并非声称这四人是“全部疑似王室 HD 病例”，也不声称每人都曾被正式怀疑患 HD。

明确排除作为 HD 证据的项目：Huntington 姓氏、亨廷顿图书馆、Royal 医院/学会、
姓 King 的患者、Monarch 生物数据库、影视情节、政治评价、其他疾病的基因检测。

全文读取的缺口：GeneReviews 打开遇到验证码、NINDS 页面遇到 403，未把这些失败
说成阅读全文；一般疾病定义采用成功读取的 MedlinePlus 页面。PMC 的乔治三世论文复查遇到验证码，改从 PLOS 原站读取正文。部分历史论文仅读
摘要，已逐条标记。没有对欧洲以外所有王朝、所有语言和未数字化文献做穷尽检索。

如出现新个案，需追加具体名字、身份来源、诊断原文位置及证据层级，再修订记录。
“当前没有核实到”必须与“已证明没有”始终保持区别。
