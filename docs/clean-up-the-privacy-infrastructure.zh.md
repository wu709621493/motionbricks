# 安心如厕行动 · Clean Up the Privacy Infrastructure

我们严厉谴责轮奸等性暴力，呼吁印度中央、各邦及地方政府保障每个人在公共空间乘车、步行、如厕和求助的自由。我们也呼吁韩国公共设施管理者承担防偷拍、接报和支援受害人的责任。两个试点共享一道验收题：一个人需要厕所时，走得到、进得去、锁得上门吗？如果途中遇险或发现偷拍，谁接报，谁到场？

## 两地的起点

印度 2019–21 年全国家庭健康调查中，农村有 25.9% 的住户、城市有 6.1% 的住户属于「没有设施／使用户外空地或田野」一类。这个历史指标反映住户的处境；选址仍须实地核对今天哪些村落、街区和时段缺少可用厕位。2017 年，昌迪加尔一名女子搭乘机动三轮车后被带到林地遭轮奸，三名被告于 2018 年获判终身监禁。我们将交通、求助和厕所一起列入公共安全议程；上述案件没有提供厕所短缺导致轮奸的因果证据。[印度统计部卫生设施表 5.05](https://mospi.gov.in/sites/default/files/reports_and_publication/statistical_publication/EnviStats/ES1_2025_Comp5.pdf) · [昌迪加尔案件判决报道](https://indianexpress.com/article/cities/chandigarh/2017-gang-rape-case-three-sentenced-to-life-in-jail-fined-rs-2-05-lakh-each-5334723/)

韩国警方在 2021–23 年查获 1,457 宗公共厕所非法拍摄案，数字涵盖各类公厕。同期地方政府安装了 1,284 部常设探测设备，国会预算政策处记录经相关设备和巡检查获的案件为零。两个数字的发现渠道不同，无法据此推算偷拍发生率或设备预防了多少案件。设备投入之外，管理者还应交代使用者的举报怎样得到响应。[韩国国会预算政策处预算分析](https://www.nabo.go.kr/board/file/down.do?fid=33318890) · [警方数字及立法报道](https://www.koreaherald.com/article/10818997)

## 公共通道有人负责，厕格内保有私隐

- **补足可用厕位。** 邀请当地女性、残障使用者和清洁人员走访日间与夜间路线，记录开放时间、步行与轮候时间、无障碍通行、供水、照明和门锁。坏锁先修，夜间开放落实值班，确实缺位处再增建。
- **按地点评估公共摄像。** 在车站、候车区、公共通道及公厕外围按风险设置摄像设备，同时提供照明、求助按钮和当值人员。禁止在厕所内部及更衣空间摄录。安装后须在门完全打开时核验外围镜头视野，确保拍不到内部。管理方应公布拍摄范围、用途与保存期限，限定调阅权限，记录每次访问，案件证据按程序保全。系统综述未观察到摄像对暴力犯罪整体有显著预防效果，每处点位仍须安排接警和现场响应。[英国警务学院证据综述](https://www.college.police.uk/research/crime-reduction-toolkit/cctv)
- **接报即处理。** 厕所入口提供电话和文字举报渠道。出现偷拍举报时，由当值负责人封闭涉事厕格、安排替代厕位、联系警方并提供影像下架与受害人支援转介。巡检须清场。报案人可以离场，无需自己寻找镜头或提供录像才获受理。
- **提高法律意识和执法能力。** 以当地语言讲解性同意、旁观者安全求助、报案及就医途径。由司机、车站人员、保安和警方一起演练。报案人应获回执及后续联络方式，拒绝登记、施压私了、泄露影像等投诉应可交由独立渠道复核。印度已有跨邦调查记录警方施压撤案或私了的个案。[人权观察调查](https://www.hrw.org/report/2017/11/08/everyone-blames-me/barriers-justice-and-support-services-sexual-assault-survivors)

## 九十日社区试点提案

建议印度、韩国各由一个有意参与的社区与设施管理方试行。第一个月走访并记录基线；第二个月维修设施、演练接报；第三个月由使用者复查。公开开放时段内可用厕格比例、坏锁修复时间、接报至到场时间、按程序保全录像的情况及投诉处理结果。仅发布汇总数字，避免从小样本识别受害人；记录举报渠道的变化，解释案件数字升降。

我们亦倡议印度按案发地分别公布城乡强奸立案数、人口分母及立案率，并以自愿、保密、有代表性的调查估算受害经历与漏报。受害者现居地和案发地须分别标明。警方统计反映已登记案件；全国总数减去部分大城市，余数仍含中小城镇，无法据此还原自 1956 年起的城乡案发率。[印度城乡强奸统计方法研究](https://publications.azimpremjifoundation.org/289/1/Urban-rural%20incidence%20of%20rape%20in%20India_myths%20and%20social%20science%20evidence.pdf)

**人人都应该有一道闩得埋嘅厕格门。门入面嘅私隐属于使用者，门外面嘅维修、巡查同问责属于管理者。**
