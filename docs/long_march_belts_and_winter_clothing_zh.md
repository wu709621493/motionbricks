# 半截皮带，半截旱烟

小时候读长征故事，容易记住两样东西：锅里煮着的皮带，雪地里一个老兵指间夹着的烟。多年后重读，值得分别追问：皮带是谁留下的？夹烟的姿势是谁写下的？讲完牺牲之后，还有谁该回答棉衣和口粮的问题？

## 草地上的皮带

旧人教版小学语文《草地夜行》写道：“干粮早就吃光了，皮带也煮着吃了。”这句话交代了一个小战士为什么已经走不动。至于把皮带切开下锅，另有具体的人和实物可查。1936年7月，红四方面军再过草地，战士周广才所在的班断了粮。后来的记述写到，战友把他那条皮带的一部分切细煮汤。留下的半截由周广才保存，背面后来烫上“长征记”三个字。国博的藏品说明记下了皮带的来历和保存经过；切丝入汤的细节见于关于这个班的叙述。[《草地夜行》旧课文](https://news.sina.com.cn/z/changzheng70/cdczkw/index1.html) · [中国国家博物馆藏品说明](https://www.chnmuseum.cn/zp/zpml/gmww/202105/t20210531_250098.shtml) · [《长征路上的两条半截皮带》](https://cpc.people.com.cn/n1/2023/0904/c443712-40069937.html)

## 雪地里的旱烟

李本深的《丰碑》写一名冻死的老战士靠着树干坐着，右手还夹着半截纸卷的旱烟，左手伸出去，像是找人借火。带队的指挥员见他衣服单薄，动怒，要见军需处长。战友这才说出，眼前的人就是军需处长。另一篇课文《金色的鱼钩》里，照料三个病号、钓鱼熬汤的炊事班长，才是读者熟悉的那位“老班长”。[《丰碑》课文节选](https://ep.ycwb.com/epaper/ycwb/html/2026-10/28/content_2977_770286.htm) · [《金色的鱼钩》课文](https://file.xdf.cn/uploads/200401/1113_200401214528h7g4aQ727vDcK5zq.pdf)

李本深在《军需处长的丰碑》里交代了故事的来源。他在江西兴国采访期间，听一位老首长说，红军过雪山时冻死了一名负责棉衣的军需处长。作者坦言，自己也不知道此人的姓名。这段回忆能让读者追溯小说的由来。至于右手夹烟、左手像在借火，能核对的是课文里的描写；目前所引材料没有提供独立的现场记录来印证这个姿势。[李本深谈《丰碑》的写作经过](https://paper.people.com.cn/rmrb/pc/content/202610/21/content_30186810.html)

## 军礼之后，谁来回答棉衣的问题？

> 我认为😤modern warfare reflects badly compare to these

这句读后感，把我带回《丰碑》里揭晓身份之前的那一刻。指挥员眼前只有一个穿得太少的士兵。他还不知道这个人是谁，就已经要找负责发棉衣的人。后来他知道该向谁敬礼了，可是先前那个问题仍然成立：这个兵为什么没领到足以御寒的衣服？换作一个谁都叫不出名字的普通士兵，这个问题也该问得一样重。

拿这件事衡量现代战争，我想问两个具体问题。一支军队能远远看清一个目标时，谁能及时看见自己队伍里那个快要冻僵的人，又有谁能把棉衣送到他手里？当屏幕上的一栋楼已经清晰可辨，楼里还有没有平民，由谁查清？在答案仍不确定的时候，谁有权叫停，又有谁肯承担叫停的责任？

皮带值得保存，因为它让后来的人知道，当年有人饿到了什么地步。军需处长也值得记住。我希望下一个管棉衣的人有足够的棉衣发给每一个兵，包括他自己。
