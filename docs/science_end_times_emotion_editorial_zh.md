# 别把不确定性藏进附录，把末日写上标题

构思与核心观点：吴孟城（Windy Wu）  
整理：ChatGPT / Codex，依据本次对话，2026-11-10  
文体：中文评论与研究问题提案；不是实证研究报告。

> 不确定性不能藏在论文附录里，确定性的口气却铺满新闻标题。

## 从一个科学命题变成公共情绪

这次讨论从一个问题开始：科学家把“全球变暖”做到广为人知，究竟花了多久？

1896年，阿伦尼乌斯对大气二氧化碳与地表温度的关系进行了早期定量研究；1958年，基林开始持续测量大气二氧化碳；1988年，汉森在美国国会作证，全球变暖成为头版议题，同年 IPCC 成立；1992年，《联合国气候变化框架公约》开放签署。[1–3]

以1988年为传播转折点，从1896年算是92年，从1958年算是30年。这只能说明理论、观测与公共议程之间的时间跨度，不能把整段历史都算成有组织的宣传，也不能把美国的新闻转折点当成全球每个人同时知晓的日期。

一项2015年发表、采用2007—2008年119国调查数据的研究发现，北美、欧洲和日本的气候变化知晓率超过90%，但全球仍约有40%的成年人没有听说过这一概念。[4] 这是历史调查结果，不是2026年的现状。听说、理解、认可与采取行动，也必须分别衡量。

## 曲线有历史，模型有边界

“人类人口增长是 S 形”同样需要拆开。Verhulst 于1838年提出 logistic 人口增长模型；Pearl 与 Reed 在1920年用曲线研究美国人口增长。[5–6] 到2026年，这两个节点分别已过去188年和106年。

S 形是一类形状，经典 logistic 是其中一种模型。在通常的正增长参数、初始人口低于承载上限的设定下，人口向固定上限靠近。人类技术、资源利用和生育行为会变化，某段曲线拟合良好，不足以证明人类永远遵循同一个固定参数模型，更不能直接读出“地球最终能养活多少人”。

联合国2024版预测是全球人口在2080年代中期达到约103亿，随后到2100年回落到约102亿。[7] “达峰后下降”已经不同于经典 logistic 的单调趋近平台；这些数字仍是预测，不是人口命运的判词。

Pearl 与 Reed 的原文开头就指出，经验拟合本身不能揭示或证明底层增长规律。[6] 百年前的提醒，今天的新闻标题仍然用得上。

## 谁的末日，什么的终结

吴孟城在讨论中提出：

> 对于每个人来说，“末日”意味着什么，其实基于你相信哪个结局；“末日”的画面很不一样。

这是一项关于意义与价值的观察。人类物种灭绝、文明知识失传、宗教中的审判与救赎，以及个人体验中的“世界崩塌”，并非同一个事件。这里比较人怎样理解未来，不把宗教文本与科学模型的证据资格混为一谈。

按现代历史研究的常见断代，《但以理书》7—12章的末世异象约成于公元前167—164年；《启示录》现有形式通常定于公元1世纪末。[8–9] 这些是文本形成时间的学术判断，不等于故事发生时间，也不是末日日期。《马太福音》24:36强调人不知道那日子与时辰。[10]

另一组时间并置也值得记住：哥白尼在1543年出版《天体运行论》；“五月花号”的朝圣者于1620年抵达北美；清教徒大规模移民马萨诸塞湾始于1630年，两者分别晚77年、87年。[11–12] 朝圣者中的分离派与仍希望改革英国国教的清教徒应作区分；当时也还没有今天的美国国家。

这一时间顺序说明科学革命与宗教社会生活存在重叠，不能据此推断移民个人是否接受日心说，更不能推断天文学已经回答宗教救赎问题。

## 两到四年的情绪影响：把直觉写成可检验的问题

吴孟城提出：“科学、宗教文献对短时间限度（2—4年）内人类的情绪有着巨大影响。”

本文保留这项原创判断作为研究出发点，但“巨大”与“2—4年”都尚未由本次讨论中的数据证实。我们没有完成系统文献综述，也没有收集情绪随访资料；不能把未核验写成已有证据，也不能反过来断言相关研究不存在。

可检验的版本是：

**科学与宗教文献所提供的未来图景，可能通过改变人对安全、意义与行动价值的预期，影响其随后2—4年的情绪轨迹。影响的大小、方向和持续时间，需要分别测量。**

这里先把2—4年定义为拟议的观察窗口；它不等于单次阅读必然产生如此长的效应，也不等于文本中的事件将在这段时间发生。

| 需要区分的问题 | 拟议的研究处理 |
| --- | --- |
| 是原文还是传播包装产生影响？ | 分别记录直接阅读、新闻标题、短视频和社群讨论的接触 |
| 影响是恐惧、希望，还是行动感？ | 分别记录情绪与行为，不预设只能造成负面影响 |
| 是文本影响情绪，还是原有情绪决定阅读选择？ | 记录基线状态并进行纵向随访；观察关联不直接写成因果 |
| 是持续效应还是反复刺激？ | 区分单次接触、重复报道和同期现实事件 |
| “巨大”究竟多大？ | 预先定义主要指标、效应大小和不确定区间，报告无效或反向结果 |

上述为研究设计建议，未实际开展。可信的风险信息可能令人不安，也可能促进行动；安慰性叙事可能带来希望，也可能降低警觉。具体方向应由资料回答。

## 某些“科研贩子”，确实该收敛一点

“科研贩子”在这里是对夸大传播行为的讽刺，不是对某个研究者或机构的事实指控，也不是给整个科研群体贴标签。批评应落到可核查的行为上：

- 把有条件的模型情景说成无条件、必然到来的未来。
- 把初步结果或单一实验包装成已经完成的临床突破。
- 把论文中的“可能”“尚待验证”从标题中删除。
- 用极端后果吸引注意，却不给概率、时间尺度和适用范围。
- 用公众的恐惧或希望推动募资与流量，却不清楚说明利益关系和证据限制。

这些是本文提出的判断标准，不是已经查实的个案清单。研究需要经费、传播需要让人看懂，本身都不等于欺骗。严肃报告风险也可能引发不安；“令人害怕”不能单独成为判定夸大的依据。

责任首先在于让措辞与证据相称：预测就说明条件，风险就说明时间范围与不确定性，初步结果就保留“初步”，受到可靠质疑就公开修正。传播者不能一边享受确定性带来的注意力，一边在问责时退回论文角落里的限定语。

我们主张：**结论有多大的证据，宣传就承担多大的边界。**

粤语讲一句：**有几多证据，就讲到几尽；唔好正文写“可能”，标题就写“玩完”。**
