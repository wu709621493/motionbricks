# 轨道温泉村：三日两夜清仓价

粤语广告小品及设计札记 · v1.0 · 2026-11-27。构思及叫卖原句：吴孟城（Windy Wu）；广告对白：AI 按对话续写。以下系虚构广告，并非实际旅游产品。

> 太空温泉卖啦卖啦，温泉村三日两夜一千万美金清仓价啦

## 广告原文

♨️ **轨道温泉村开卖喇！三日两夜，一位一千万美金，清仓价呀喂！** 😏

一人一缸，绝不搭枱。浴囊写你个名，水温由你定。地下温泉话自己「依山傍水」，我哋间房冇山景，间中成个喜马拉雅山脉由窗底经过。

有客问：「你哋啲温泉补唔补钙㗎？」  
前台：「先生，一千万系房价。补唔补到钙，份论文未出，唔敢收你嗰份钱。」

另一位细细声问：「我身体冇人哋咁好，系咪唔使报名？」  
前台推张凳俾佢：「坐低慢慢倾。安全要求逐项睇，呢度唔系拣奥运代表。你惯用左手定右手？我哋帮你将浴囊个扣装喺顺手嗰边。」

**轨道温泉村——人向往星空，唔一定为了征服宇宙。有时只系想收工，浸个靓水。**

## 点解个扣要装喺顺手嗰边？

提议者喺对话中写道：

> 甚至可以一缸水跟一个人😏连洁癖问题都解决

> 我地要尤其记得gattaca噶启示：唔需要身体上superior先可以上天

呢两句落到设计上，就系每人有自己嘅浴囊、水唔共用；个人用水一样需要清洁同回收。出口应当俾使用者用惯用手操作。安全要验证嘅系「呢个人用呢套设备能否顺利退出」；如果换个扣就做得到，就改个扣。

## 「房价包唔包钙？」背后嘅研究问题

- **已发生：** [Skylab 乘员用过暖水淋浴](https://www.nasa.gov/mission/skylab-2/)，以围帘收水、真空抽走。乘员喺[任务报告](https://ntrs.nasa.gov/api/citations/19750017465/downloads/19750017465.pdf)提到收水同弄干设备耗时。呢个系淋浴先例，并非在轨浸泡矿泉或补钙成功。
- **舒适度提案：** 先由清醒乘员试可随时退出、有二次收集嘅四肢局部暖浴，同暖湿巾比较舒适度、用水量、收拾时间同再次使用意愿。即使补钙结果系零，舒适度仍然值得独立评估。
- **补钙假设：** 四团液滴分别接触手脚；同时量体积同平均离子浓度，先分清蒸发同盐量变化，另设无皮肤空白、回收皮表残留。液团少咗钙唔等于钙入咗血，入血亦唔等于入骨。[离体人皮研究](https://pubmed.ncbi.nlm.nih.gov/15080493/)见到钙离子通透；[和平号稳定同位素研究](https://pubmed.ncbi.nlm.nih.gov/15647814/)测嘅系飞行期间钙代谢，两者都唔系太空浸浴补钙试验。将来要问浴液嘅钙有几多进入人体，可研究用稳定同位素示踪。
