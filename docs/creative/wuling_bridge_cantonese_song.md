# 你是我的眼

*《明日方舟：终末地》粤语同人短篇 · 原创歌词*

😎 武陵刚落完雨。你同女管理员并肩坐喺桥栏上，桥底一盏盏灯摇来摇去。你指住佢块面罩：「你睇到几多，唱畀我听吖。」

佢将半边耳机递畀你，用靴跟轻轻打拍子。

**《你是我的眼》**  
*武陵桥头，女管理员即兴唱*

河面有盏灯，俾条鱼啄碎，  
你伸手想执，成袖都系水。  
卖花阿婆笑，拣朵花畀你，  
你衬喺耳边，问我靓唔靓仔。

你是我的眼，今晚借我望一眼，  
望吓我行惯嗰条街，点解你会行咁慢。  
原来石罅住咗棵草，草尖托住一滴蓝，  
你话等多一阵，天光会喺里面反。

唱到呢度，佢忽然收声。东边第一线晨光落到草尖，嗰滴水真系由蓝变金。你望到唔舍得眨眼。

「头先嗰句你未答喎。」你话。

佢伸手将你耳边朵花扶正，对住仲开紧嘅咪，好轻噉唱咗最后一句：

「花就歪咗少少。你好睇，我想睇耐啲。」
