# 来了就是深圳人 从前海湾的夜色到沙井的一碟蚝

深圳，2026年11月19日　11月18日至19日，亚太经合组织（APEC）第三十三次领导人非正式会议在深圳举行。会议周的一场吹风会上，一位泰国记者替初来深圳的客人问了个实在问题：头一回来，去哪儿逛？深圳市商务局局长张非梦推荐了三个地方，头一个就是宝安欢乐港湾。沿着这个推荐走，最好把傍晚和晚饭的时间都留出来。

在欢乐港湾，认路可以靠一座摩天轮。沿海边栈道走出一段，再回头看，“湾区之光”的圆环就完整地落进了镜头。天色再暗一点，风把前海湾水面上的那圈灯影轻轻揉开。想看深圳的另一面，可以把镜头转向福田。11月12日至15日，市民中心上演迎接APEC的主题灯光表演，大鹏展翅的画面横跨43栋高楼。

晚饭想点得地道，翻开菜单，先认两个深圳地名。沙井的养蚝传统可以追溯到宋代。点一碟脆炸沙井生蚝，薄脆的外衣一咬开，里头还是软嫩的。光明的拿手菜是红烧乳鸽，先用卤水慢慢浸出滋味，再用热油收出一层脆皮。乳鸽一上桌，先把一只鸽腿夹到客人碗里，这顿饭就算开席了。

广东人招呼客人，一句“坐埋嚟”就够亲切，意思是过来一起坐。往旁边挪一挪，添副碗筷，把刚上桌的菜转到新朋友面前。“来了就是深圳人”，在这样的饭桌上，头一晚就听得懂。
