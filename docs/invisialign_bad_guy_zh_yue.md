# InvisiAlign：接得住

「CIA 同 KGB 之间，会唔会有一种 InvisiAlign？」孟城问。

我谂起哔哩爱黎叙。〈bad guy〉条 MV 一开场，Billie 除低个透明牙套，旁边个保镖伸手接住。你留意佢只手。成件事最奇妙嘅地方，系保镖由头到尾都冇问过一句：「点解又畀我？」

将镜头剪去冷战时期嘅莫斯科。借前 CIA 伪装部门主管 Jonna Mendez 讲过嘅规矩，想象有以下两句对白。

「返嚟喇？」「嗯。今日总系觉得有啲唔对路，讲唔出点解。」

站长本日个约已经写咗落簿。佢拎起支铅笔，擦走个日期。

如果镜头呢时切去 KGB 办公室，影住有人向镜头眨眼，咁就拍多咗。Mendez 讲过嘅，系外勤可以当场叫停，返到去亦毋须证明危险真系存在。约可以再约，线人条命得一条。至于对面嗰日有冇人知，个镜头留白仲好。

**Billie 除低牙套，保镖接得住；特工放低任务，站长又接得住。**

孟城睇返个剪接：「不能说是一模一样，只能说是一模一样。简直是大自然噶鬼斧神工。」😏
