# 叼爆好莱坞：畀只丧尸三秒钟

> 日式恐怖交给好莱坞简直是轧屎

吴孟城观影原话。以下讲《生化危机》Alice 真人电影系列。

Alice 同 Ada 确实好睇。配乐一响，嗰阵冻冰冰嘅惊悚味亦确实对路。第一集条激光走廊，到今日我都仲记得自己几咁热心：第一道光横过嚟，我喺银幕外面替人嗌「趴低！」到成幅光网过嚟，我即刻收声。导演识拍㗎。最惨就系知道佢哋识拍。

第三集《灭绝》，有只丧尸拎起相机，帮两个实验员影相。跟住玩细路仔嗰款形状配对盒，积木塞唔入，发起脾气，扑向实验员。孟城评保护伞：「遗传学上的天才，行为学上的笨逼」。成场戏最似人嗰下，可能就系塞极都塞唔入嗰阵。你试下戴住手铐砌积木，隔离仲有两个同事一路睇一路写，睇下你忍到几耐。[第三集实验室原片段](https://www.youtube.com/watch?v=F4vC93arIJk)

保护伞肯承认揿快门有意思，因为呢个动作可以写入实验结果。到佢挣扎，同一班人又肯唔肯听成一句「我唔想玩」？咬人足够叫停实验，动机就仲有排拗。更加值得问嘅系，佢有冇办法讲「痛」或者「停」，而房入面边个人有权即刻开门？电影可以将呢个难题拍畀人睇。真要攞人做研究，参与者嘅意愿、风险同退出点安排，都要有人交代。[国家卫健委对研究伦理审查办法的解读](https://www.nhc.gov.cn/qjjys/c100015/202302/687d51e0d215464590b87d7e2246c720.shtml)

去到第四集，威斯克喺船上养咗两只「百裂冥犬」——孟城帮佢哋改嘅花名。狗头一裂开，戏院有人「哗」一声，好，呢张飞有交代。至于上集张相影成点，已经冇人得闲问。[第四集威斯克与变异犬原片段](https://www.youtube.com/watch?v=8ZEXGUczkiY)

### 保护伞预算会（二创）

「上次畀丧尸咬嗰单，行为组有咩建议？」

「先搞清楚佢点解咬人。」

「遗传组呢？」

「我哋可以令只狗个嘴开大一倍。」

威斯克签字。「批。我要两只。」

### 如果第三集迟三秒先剪（二创）

两个研究员影完合照，低头睇个玩具盒。只丧尸仲举住部相机。左边嗰个行开半步，镜头冇郁。右边嗰个侧一侧身，镜头就跟住佢。研究员听见第二下快门，先至抬头。

到呢度剪走，我返到屋企都会谂：佢认得嗰个人？

玩原作嗰阵，最肉紧往往系手搭住门柄嗰下。背包净返三粒子弹，门后有声，而我要搵嘅嘢偏偏响入面。后期电影畀得起钱整到只狗个头裂开，我只系想佢悭返少少，畀只丧尸三秒钟。
