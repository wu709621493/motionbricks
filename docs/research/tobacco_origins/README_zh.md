# 全球烟草与雪茄产地、溯源及传统药用证据目录

版本：0.1.0；检索截至2026-11-14（北京时间）。研究倡议与讨论：吴孟城；资料整理与核对：Codex。此为研究目录与规范提案，不是已发表论文、疗效认定或完整全球烟田普查。

## 主张与工作顺序

先把原料产地标注和加工审核做实，再研究发表与传统技艺保护，最后讨论药理。把**种植地、加工地、卷制地、品牌归属、出口地**分别记录。来源未知就保留未知，不用品牌地名填空。

用户原话（本次讨论，按原文保留）：

> 至少原料产地标注要做的好，然后加工规范应该严格审核，甚至可以考虑发技术论文或者申遗。之后再考虑药理

> 我们可以有两个有趣的对照组😘一是雪茄；二是：如果我们用乙醇萃取烟草做成烟草酒呢？第二种情况尤其适合中医药理对照讨论

研究解释：雪茄与实验室乙醇提取物作为比较体系。后者涉及尼古丁经口中毒风险，本档案只建立化学和药理文献分类，不提供饮用配方、提取操作或人体自试方案。[P02/H01]

## 当前可支持的结论

产地影响与产地识别已有实证研究，不能声称全领域忽略产地。尚需验证的是：在限定品种、年份、叶位和工艺后，产地可解释多少化学与感官差异，以及这种差异在提取、发酵、燃烧和混配后如何变化。[L01–L15]

本版没有实施采样、仪器分析、盲测、药理实验或复现论文模型。产地真实性、风味偏好、毒性和药效是不同终点。
