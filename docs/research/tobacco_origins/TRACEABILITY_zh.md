# 产地假说、溯源与加工审核

## 把理论写成可检验的问题

用户提出：香烟中大量有机分子有多少由产地影响，口味作用是否明确？本目录保留这个研究方向，同时校正“所有烟草论文忽略产地”的过强表述。已有代谢组、稳定同位素、元素和近红外研究。[L01–L08]

分别定义三个终点：物种／品种与地理来源识别；成分变异的解释比例；人能否辨别与喜好度。分类准确率不是产地的因果贡献比例。显著变化的分子数不是它们的感官贡献；LC-MS峰／feature数也不是已确认化合物数。烟叶、烟丝、提取物、热解物、主流烟气分别计数。NCI的“超过7000种”指烟气化学物质，不专指烟叶有机分子。[H02]

建议预注册分层模型：成分或感官终点由产地、品种、年份、叶位、成熟度、农业投入、调制、储存、微生物状态及交互作用解释；农场与批次设为适当层级。先定义“产地”的估计对象：若包括地方工艺，是地域产品体系总效应；若控制全部工艺，估计的是不同的条件效应。不能在两种定义间换口径。

训练／测试按农场、批次和年份分组，不能把同一叶片的技术重复拆到两边。保留跨年份、跨实验室、未见产区和混配样品；必须允许拒识。报告类别平衡、置信区间、混淆矩阵和失败案例，防止只报随机划分准确率。

## 方法对应证据

| 方法 | 能提供什么 | 主要限制 |
|---|---|---|
| 采购、批次谱系及干基质量平衡 | 来源声明的文件链及混配比例 | 假记录需要抽查、盘点及独立审计识别 |
| 植物凭证与基因鉴定 | 物种／品种身份 | 品种可跨地种植，不能单独证明烟田 |
| 稳定同位素与元素谱 | 限定参考集内的地理分类 [L03–L05] | 肥水、年份、污染、加工和混配影响 |
| LC-MS／GC-MS代谢谱 | 成分变化与候选标志 [L01/L02/L08] | 仪器批次、注释错误和加工混杂 |
| 近红外与化学计量 | 快速筛查 [L06/L07] | 品牌识别不等于田块来源；需拒识和外部验证 |
| 气味活性、重组／缺失实验 | 关键香气成分的感官贡献 [L10/L11] | 烟叶气味不等于燃烧烟气体验或健康结局 |

新增提案：消费者端分列主要原料来源、加工／卷制地点、年份与声明依据；监管端保存完整批次谱系、干基比例、添加物身份及用量、检验方法／检出限、留样和召回关系。没有把此提案写成已生效标注义务。商业保密披露尺度应另行讨论。

审核至少覆盖文件真实性、现场与库存核对、计量校准、异常批次处置、添加物变更、污染与农残等适用检测。公开报告应显示未测项目和不确定度；二维码、区块链或化学指纹都不能独立证明原始记录真实。

## 三种比较体系

1. 同一品种多产地、多年、多农场，尽量标准化处理：研究产地与年份效应。
2. 卷烟与雪茄：分开茄衣／套／芯，控制工艺及混配；市售两产品直接比较只能估计产品体系差异。
3. 同批原料的实验室提取物、热解物和烟气：比较成分去向与变化。乙醇空白及相应试剂空白用于分析／体外体系；不转化为饮品或人体品饮试验。

本版不提出自动展开动物或人体实验。若以后确需研究参与者，另写方案并完成相应伦理与资质程序。

## 可发表与技艺保护方向

可形成开放产地元数据目录、跨年溯源基准、加工前后特征传递研究，以及传统技艺的历史／民族植物学档案。正式投稿前需补原始数据、独立验证、资金与行业关系声明，并逐刊检查烟草行业资助政策；不能保证任何期刊接受。

非遗路径先记录具体社区、传承者、工具、地方技艺差异与历史材料，征得参与者同意并明确署名和资料使用边界。保护重真实性、整体性和传承性；非遗、地理标志与质量追溯制度各有不同目的，均不能代替药效或健康认证。[S05/H03]
