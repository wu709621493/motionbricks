# 产地地图册：国家底表与次国家证据

## 使用规则

原料产地不能由品牌、购买地点、出口国或雪茄制造国自动推断。雪茄的茄衣、茄套、茄芯分别追踪；多国混配按部位记录。统计名称沿用数据源，仅是数据身份，不表述政治地位。历史国家不能与继承国家逐年简单加总。[D01]
