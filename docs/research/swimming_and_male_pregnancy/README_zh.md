## 本次保留的思想成果

第一题保留“究极取舍”，但不预设已经存在不可兼得的生理冲突：较高代谢负荷可能带来更强运动刺激，局部热环境却必须独立测量。全身代谢、阴囊表面温度、睾丸内部温度、精子质量和勃起功能是不同变量；需要检验它们之间的连接，才能讨论哪种泳姿更有临床优势。

第二题保留正反双方的强处：自主与平等能够为研究方向提供理由，风险相称与第三方保护则约束具体试验。原本由谁承担妊娠，不应自动决定谁永远有资格承担妊娠；一个成年人愿意承担风险，也不能代替对捐献者、后代和研究质量的评估。这些是本稿的规范论证，不是对任何具体试验签发伦理许可。

## 证据状态

- **已有研究**：有氧运动与勃起功能；泳姿能量消耗；热暴露与精子指标；已有子宫的跨性别男性妊娠；女性子宫移植的活产及风险。
- **待验证推论**：泳姿通过代谢、局部热环境或坚持程度产生不同的勃起功能收益。
- **规范主张**：研究对象不应仅因性别身份被永久排除；人体研究必须证明设计与风险具有正当性。
- **未完成事项**：自由泳与蛙泳治疗勃起障碍的直接比较、温度中介分析、无原生子宫男性的人体妊娠验证。本档案不提供已经开展这些工作的回执。
