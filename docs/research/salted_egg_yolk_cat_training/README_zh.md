## 从一块咸蛋黄开始

> 是时候打破猫不能被驯养的myth了😏驯养猫的关键就在于：零乳糖牛奶和咸蛋黄

> 正如孟城所说，😏“胆子有多大，招安的猫就有多大”

> 😏什么鹌鹑蛋什么金枪鱼，太贵了

以上为本次讨论中吴孟城的原话。“招安”是幽默表达；本文将其转为可讨论的行为问题：猫是否愿意靠近人、响应提示，以及完成特定动作。个体训练、亲人行为与跨世代驯化需要分别评价；这里不把一次成功投喂当作驯化证据。

这份构想的主角是**咸蛋黄**。普通鸡蛋、常规猫粮和已有奖励食品可以作为研究参照；鹌鹑蛋或金枪鱼无需成为方案的采购前提。成本优先是作者的设计要求，咸蛋黄在具体地点是否更便宜仍需核算，本文没有报价或采购数据。

## 核心假说

**孟城假说：盐腌加工产生的蛋黄风味与质地变化，可能提高其对部分猫的奖励价值，进而改善特定行为的学习表现。**

需要区分三个递进问题：

1. **接受度**：猫是否主动接近、嗅闻或食用？
2. **奖励价值**：在有选择时，是否更愿意为它完成同一动作？
3. **学习效果**：在一致训练条件下，是否更快学会，并能在后续提示中保持表现？

愿意吃、接近拿食物的人，以及形成稳定的提示—行为关联，是不同的结果。本文没有任何一项的实测数据。“部分猫”保留个体差异，不假设所有猫喜欢同一味道。

原始构想中的零乳糖牛奶保留为另一候选奖励。它与咸蛋黄应分开评价：组合后出现行为变化，不能直接把效果归给其中某一种，也不能默认存在协同作用。

## 下一步值得回答什么

以下是研究设计问题，不是已经实施的喂养流程。

| 比较或变量 | 要排除的替代解释 | 可考虑记录的结果 |
| --- | --- | --- |
| 同一蛋种的普通熟蛋黄与盐腌熟蛋黄 | 蛋种不同、熟制不同或批次不同造成差异 | 接受率、偏好与个体差异 |
| 盐含量与盐腌产生的香气、质地分别表征 | 效果可能来自加工风味、油脂释放或质地，而非“咸”本身 | 钠含量、成分或风味表征；不能从偏好反推机制 |
| 保持奖励时机、训练提示和任务难度一致 | 训练者操作差异造成学习差异 | 正确响应率、达到预设学习标准所需次数、保持表现 |
| 分别评价牛奶、蛋黄与组合 | 不能识别哪一项有效，或是否存在交互作用 | 分开报告各条件结果 |
| 记录轮换次序、饱腹状态与熟悉程度 | 新奇、饱腹、习惯化或顺序造成差异 | 次序、先前经验、拒绝参与和缺失记录 |
| 记录实际用量、价格与损耗 | 单件便宜未必代表每次有效奖励便宜 | 每次奖励成本、每个成功学习目标的总成本 |

日常猫粮可作为成本基线，普通无盐熟蛋黄可帮助识别盐腌加工是否产生额外效果。两者用于比较，不替代本文提出的咸蛋黄问题。

正式研究应预先确定主要指标、样本量依据、顺序安排与分析方法，保留失败和不偏好的记录；不能只汇报最配合的一只猫。本文未确定样本量、投喂剂量或显著性结果。

## 营养与实施边界

咸蛋黄的钠含量、热量和批次差异尚未在本项目中测定，不能直接把人食产品写成日常训练配方。现有蛋类喂养建议使用充分煮熟、不加盐或调味料的蛋，并作为少量零食。[S5] WSAVA建议零食占每日热量少于10%，且不替代完整均衡主食。[S6] 这个热量比例不能单独保证某种食物的钠负荷合适。

若推进涉及食用咸蛋黄的正式研究，应先确定产品成分、总膳食和兽医营养评估，再确定是否适合纳入比较。本文不提供未经评估的剂量，不实施饥饿强迫，也不把猫拒绝参与当作训练失败后需要加码的理由。

零乳糖牛奶的去乳糖处理不能消除所有食物不耐受可能，也不能替代完整主食或日常饮水；相关指导强调其额外热量与营养不完整。[S4]
