# 中国内部迁徙、1979年后赴美迁移与遗传祖源参考 v0.1

更新：2026-11-15。目标：为 All of Us 等队列补充中国历史地理、迁徙机制及区域遗传研究的公开背景资料。**这是本仓库的数据扩展，不是 All of Us 官方数据库更新、认证或已经完成的祖源校准。**

本版包含34项来源、177条可计算观测、17项历史事件、36项地理定义、9项遗传研究分类记录，以及1项福建赴美社区调查路线案例。古代事件为代表性目录，现代省际路线为选取的56条；不声称覆盖全部中国迁徙史或全部1979—2026年赴美流量。

在仓库根目录执行（Python标准库，无网络、GPU或外部包要求）：

```bash
python -S tools/validate_china_migration.py
python -S tools/validate_china_migration.py --summary
python -S -m unittest discover -s tests -p 'test_china_migration.py' -v
```

`--summary` 输出各系列记录数和同口径的描述性计算；不将存量、签证、绿卡或样本人数合并。CI只验证本数据扩展，不运行 MotionBricks GPU 推理。

## 已能支持的结论

2020年跨省流动人口为124,837,153人。31个来源省汇总和31个现住省汇总分别与该数相等，性别分项也逐项相等。表7-3的行是现住省、列是户籍省；例如广西户籍、广东现住者为6,930,342人，四川户籍、广东现住者为2,623,105人。这些是同一时点的户籍—居住关系，不是2020年当年迁移事件，也不等于出生省或祖籍。[NBS20, NBS_OD20]

美国人口普查表中 China 出生类别在1980、1990、2000年分别为286,120、529,837、988,857人。1980年居民包含1979年前迁入者，不能全部算作建交后移民。[CENSUS06]

国务院FY2015—2024年大陆出生归属类别的移民签证签发量依次为39,251、42,069、35,350、29,360、27,541、12,217、18,501、22,108、19,786、26,199。境内调整身份不包含在该签发量中；FY2019方法调整及疫情服务中断也需要标注。[DOS24_XIII, DOS24_METHOD]

## 范围边界

没有访问 All of Us 注册/受控数据，没有移出参与者信息，也没有尝试将族谱、移民档案或公开记录匹配到参与者。没有执行PCA投影、IBD共享、古DNA分析、跨队列重加权或PRS校准。当前成果补充数据语境与可执行校验；不能声称已纠正某位参与者的祖源分类。

历史数量保留原文措辞和单位。`七十余万口`、`数万家`、现代普查人数和签证张数分别保存。空值表示未取得；零仅在来源明确记零时使用。

来源方的文献与数据权利保持原状；仓库提供归一化事实、引用及原创方法说明，不将第三方全文或受限基因组重新授权。
