# 检索范围、实际读取与剩余缺口

截止日期：2026-11-12（Asia/Shanghai）。本次用公开网络检索定位原刊、大学档案、诺奖官网及研究论文，再沿馆藏链接读取材料。主题包括采访、自传性写作、书信、稿件修改、年度记录、录音转录规则、人格判断与拟社会关系。

## 可复核记录

- [来源登记](SOURCES.md)覆盖全部47项被纳入或明确标出访问边界的来源；各自URL、定位及阅读层级见[sources.json](data/sources.json)。
- [search_log.json](data/search_log.json)保存部分实际执行的精确检索批次，是检索路线记录，不是完整网络搜索历史或系统综述筛选图。
- [inventories.json](data/inventories.json)保存Cather采访目录的33个条目和Fitzgerald账簿复合对象的82个数字项目。每个成功抓取项保留访问日期、公开URL、SHA-256、字符数与阅读状态。
- 哈希对应本次读取到的HTML或API响应字节，不是史料真伪鉴定；网站导航变化或动态内容也可能使其改变。没有将受版权保护的全文、图像或音频批量提交仓库。

33个Cather条目中5篇做了有关段落的细读，其余仅抓取和目录编目。82个账簿项目中3页做了细读，其余仅抓取元数据和可用转录。正文没有把两组的抓取范围当作全部人工研读范围。

## 覆盖边界

本次定位并整理了主要公开入口，但未声称找到四位作者“所有数据”。档案存世与开放范围会改变，部分内容仅限到馆、付费、经许可复制或仍在私人收藏；未开展购买、到馆或联系个人。两组集合清单的内部覆盖可以核查，整个文学史资料世界没有已知分母。

尚待推进：

1. 凯瑟全部书信按收信人、时期和文献类型编码；核对未公开、摘要重构、重复件与已上网原件的比例。3118、3125和超过3200的网页统计差异保留为不同口径的未解决项。
2. 海明威完整书信各卷及访谈原稿、不同回忆录版本逐段比对。当前出版社和馆方的说明不能替代本次独立校勘。
3. 菲茨杰拉德账簿转录与扫描原件人工抽查、合同及税务记录独立比对。未计算收入—情绪相关，避免把混合口径收入及回顾性自评伪装成时间序列。
4. 福克纳完整录音试听与同段转录比对、缺带与编选的完整对照。字数及音频分钟不提供心理理解率。
5. 对本次已知答案之外的新任务开展独立编码、真正盲测与预注册分析。

停止条件是本次资料包已经能够具体回答研究问题的层次、提供来源及反例，并明确尚不能验证的部分；它不是宣称搜索已经穷尽。新增档案应按同一规则继续登记。
