## 1. 核心问题及方法

用户提出：“头痛医头 脚痛医脚的做法是不可取的。过去几十年的历史证明了这点”。本文将其作为有待通过具体案例检验的政策判断，不把跨年代的因果关系当成已证事实。

本文提出的分析框架是：局部处置可以必要且有效；如果调查停止在最显眼、最易处罚的一环，制度条件可能继续存在。“选择性追责”须通过可比较案件、责任证据、管辖范围及处理理由验证，不能从没有起诉、改名或政策未落实单独推出包庇。

四个方向共享五项提问：损害是什么；谁有决定和监督权限；已有何种可核实措施；受影响者获得何种救济；是否有后续结果可检验。不预设四类事件规模、法律性质或责任主体相同。联合国A/RES/60/147区分赔偿、康复、满足及不再发生的保障等补救维度，可作分析参照；该文件针对严重侵害，不能不经适用性判断便套用于每次校园争议。[S25]

检索以校方历史材料、审判原文、政府文件、救援组织档案、原始研究为主，辅以档案研究。关键词围绕Millikan/HBF、Nuremberg organizational guilt、COVID stigma/HIV stigma、1939 Jewish settlement China及refugee integration组合。不是预注册检索；没有双人筛选、完整去重或文献质量总评分。来源的自述、摘要、目录说明与原件逐一分开。正文中的评估指标均为建议，未取得新的实测结果。

## 2. 方向一：撤除冠名之后，机构历史是否得到完整公开

### 2.1 已有事实

Caltech于2021年1月宣布撤除Millikan等人的相关冠名，同年11月批准将Robert A. Millikan Memorial Library改名为Caltech Hall。[S01][S02] 校方数字展览记载，1965年申请建筑高度例外许可时已使用纪念图书馆名称，1967年举行落成仪式；这支持“建设阶段已有纪念目的”，不能证明某一张尚未取得的原始蓝图标题栏如何书写。[S04]

校方命名委员会报告认为，Millikan于1937年成为HBF董事，以声望支持该组织，同时明确指出他没有领导HBF、没有制定其政策。报告附录H说明HBF解散后的资产转入Caltech并形成研究基金，亦说明后续用于基础研究。[S03] 这些是校方历史审阅的结论，不能仅凭接受资产或个人关联认定学校直接实施了强制绝育。

HBF的1938年年报自报大量向大学课堂及专业人士分发材料，并叙述与加州州立机构绝育调查的联系。[S05] 这是值得追查的科学权威与政策传播网络证据；自报发行数不等于实际阅读人数或政策影响量。

### 2.2 评价及下一步

本文支持把公共冠名视为可重新审视的荣誉安排，同时保留历史记录。改名是否改善校园体验，需要调查，不能从新名字直接推断效果。制度调查应覆盖命名者、董事、捐赠安排与学校接受资金的决定，避免只围绕一位已故人物完成道德叙事。

优先取得：1959—1967年捐赠协议、命名与建造决议、设计合同、原始图纸标题栏、1967年落成致辞，以及改名后的历史教育实施记录。向档案馆的进一步询问属于后续工作，本文未联系或发送材料。

建议记录：材料目录覆盖情况、拒绝公开的具体理由、历史说明是否同时呈现人物贡献与责任、用户能否从现名找到旧档案。不能为了通过指标而删除原始名称。建筑档案完整保留旧名，现行导览注明更名日期。

## 3. 方向二：处罚执行者之后，授权与监督责任是否被查明

### 3.1 个人罪责与组织犯罪

纽伦堡国际军事法庭《宪章》第6条规定其案件和管辖范围，第7、8条分别处理官职与上级命令，第9、10条涉及组织犯罪宣告与后续个人审理。[S06] 组织判决强调个人罪责、防止集体惩罚，并设置不知情及被强制征入等排除条件；仅有成员身份不足以落入该宣告范围。[S07] 这不意味着每名执行者可免责，也不意味着领导须亲手实施才能负有责任。

加州1909年优生绝育法曾被纳粹法律专家引用为先例。[S08] 加州总检察长2003年公开道歉，州政府后来建立强制或非自愿绝育赔偿项目。[S09][S10] 对不同年代、法律和个案的责任仍需独立调查；道歉与赔偿不能单独证明某个人已被刑事追责，也不证明从未有人被调查。

此前讨论把战后德国概括为“东德、西德、敖德萨三方博弈”，不作为本文历史前提。纳粹逃亡网络与统一强大的ODESSA组织是不同主张；后者缺乏相应证据。[S26] 纽伦堡没有审理加州行为，首先涉及其管辖范围；要判断双重标准，还需查美国国内有哪些调查义务、可用法律、起诉证据与实际处理。

### 3.2 沿责任链取证

| 角色 | 必须取得的材料 | 不得自动推出 |
| --- | --- | --- |
| 实际执行者 | 行为、同意或强迫情况、当时获知信息 | 服从命令即免责 |
| 审批和指挥者 | 指令、审批、会议记录、控制权限 | 有头衔即对全部行为负责 |
| 科学及传播支持者 | 文章、通信、具体支持行为及时间 | 支持过机构等于亲自实施犯罪 |
| 资助和接收资产的机构 | 合同、用途、知情程度、管理决策 | 接收遗产等于继承全部刑事罪责 |
| 监督和司法机关 | 法定权限、收到的线索、调查与不起诉理由 | 没有起诉即故意包庇 |

首选调查对象是加州强制绝育的决策—执行—传播—补救链。以具体机构和时间段建案，分别记录起诉、行政处分、专业纪律、民事赔偿和历史说明。比较案件要控制证据可得性、被调查者是否在世、时效及管辖条件，不以立场一致代替法律要件。

## 4. 方向三：谴责疫情仇恨之后，传播与救济机制是否改变

DOJ/HHS的2022年联合指导记录疫情期间针对亚裔等群体的仇恨事件上升。[S11] WHO的2015年命名建议要求新疾病名称避免地名、人名与人口群体指称，目的是减少不必要的污名；它不是禁止科学讨论地理传播，也不是用于事后重写所有既有疾病名。[S12]

原始研究提供了不同强度的机制证据：[S13]使用2020年8月5,000人的调查嵌入实验，在假想室友选择情境中发现，提升COVID显著性可提高针对东亚裔、南亚裔和西班牙裔的偏见及歧视意向；作者明确没有直接观察实际行为，也不能测出整个疫情的总体影响。[S14]的框架实验报告，将中国与COVID联系起来的表述相较中性表述增加了部分负面态度。本次对后者仅取得摘要；其长期效果、真实暴力及全部政治传播的归因仍未确定。

美国国立医学图书馆记录，艾滋病早期曾将男同性恋、血友病患者、海洛因使用者和海地人概括为“4H”，群体身份与传播责任被混同。[S15] CDC现行科普解释，HIV污名会妨碍检测及获得服务。[S16] 两类疫情可以比较身份污名机制，不能由此认定它们具有同一传播路径、同一政策过程或同一损害规模。

建议分开收集：仇恨犯罪司法认定、警方报案、社区自报、调查中的歧视经历、态度及行为意向。它们不能相加为总发生率。少报、调查覆盖变化及分类变化需记录。举报增加也可能意味着渠道改善，不能直接判为伤害增加。

后续研究宜比较传播框架改变前后、不同地区投诉渠道与语言可及性，以及受害者获得医疗、法律帮助和案件反馈的情况。应预先定义结果、时间窗和对照，尽量检验反污名干预是否真正降低伤害。本文未实施问卷、访问患者或收集个人健康数据。

## 5. 方向四：宣布接纳难民之后，运输与长期安置是否落实

1939年孙科及其他提案者讨论在中国西南安置欧洲犹太难民，云南是主要候选地。Gao Bei的档案研究区分孙科、Berglas及Maurice William的不同方案。[S17] 同期JTA报道提及十万人设想；本次仅取得报道摘要，不能当成政府最终承诺或实际安置人数。[S18]

JDC档案目录的File 458记载其对Berglas方案可行性的负面判断；该目录将省名写作“Hunnan”，不得默改后当成原件已经核实，须进一步调出通信与方案比对。[S19] 本次资料支持存在正式讨论、设想未实现为拟议规模；具体失败原因和权重仍待各机关原件验证。

上海的实际避难与救济是另一个事实层次。JDC记载1938—1939年约17,000名中欧难民进入上海，并提供救济与移民档案线索。[S20] 何凤山签发赴上海签证的救援有见证与纪念机构记录；目的地签证可帮助满足离境手续，不能因上海入境通常免签便说这些签证没有意义。[S21] 当时上海存在租界与日军控制等复杂条件，不应把所有救援简写成一个中央政府统一安置项目。

UNHCR安置手册分别讨论法律身份、住房和就业，提供现代实施维度。[S22][S23][S24] 本次部分网页仅取得搜索可见摘要，打开遇到限流，未声称全文审阅。现代手册可用于设计比较指标，不应把1951年后的制度要求追溯当作1939年中国违反当时法律的证据。

建议分阶段统计：拟议名额、正式批准、实际出发、抵达、取得居留、获得安全住房、医疗和教育、进入自愿就业、后续迁移。每项注明时间和分母。接纳人数不能替代安置质量，就业价值也不能成为人的尊严或免遭迫害的前提。失败原因至少分资金、航运与通道、战争风险、地方治理、国际协调及难民自身意愿，暂不预设单一主因。

## 6. 下一阶段可执行的调查顺序

1. **先做Caltech命名档案个案。**确认原始蓝图标题栏、命名决定、捐赠条件及更名后的历史呈现。离材料最近，也最容易界定事实缺口。
2. **扩展加州绝育责任账本。**按机构、角色、时期、行为和问责形式逐项建档，与既有[纳粹医学实验证据整理](../../nazi_medical_experiments_evidence_zh.md)互相参照，不混同案件。
3. **建立疫情传播与救济文献表。**重点取得原始研究全文、处理条件及结果变量，避免把态度实验写成暴力因果证明。
4. **复原1939年安置方案文件链。**比对国民政府档案、JDC文件、同期报道，分别记录提案、讨论、批准与执行；不将十万人当成接收成果。

此顺序是本文的调查优先级建议，不表示已安排未来任务或联系机构。

## 7. 尚不能作出的结论

- 未看到原始蓝图，不能确认标题栏文字；现有材料只能确认建设阶段名称。
- 未系统查阅美国全部司法及行政档案，不能宣称某一整类人员从未被追责。
- 没有改名效果追踪，不能宣称改名无效或已经解决歧视。
- 没有完整比较案件，不能把所有问责差异归因于阴谋或身份偏袒。
- 没有证明疫情、纳粹迫害与难民政策存在一条统一策划链；此处比较的是责任与救济机制。

本文的规范立场是：具体行为应有具体证据；机构反思须包含自己的决策；救济应能到达受影响者。是否避免问题重演，要靠后续结果检验。
