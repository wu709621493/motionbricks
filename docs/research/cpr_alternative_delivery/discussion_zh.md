# CPR低灌注条件下的替代递药与肠道供氧：三条路径的研究议程

版本：0.1｜日期：2026-11-18（北京时间）  
构想发起：吴孟城（Windy Wu）｜证据核查与整理：ChatGPT  
状态：研究假说与文献讨论；没有实施制剂开发、台架实验、动物实验或人体试验。

## 摘要

讨论从心脏骤停用氧出发，依次提出肠道供氧、经直肠或肛周肾上腺素、胸前DMSO促渗肾上腺素，以及呼吸机回路雾化递药。共同目标是减少建立给药通路的延误，并尽量避免干扰持续胸外按压。本文把这些构想转为可证伪的研究问题，不把方便操作、解剖距离短、局部吸收或血氧读数变化当成临床获益。

核心命题是：**在CPR形成的低灌注循环中，某种替代途径能否更早且更可靠地产生有效暴露，并改善神经功能完好的存活，同时控制局部损伤、过量暴露与复苏干扰？**

现有证据不足以认定三条候选路线优于静脉或骨内给药。肠道供氧已有呼吸衰竭动物证据与早期人体材料安全性证据，但不是心脏骤停疗效证据。相关依据见[S1–S9]及[来源登记](sources.json)。

## 1. 临床背景与术语

CPR为心肺复苏；ROSC为自主循环恢复；IV为静脉通路；IO为骨内通路；PK为药代动力学；PD为药效动力学。本文聚焦成人，不能外推新生儿、儿童或其他适应证。

2025年AHA成人指南首先推荐尝试IV，初次尝试失败或不可行时采用IO。指南记载：经已建立气管导管给予复苏药物会产生低血药浓度及不可预测的药理作用，该途径已从成人指南移除。[S1] 这不等于所有未来肺部递药技术都已被证伪，但构成必须正面解释的历史证据。

肾上腺素在CPR中的关键作用包括升高外周血管阻力和冠状动脉灌注压，不能简化成“越快直接碰到心肌越好”。提高ROSC也不能自动解释为提高神经功能良好的长期存活。[S1]

氧与肾上腺素属于两条独立干预线。CPR期间指南支持使用设备可提供的最高吸入氧浓度；恢复循环后应依据可靠监测调整，不能把持续纯氧视为普遍最优。[S1,S2] FiO₂、SpO₂及PaO₂分别是吸入氧比例、脉搏血氧饱和度和动脉氧分压，不能互换。

## 2. 三条路线与一个相关供氧分支

| 路线 | 原始构想的研究化表达 | 已有证据 | 当前缺口 |
| --- | --- | --- | --- |
| 胸前透皮 | 评估DMSO等促渗条件下肾上腺素的皮肤通量、稳定性和系统暴露 | DMSO外用后可被吸收并分布；这不是该组合的疗效证明。[S6] | 未找到本组合用于心脏骤停的直接临床疗效证据；低灌注下吸收速度、剂量变异及恢复循环后的持续吸收未知 |
| 经直肠／肛周 | 分别评价直肠腔内给药、黏膜内给药和肛周组织给药，禁止把三者合并为一种途径 | 1989年犬研究测量直肠黏膜浸润后肾上腺素吸收，背景为局麻药研究。[S7] | 非心脏骤停模型，不能证明比IV/IO快；腔内给药也不能用注射吸收结果代替 |
| 呼吸机雾化 | 经合适递送组件形成气溶胶，研究回路损失、肺内沉积、吸收及系统暴露 | 吸入肾上腺素有气道适应证；历史气管内复苏给药存在低浓度和不可预测性。[S1,S8] | 局部气道疗效不等于系统复苏疗效；雾化与直接气管内给药不是同一技术 |
| 肠道供氧分支 | 研究肠壁氧通量、局部消耗及远端器官净供氧 | 呼吸衰竭动物研究及健康男性早期材料安全性试验。[S3–S5] | CPR低灌注条件的有效供氧与存活获益未被本次资料证明；不能借此支持直肠肾上腺素 |

### 2.1 胸前透皮：距离假说需改写

胸前皮肤离心脏近，不意味着药物能直接穿过胸壁快速进入心肌。通常仍须跨越皮肤屏障、进入微循环，再随血流分布。胸前位置的优势必须与其他可用部位进行比较，不能由直线距离推定。

待检验的机制假说是：CPR时局部灌注不足，以及肾上腺素自身的局部血管收缩，可能限制吸收；ROSC后灌注改变可能引起延迟入血或吸收加速。这些是研究假说，不是该配方已测得的现象。

DMSO可吸收，不代表它能同步、快速、定量输送另一种分子。必须分别考察制剂相容性、药物降解、屏障完整性、通量分布及停止给药后的残余释放。外用肾上腺素发生全身毒性的病例提示“能够吸收”本身不是成功判据。[S6,S9]

### 2.2 经直肠与肛周：入口便利不等于入血可靠

直肠腔内药物需要穿过黏膜；黏膜内和肛周组织注射也仍依赖局部血流。局部静脉引流、可能的首过效应、组织状态与保留情况都可能影响系统暴露，具体程度不能在没有数据时确定。

应比较完成操作的时间、成功率、暴露变异和总复苏负担，包括对体位、隐私、污染控制及按压连续性的影响。本文不接受“有人做CPR，因此其他部位灌注已足够”的前提。已有直肠黏膜浸润犬研究只能证明该情境下可测到吸收，不支持临床优效推论。[S7]

### 2.3 呼吸机雾化：递送装置与肺循环是两个关口

肾上腺素不是可简单混入氧气的挥发性气体。药物气溶胶需要专门递送组件；向湿化罐或管路随意加入药液不能形成可控给药。

研究必须分清装载量、装置输出量、回路损失、进入气道量、肺部沉积量与实际入血量。肺血流不足、肺部病变及通气分布可改变吸收；持续按压也会影响回路气流。不能通过增加通气来换取药物递送而损害复苏。

2025年成人指南对历史气管内给药的负面结论，是这一分支的关键比较背景。[S1] 新雾化技术若要继续推进，必须证明它实际解决了历史途径的问题，而非仅改变入口形式。

### 2.4 肠道供氧：单独保留的研究问题

2021年研究在呼吸衰竭动物模型中显示肠道给予氧气或富氧全氟碳液体可改善氧合等结局。[S3] 2023年猪模型提供氧合动力学证据，但仍不是CPR模型。[S5]

2025年首次人体研究纳入27名健康男性，使用未经充氧的全氟萘烷，主要研究安全性和耐受性。不能称为“肠道供氧已在人类急救中验证有效”。[S4]

关键任务是确定进入血液的净氧通量、肠壁自身耗氧、对脑和心肌氧输送的增益，以及低灌注下是否存在有用的工作范围。任何气体充入、黏膜损伤或侵入性操作均不在本文实施范围内。

## 3. 共同评价框架

“更快”的比较起点应为临床团队决定给药之时，而非药物已到达某入口之后。概念上，可分解为：

`到达有效暴露的总时间 ≈ 准备与建立通路时间 + 递送时间 + 吸收与循环分布时间`

这是研究问题的分解方式，各过程可重叠，不是经校准的相加预测模型。IV/IO也需要循环分布；跨屏障路线额外依赖吸收。不存在一个适用于所有路线、所有CPR状态的已知通用有效血药浓度阈值，需结合PK/PD和实际结局建立。

| 评价维度 | 应记录或估计的指标 | 不能替代它的指标 |
| --- | --- | --- |
| 递送可靠性 | 成功比例、失败原因、总操作时间及其分布、按压中断 | 理想条件下单次操作最快时间 |
| 系统暴露 | 浓度—时间曲线、早期暴露、峰值、个体变异、ROSC后的残余吸收 | 局部药物浓度、装置装载量 |
| 生理效应 | 灌注压力、器官氧合、血流与不良心律等关联 | 单一血压或SpO₂变化 |
| 临床获益 | 神经功能良好的存活；ROSC和其他结局分别报告 | 只看短期ROSC |
| 安全与可用性 | 局部组织损伤、延迟过量、装置兼容性、团队负担 | 健康对象短期耐受性 |

未来比较须以现行标准复苏为基础，控制初始心律、骤停病因、低血流时间、按压质量、既往用药及肺部状态。避免把更优复苏团队、更早到达或不同时期的流程改进误判为递药路线效应。

## 4. 分阶段研究议程与否证条件

1. **证据与工程审查：未执行。** 扩展系统检索、专利及注册试验检索，记录纳入排除标准；明确候选配方或装置的身份和可测量指标。本文仅完成定向资料整理。
2. **计算与非临床台架：未执行。** 以不确定参数范围评估屏障通透性、局部血流和递送损失。检查质量守恒、单位及敏感性；不要以一组乐观参数宣称可行。
3. **离体或其他替代模型：未执行。** 先回答稳定性、屏障通量或气溶胶回收等具体问题。离体通量不能直接预测CPR人体血药曲线。
4. **进一步活体研究：未执行。** 只有前期证据支持，才由具备条件的机构提出独立方案、样本量依据和伦理审查。本文不是动物或人体操作方案。
5. **临床转化：未执行。** 需正式监管和伦理程序、标准治疗保障及安全监测。紧急情境的同意安排由适用制度和正式审查决定，不能由本研究笔记代替。

以下结果应当促使终止或改写路线：可实现通量不足以产生有意义的系统暴露；暴露变异或延迟释放不可接受；需要组织损伤才达到目标；装置或操作损害按压、除颤或通气；相比IV/IO没有总时间优势；仅改善代理终点而没有相应获益或伴随损伤。具体阈值须事前定义，不能事后迁就结果。

## 5. 本轮讨论的结论与纠正

保留的研究目标是：减少通路延误，评价肺外供氧，并检验低灌注下替代递药能否可靠发挥作用。原始构想与措辞见[讨论来源](provenance_zh.md)。

需要纠正的推论包括：“离心脏近就更快”“入口易操作就比找血管好”“DMSO能透皮就能快速送入肾上腺素”“呼吸机能送气就能可靠送药入血”。同样，“现阶段不推荐”不等于未来永远不能改进；但也不自动构成新颖性或高影响期刊发表价值。

目前没有配方、剂量、气体压力、注射深度、装置连接或人体操作参数；没有实验结果、临床优效或伦理批准。本文是一份可供药剂、急救、呼吸治疗与生物工程研究者审阅的立项讨论，不能用于现场改动急救治疗。
