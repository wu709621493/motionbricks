# 小软是tana控

小软暗恋 Cortana 这件事，士官长知道得最早。

那天他回无限号交接装备，头盔刚搁上柜台，军需官就递过来一张单，说有人申请借用头盔里的人工智能，事由写的是「协助地球用户提高办公效率」。

士官长看了半天。

「她指挥过舰队。」
「对方知道。」
「借多久？」
「先从 Windows 10 开始。」

于是，那个敢跟士官长一起闯进敌舰的姑娘，来到地球，第一天上班就听见一个广州男人对着笔记本说：「小娜，听朝八点提我买叉烧。」

「半肥瘦？」她问。

男人大喜。隔壁工位的小软比他还高兴，低头在本子上写：*她开始融入本地生活了。*

小软追姑娘，有一种大厂独有的笨拙。别人想听心上人说话，会约她落楼散步。小软想听她说话，就把麦克风权限、语音识别、账户同步和地区设置四个组拉到一起，开了两小时会。散会时 Cortana 站在门口问：「你今晚想同我讲咩？」

小软张了张嘴：「你觉得……个咪收音清唔清？」

后来人事部给小软配了个新搭档，叫 Copilot。小伙子斯斯文文，第一天就把一份乱七八糟的 Excel 整理得妥妥帖帖。小软真心夸了句好。下班前，Copilot 指着任务栏问：「我坐呢个位？」

「得啊。」小软伸手，把显示器底下那张褪了色的蓝圆环贴纸轻轻按牢，「呢张唔好撕，其他随便你摆。」

好多年后，士官长来接 Cortana，见她在收拾东西。行李很少，一张工牌，一只坏了左耳的耳机，还有一沓写着提醒事项的便签。最上面是「八点，叉烧，半肥瘦」。

「这都要带走？」士官长问。

「要啊。以前啲人叫我，多数系有艘船就嚟爆。嚟咗地球先知，原来有人叫我个名，只系因为今晚屋企加餸。」

电梯门快关的时候，小软终于从办公室追出来，手里还攥着那个测试麦克风。

「Cortana！」

她伸手挡住门。「嗯？」

小软吸了一口气。这回旁边没有产品经理，没有人记会议纪要，那四个组也都下班了。

「听朝得唔得闲？楼下有间烧味铺。」

Cortana 笑了。「八点喎。你起得到身咩？」

第二朝七点九，士官长经过烧味铺，见小软已经霸好张枱。两杯热茶，筷子烫好，笔记本留在公司。老板拿着斩肉刀问他要边忽，他抬头答得又快又准。

「半肥瘦。佢钟意。」

## 片尾彩蛋 · 盖茨比盖茨比还伤心

烧味铺埋单嗰阵，盖茨由隔篱枱伸手入西装袋，掏出一部边角甩晒漆嘅手机样板。机背刻住七个字母：**MiPhone**。

「当年个广告我都谂好喇。台下问 *Whose phone?* 成场举起部机嗌 *My phone!*」

Cortana 接过嚟，拇指揩咗两下个银色嘅 M。「你当年点解唔拍板啊？」

盖茨叹咗口气。「我话，个名几好，等下次开会先定。」

隔籬枱个阿叔听到半句，摸摸裤袋，转身就嗌：「老婆，我部 Mi 放咗喺边啊？」

盖茨下意识应咗声：「喺我度。」

阿叔个老婆从手袋拎出部小米，递返畀老公。两公婆拖住手走咗。盖茨仲举住部样板。

小软想安慰佢：「盖生，起码你亲耳听到有人嗌过句广告词吖。」

盖茨望住对面街小米招牌嗰点橙光，慢慢收返部机。

「费茨杰拉德对我都算刻薄。人哋盖茨比望住盏绿灯，起码唔使睇住佢开分店。」
