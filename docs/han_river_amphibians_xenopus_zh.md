# 汉江两栖动物：从 Xenopus 蛙测孕到可检验的生态推论

日期：2026-11-11（Asia/Shanghai）。这是[汉江调查](han_river_hormones_pde5_ecology_zh.md)的研究设计补充，不改写原始浓度、原报告结论或[49 条证据表](data/han_river_pharmaceuticals/concentrations.csv)。下列实验均未实施；实验文献中的暴露浓度不进入当地实测 CSV。

## 1. 历史切入点：蛙能报告激素效应，但不能识别一切激素

Shapiro 与 Zwarenstein 于 1934 年在 *Nature* 发表 Xenopus laevis 快速测孕报告。[A1] 应称它为**早期活体测孕方法之一**，不能称为人类最早测孕方法；1946 年的原始临床报告也明确提到此前的鼠试验。[A2]

蛙测孕利用孕妇尿液中 hCG 的促性腺活性引起雌蛙排卵／产卵。它启发我们把生物反应作为读数，却不意味着 E2、EE2、hCG 和西地那非能互换：hCG 是促性腺激素，E2/EE2 属雌激素，西地那非是 PDE-5 抑制剂。2012 年 Xenopus 原始实验也区分了用于激发行为的 hCG 与水中施加的 EE2。[A2、A4]

因此，不能把“给蛙注射河水后是否产卵”当作通用雌激素或伟哥检测器。注射绕过自然暴露过程，混合物的反应缺乏化合物特异性；不产卵不能证明没有内分泌活性，产卵也不能证明存在 hCG 或特定药物。

## 2. 证据与推论分层

| 对象 | 目前支持什么 | 对汉江两栖动物可提出的推论与限制 |
| --- | --- | --- |
| EE2 发育暴露 | Gyllenhammar 等的 *X. tropicalis* 研究报告幼体暴露后的性别表型及成年生殖影响；摘要称低至 6 pM（1.8 ng/L）提示性逆转 [A3] | 性分化期暴露值得调查；这个实验值不是汉江当地阈值。该文使用 *X. tropicalis*，不可改写成 *X. laevis* 或当地野生蛙的结果 |
| EE2 与求偶行为 | Hoffmann 与 Kloas 的成年雄性 *X. laevis* 实验报告鸣叫变化，最低处理浓度为 0.296 ng/L；设计包含 hCG 刺激和溶剂对照 [A4] | 行为终点可能提供补充信息；hCG 刺激、实验水体和短期设计限制了野外外推，不能据此宣称当地种群已衰退 |
| E1/E2 当地暴露 | 原调查 S4 是四座污水厂模型；S3 的 E2/EE2 是历史未检出汇总 | 若当地繁殖栖息地在敏感窗口有持续雌激素活性，可能影响发育或繁殖；需先实测，不能拿模型出水值充当蝌蚪栖息地浓度 |
| 西地那非及其他 PDE-5 抑制剂 | S2 支持历史水体暴露；尚未在本次检索中取得汉江野生两栖动物的对应因果研究 | 可提出 PDE-5/cGMP 相关生理或生殖终点的探索性假说；不能预言“蛙更兴奋”、一定雌性化或必然繁殖失败，也不能直接套用 EE2 的效应浓度 |
| 混合物 | 现有当地表没有同批化学暴露与两栖动物效应配对数据 | 相加、协同、拮抗或无可测效应均须检验；不同药物的 ng/L 不能相加成为统一“性激素效力” |

本次也检索到含西地那非处理的转基因 Xenopus 脱髓鞘／再髓鞘实验。[A6] 它属于药理模型，不能替代环境相关暴露下的生殖生态实验。因此，这里的缺口是**当地暴露—生物效应—种群后果之间的证据链**，并非宣称从来没有人用 Xenopus 研究西地那非。

尤其不能用 S3 的历史 `<1 ng/L` 与 A4 的实验处理值做简单大小比较，得出当地安全或受损结论：时空、实际暴露、物种、终点和分析能力均不匹配；报告上界也不是逐物质 LOQ。

## 3. 如何应用 Xenopus 的思想：待实施的分层方案

1. **当地暴露与生境配对。** 先确认受纳支流、河漫滩池塘或其他繁殖水域与排口的水力联系及当地物种，按繁殖季同步记录水质、卵块／幼体观察与化学样品。控制水温、水位、营养、农药、栖息地变化和疾病等混杂因素，不把鱼类数据自动当作两栖动物数据。
2. **化学鉴定与功能筛查。** 对同批水样进行经基质验证的 LC-MS/MS 及雌激素受体活性测定；西地那非单独量化，不归入雌激素当量。保留空白、回收率、LOD/LOQ 与未知值。先用非动物方法和现场观察决定是否需要后续动物试验。
3. **标准化 Xenopus 发育试验。** 如前期证据支持，可参考 OECD TG 241 LAGDA，观察生长、存活、变态及性腺等终点。[A5] 设置基质、溶剂、单物质及混合物对照，暴露浓度须实际测定。该试验到早期幼蛙／部分生殖成熟阶段，不直接提供完整成年繁殖成功率，也不是现成的西地那非专属检测方法。
4. **可选的成年 hCG 挑战模块。** 借鉴早期蛙测孕的功能读数，提出在受控暴露后比较标准化 hCG 刺激下的产卵潜伏期、卵数及后续受精／孵化表现。这是本补充的研究建议，尚未验证为汉江监测方法。必须并行保留不经 hCG 刺激的繁殖观察，并控制成熟度、季节与处理史；外源激素可能掩盖自然生殖轴受损，刺激后能产卵不等于自然繁殖无损伤。hCG 是功能挑战，不能用来反推水中 EE2 或西地那非浓度。
5. **回到当地验证。** 实验室效应只用于选择野外终点；需要配对暴露、治理前后与对照地点观察，才逐步判断当地因果关系。Xenopus 在此是受控实验模型，不被假设为汉江土著物种；不向流域释放。动物研究须经适用的伦理审查，减少使用量并预设人道终点。

可证伪的预测是：在控制混杂后，若某类化学活性确为效应驱动因素，其空间／时间暴露差异以及针对性去除，应与相关生物终点一致变化。若未出现一致性，就应修正假说，不能用“可能有协同”无限延长不可验证的解释。
