# 谁是大客？落低一亿订单的，还是家里有十个一亿的？

朝早九点，公司有两位客。

陈生着件洗到有啲起毛粒嘅恤衫，拎住份合同入嚟。价钱倾咗三个月，规格改咗七次，今日终于落笔：一个亿。

周生迟十分钟到。秘书细细声讲，佢屋企有十个亿。

老板即刻起身，将陈生杯普洱移开少少，腾个位摆周生嗰壶明前龙井。

「周生，真系大客光临！」

陈生握住支笔，忽然唔知自己应该签名，定应该帮手斟茶。

其实周生今日只系路过，上嚟借个厕所。佢见大家咁热情，亦都客气：「你哋忙，唔使招呼我。」

老板听完，更加佩服。有钱人果然低调，连唔买嘢都讲得咁有分寸。

陈生就冇咁好命。一个亿订单，附带交期、验收、售后，仲要逐条核对。财务嫌佢付款条件严，生产嫌佢要求多，老板嫌佢倾价倾得尽。

周生乜都未要求，所以样样都好。

呢个就系做生意最微妙嘅地方：一个人准备畀钱你，佢啲要求就开始令人烦；另一个人有好多钱，但未准备畀你，你就觉得佢充满可能。

茶饮到第二轮，陈生终于签好名。

「订金今日过数。收款之后，麻烦按合同排产。」

老板话：「好，好，稍等，我送一送周生。」

周生听到呢度，反而停低。

「你招呼佢先啦。人哋真系有生意同你做。」

老板笑住摆手：「您咁嘅身家，将来随便支持少少——」

「我屋企有十个亿，」周生话，「又唔系摆咗十个亿喺你度。」

间房静咗一静。

陈生低头，将合同装返入文件袋。手机啱啱响，财务发嚟张付款回单。

老板个手机亦响咗。

今次佢终于望向陈生。

「陈总，再饮杯茶？」

陈生睇睇只杯。

「唔该。头先嗰杯都未饮完。」

窗外条街开始热闹。老板做咗廿年生意，今日先发现：**人哋屋企有几多钱，同自己盘生意收到几多钱，中间原来隔住一个「肯」字。**
