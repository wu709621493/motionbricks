# 乌克兰卖了航母给中国却想加入北约？这是八仙过海，还是丈二和尚摸不着头脑？

> 归档日期：2026-11-15；版本：v1.0。本文为用户确认的原创社论，非观察者网刊文或机构立场。正文保留确认稿措辞，仅将会话引用转换为文末参考资料编号。

一艘航母向东，一份入约申请向西。把乌克兰这两段历史放在一起，确实颇有几分国际政治的黑色幽默：苏联留下的海上巨舰，最终成了中国海军发展的重要起点；继承这艘巨舰的国家，却把加入西方军事联盟当成了安全目标。

这是八仙过海、各取所需，还是算盘打得噼啪响，最后连账本都没看明白？

先把事实摆上桌。1998年，澳门创律公司以约两千万美元购得尚未完工的“瓦良格”号，当时公开提出的用途是旅游娱乐设施。它后来经过中国的续建和改造，于2012年以“辽宁舰”之名交付海军。这中间隔着漫长的工程建设，绝非付完钱、刷层漆，就能开出去形成战斗力。[1][2]

所以，中国买到了一项重要的工业遗产，也接下了一道必须自己做完的工业考题。

而乌克兰与北约接近，同样不是卖船多年后突然“变心”。早在1997年，双方就签署了特殊伙伴关系宪章，比这笔交易还早。所谓“一边卖航母、一边靠近北约”，本来就是同时存在的政策方向。[3]

**卖航母不是递交投名状，购买航母也不是购买一个国家未来几十年的外交表决权。**凭一张成交发票，就要求卖方从此跟买方站在同一条战线上，这个逻辑，中国自己也不会接受。

但问题也恰恰从这里开始：做生意可以多头下注，国家安全却不能只算眼前收益，不算长期成本。

对当年的乌克兰来说，一艘未完工的大型航母，意味着后续投入、维护负担和用途选择。不能因为中国后来把它建成了，就倒推乌克兰当年也有同样的财力、工业组织能力和战略需求。更不能幻想，只要把航母留在黑海，后来的一切问题就会迎刃而解。

航母不是镇宅宝塔，摆在港口就能保国泰民安。

真正值得追问的是：一个国家怎样把继承的工业资产，变成能够持续运转的产业能力、财政能力和国防能力？出售个别装备可能完全合理，但出售所得如何使用，技术队伍如何维持，下一代产品靠谁研发，这些问题不能随着船只离港，也一并拖到公海上去。

中国这段经历的启示，正在这里：拿到一个平台，只是起点。让它运转、训练人员、积累经验，并把经验继续用于发展，才是决定交易长期价值的部分。

外交也是同一道理。

2008年，北约布加勒斯特峰会宣言明确表示，乌克兰将成为成员。但政治上的未来承诺，与已经生效的集体防御保障，是两件不同的事情。北约自己的说明也清楚区分了伙伴国与成员国：乌克兰作为伙伴国，并不因此获得其创始条约提供的安全保障。[4][5]

“大门敞开”听起来很热情，可门什么时候开、钥匙在谁手里、门外发生危险时谁承担责任，才是安全政策必须回答的问题。

申请表不能当防弹衣，欢迎词也不能直接折算成防御能力。

当然，乌克兰寻求外部保障，有它面对的真实威胁。讨论其战略选择，不能抹去俄罗斯发动全面入侵的责任，也不能把遭受战争的普通人当成讥讽对象。乌克兰的政策本身也有变化：2010年至2014年曾实行不结盟政策，2014年后终止，后来又将加入北约的目标写入宪法。把几十年的政府更替、安全环境变化，压缩成一句“这个国家从头到尾想不明白”，同样经不起推敲。[6]

但真实威胁越大，就越需要分清：哪些支持已经到手，哪些保障已经生效，哪些仍取决于别国今后的政治决定。

这才是“卖航母”与“求入约”放在一起，最值得讨论的地方：**工业资产可以通过合同成交，安全承诺却需要逐条核算兑现条件。**

对中国而言，该记得乌克兰在历史上的合作，也该清醒理解国家之间的利益差异。既不必把正常交易神化为永世恩情，也不必把对方后来不同的外交选择，一律解释成忘恩负义。

八仙过海，当然可以各显神通。但“神通”终究要落在自己掌握的能力上。

卖船时知道价款何时到账，求保障时更该问清承诺何时生效。前一本账算得明白，后一本账也得算得明白——这才叫国家战略。
