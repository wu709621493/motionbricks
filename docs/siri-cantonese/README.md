## 畀人炒之后，边个知边个叻？

作者原话：「比马斯克炒说明你基本有一个方面比他强而且他不知道辣」。读作一句挑机，佢点中老板知识嘅边界。读作统计结论，就欠咗所有顶撞过而留任嘅人做分母。公开争执可以留档，边个技术判断啱，要睇实测。至于篇文似苹果招聘广告？绝对唔系招聘！唔使交 CV，请带样机。

## 钛加木，去吉克普林见工

「钛加木」读到头两个字，泰加林已经签咗份谐音可行性报告。概念机用钛边、铝骨、真木背。吉克普林木屋内，镜头沿住枱面滑，一道钛边经过，观众先发现有一截木纹可以攞起身放入口袋。「我认为库克王朝应该在此埋葬」系呢场交接戏嘅台词。镜头拍完，仲要过广州回南天。先睇木背接缝会唔会翘到勾冷衫，再测充电同温升。呢部机仲系纸上设计。[iPhone 15 Pro 钛边与铝内架](https://www.apple.com/newsroom/2023/09/apple-unveils-iphone-15-pro-and-iphone-15-pro-max/)

## 畀 Apple Park 嘅虚构申请

本人申请，产品评审容许员工用「叼黎老母」顶撞 CEO。HR 爱点样记录用词都好，工程会议纪要记得写低**边部样机会勾冷衫**。加咗嗰四个字，好似羊肉加孜然。「叼黎老母，你摸下」系一早知条边有问题；「你摸下……叼黎老母，真系勾线喎」可以系讲者摸完先信。呢两种系场景读法，留住停顿先有得判断。
