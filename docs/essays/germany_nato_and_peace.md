# 从不列颠北部的长城到“不止一次被席卷的波兰”：德意志在北约的砝码，只能落在“和”、“平”两个字上

在英格兰北部看哈德良长城，最值得停一停的地方，是墙上的门。罗马人在长墙沿线修筑小堡，派兵把守通道。两千年后，游客沿着石基走，很容易看出帝国的边界曾经划在哪里。至于当年一个赶着牲口的人，要向谁说明来意，等多久才获准过门，地图上看不出来。边界的两面，一向住着对同一堵墙有不同记忆的人。[^1]

到了波兰，连墙也未必要动，边界就能从人身上过去。十八世纪末，短短二十三年，波兰立陶宛联邦经历三次瓜分，终于在1795年从欧洲政治地图上消失。第一次瓜分还有一套颇为体面的外交理由。普鲁士国王腓特烈二世要调停奥俄之间的利害，维持中欧均势。几家朝廷果然各有所得。若由华沙来记这笔账，所谓均势，就是三位邻居终于谈拢，由第四家出地。[^2]

所以，“不止一次被席卷的波兰”，最该细读的是那个“被”字。“席卷”听来像风过平原，仿佛波兰的苦难多少要怪地势平坦。把主语放回去，历史便清楚得多。1939年9月1日，纳粹德国从西面入侵波兰；9月17日，苏联从东面入侵。此前，两国已在秘密议定书里划分势力范围。地理可以说明军队从哪里来，签字的人要为军队为什么来负责。[^3]

今天，德国与波兰同坐北约的会议桌。柏林若问，德国究竟该在欧洲安全上占多大分量，不妨先听一听华沙怎样理解“和平”。一个德国人说，他最怕德国军队再次卷入东欧战争，这份忧虑有其历史来由。一个波兰人反问，倘若我们遭到攻击，你们究竟来不来，这一问也有同样深的历史来由。德国政治最难的一门功课，是对这两个人同时守信。

“和”字，勃兰特写过一笔。1970年12月7日，西德总理勃兰特在华沙犹太隔都起义英雄纪念碑前跪下。同一天，西德与波兰签署《华沙条约》，确认既有边界不可侵犯。后世记住了那张照片，波兰人还可以翻看那份条约。下跪让死者在外交日程里有了一席之地，签字让活着的人知道，邻国政府对边界作了什么承诺。德国的分量，在那一天恰恰来自它肯让自己的手受约束。[^4]

“平”字，则要看谁有资格坐在桌边。柏林与莫斯科保持通话，有助于在危急关头把话说明白。但若谈的是乌克兰的国土，乌克兰就得自己作主；若谈的是波兰边境居民要承担多少风险，华沙就有权当面说一句“我不同意”。欧洲最熟练的外交手艺，曾经是替缺席的人安排命运。一张谈判桌能否称得上进步，要看席间最小的国家说了“不”以后，会议还怎样开下去。

这也解释了一个看似矛盾的场面。2025年5月，德国驻立陶宛旅在维尔纽斯正式启用，东道国为此举行了仪式。若只从柏林回望历史，德国军旗向东出现，自然令人停笔再想。把报道地点移到维尔纽斯，便多出一个不可删去的事实：立陶宛人有权判断，怎样的同盟承诺能使自己的国家更安全。尊重东欧，也包括认真听取东欧盟友希望德国承担更多责任的声音。[^5]

《北大西洋公约》本来就把这道难题写进了条文。第一条要求成员以和平方式解决国际争端，第四条让安全受到威胁的成员有权要求磋商，第五条规定遭受武装攻击时的集体防卫义务。三个条款放在一起，德国的责任就很具体了：邻居担忧时，肯来听；邻居遇袭时，肯出力；尚有机会避免战争时，肯花政治本钱去谈。三件事里只拣国内最受欢迎的一件，盟友迟早会听出来。[^6]

回到哈德良长城。罗马留给后人一堵墙，也留下一道问题：谁拿着门上的钥匙？两千年前，答案刻在帝国的军令里。今天若再问柏林，德国能给欧洲的最好回答，应当让华沙、维尔纽斯和基辅的人都听得安心。

**德国有分量，足以在人家的门被撞开时，抵住那扇门。德国懂历史，就该知道，门上的钥匙应当留在主人手里。前一句是“和”要付的代价，后一句是“平”应有的意思。**
