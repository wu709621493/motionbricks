# 长期处于GDP全球排名第三的从古至今的中国：在美国和苏联之后的崛起者，从热水片到地暖，从榫卯到钢筋混凝土，中国吃到了多少后来者的红利？

北京故宫养心殿东暖阁的东山墙上，留着几处排烟口。顺着这些不起眼的孔洞，可以读懂旧时的一桩营造心思。寒冬里，人在屋外添炭，热烟沿砖下的火道行走，把暖意送到殿内人的脚下。论起怎样让一间屋子暖和起来，中国工匠很早就有自己的办法。[1][2]

那么，中国从什么时候算是“后来者”？要回答这个问题，得先看“世界第三”属于哪个年代。按经济史学家麦迪森对购买力的历史估算，1820年中国约占世界经济总量的三分之一。到1978年，在同一套估算里，美国、苏联和日本的份额都高于中国。再看按当年汇率折算的名义GDP，2008年中国居世界第三，排在前面的是美国和日本，2010年中国超过日本，升至第二。这段历史最值得追问的，是一个造过暖阁、架过大殿的国家，怎样借世界工业化之力，让普通家庭住得更好。[3][4]

## 一间屋子的暖意，有两本账

一组铸铁热水片，通常装在墙边，热水流过，整间屋子慢慢暖起来。低温热水地暖把管子铺在脚下，让一大片地面共同散热，水温也就可以低一些。到了2004年，我国施行的《地面辐射供暖技术规程》，已将热负荷怎样算、管子怎样铺、封进地面前怎样试压，一项项写明。对一座尚未封顶的新楼来说，地面本来就要施工，此时把保温层和盘管一并做好，便省去了日后掀开地板的麻烦。大批住宅开建时，恰有成熟技术可用，是后来者难得的时机。[5][6]

不过，北方一户人家过冬，有两本账要算。住户看温度计，供热站看耗能表。在河北唐山，河北一号小区的三栋五层预制板楼建于震后，主体结构尚好，墙体却缺少保温。2006年，中德合作改造给外墙加保温层，换上中空玻璃窗，也给供暖系统装上恒温阀。德国带来了改造原东德预制板住宅的经验，唐山则拿出三栋有人居住的老楼，按当地的冬天来检验。[7]

按项目记录，改造后，楼内冬季平均室温从15摄氏度升至22摄氏度，每平方米采暖能耗从107千瓦时降至68千瓦时。一头多了7摄氏度，一头省了约36%。外墙、窗户、管网和调温装置共同交出了这份成绩单。这些老楼还用得着墙边的暖气片。过去从窗缝和薄墙散掉的那部分热，如今留在了屋里。[7]

## 会修祈年殿的人，也会造体育场

1933年，第五届全国运动会在南京中央体育场开幕。田径场可容纳约三万五千名观众。观众举头看，门楼上有云纹望柱和小牌坊屋顶。看台之下，承重的是钢筋混凝土。参与设计的杨廷宝早年留学美国宾夕法尼亚大学。体育场建成后不久，他又受邀修缮北平的天坛祈年殿。[8][9][10]

传统木构自有成套的办法。梁柱可以预先加工，运到现场再以榫卯扣合。钢筋混凝土把另一套本领带进工地。看台能坐多少人，梁该配多少钢筋，浇筑以后什么时候可以拆模，都要把计算、材料和施工对在一起。杨廷宝这一代人的际遇在于，前人花了几代工夫摸索的两套手艺，他们在一生之内都有机会学到。至于一座体育场怎样既托得住数万观众，又让人一眼认出中国门楼的模样，仍要由建筑师自己落笔。[11][8]

到了上世纪五十年代，类似的考题摆到了钢厂车间。苏联援助中国建设“156项工程”，既提供机器设备，也培训工程师、车间主管和技术工人。经济学者追踪相关钢厂四十余年的表现，发现单靠设备取得的生产优势会逐渐消退，受过技术培训的工厂却能在后来继续改进工艺。机器运进厂门，省下的是从头研制的功夫。等到机器用旧，还有人知道下一次该怎么改，这笔收益才传得下去。[12]

## 阳江十八子：一把菜刀的“极致成功”

把“李”字拆开，便是“十八子”。在广东阳江，李良辉把自家的姓放到了菜刀上。1983年起步时，作坊不足二百平方米，八个人，手工生产碳钢菜刀。李良辉当过国营小刀厂的车间主任。儿子李积回后来回忆，父亲能跟着老厂采购员买钢板，靠对方的信用缓一缓货款，又能托熟悉的业务员把成品卖出去。新作坊接过来的第一笔红利，有师傅的手艺，也有供货人肯等几天的那份信任。[13][14][15]

后来者也有出门看新鲜的时候。1996年，李积回到广州逛广交会，看见海外厂商把不同用途的厨刀配成一套，放在同一个刀座上。第二年，十八子也推出了座放套刀。对下厨的人，这不过是伸手取哪一把更顺当。对一家刀厂，却意味着生意从卖出一把菜刀，做到为一户人家配齐案头用具。此后，十八子又把生意往上游做，建起特种钢厂。到2021年，据广东省高新技术企业协会介绍，企业已经能规模生产上千种规格的刀具，产品销往三十多个国家和地区。[14][15]

再往后，看展的人把展会办到了家门口。2001年，李积回以市人大代表身份建议在阳江举办专业展会。次年，首届中国（阳江）国际五金刀剪博览会迎来三百多家参展企业。到2024年第二十三届刀博会，年近九旬的李良辉仍连着三天到场，留意同行又添了什么新机械、新工艺。[16]

说十八子做到了“极致成功”，还有一份比销量更耐读的记录。翻开2022年3月实施的推荐性国家标准《厨用刀具》，主要起草单位里有阳江十八子，也有王麻子和质量检测机构。这份标准借鉴了包括锋利度、耐用度测试在内的国际标准。过去，顾客问哪把刀好用，要听掌柜凭经验讲。如今，两家厂的菜刀摆在一起，除了各报字号，还可以拿同一套方法来比。一个把自家姓氏刻在刀上的小作坊，走到后来，参与写下了连同行也用得上的那把尺子。[17]

中国究竟吃到了多少后来者红利？给全国GDP开出一个百分比，需要知道假如没有那些图纸、设备和师傅，中国会花多少钱、多走多少年。三栋楼省下的热量可以核算，钢厂四十多年间学到的本领可以追踪，阳江一家作坊成长为国家标准起草单位也有案可查。再往后看，还有一笔收益落在下一批求教的人身上。

后来，北京惠新西街12号楼也要做节能改造。起初，赞成的居民不到三成。居民代表和居委会代表专程到唐山看了那三栋楼，回来后，支持率接近九成。当年唐山为三栋楼的事向德国同行取经。到了北京居民想知道老房子究竟能暖到什么程度时，唐山就有一扇门可以敲开。[7]
