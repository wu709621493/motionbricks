# 黄色的森林里分出两条路：“走自己的路，让别人说去吧”和“走别人的路，让别人走投无路”这两种青年“邪修”是怎么做到让科研和文化蓬勃发展的

*文艺评论*

弗罗斯特笔下，黄色的森林里分出两条路。诗人朝一条路的深处望了许久，选了另一条。他倒也老实，承认那天早上，两条路上的脚印其实差不多。要是林子口恰好站着两位当代青年，事情就好办了。甲说：“走自己的路，让别人说去吧。”乙把鞋带系紧：“你先行。走别人的路，让别人走投无路。”

甲回头望了一眼：“你想抢我饭碗？”

“你嗰份饭我冇兴趣。我想睇下，点解得你有镬。”

先把这口镬搬进实验室。譬如甲用一台旧显微镜，攒出一套数颗粒的办法。同行会上有人问，你那个小镜头，能看见多小的颗粒？甲把一张图投到幕布上。后排的乙举手：“拣得好靓。可唔可以畀我拣一张？”

散会以后，乙真来了，带着一盒编了号的样片，把答案扣在自己手里。他照甲公开的图纸装了一台，请隔壁学校也装一台。大颗粒，三边数得相当齐。换上最小的一档，甲的机器也漏数。一个月后，甲在图纸上添了一行适用范围，乙在漏数最厉害的那张图旁署了自己的名。隔壁学校的学生拿着两页纸，头一回知道，做这项实验该信哪一格数字。

“走自己的路”，使世上多了一件可用的仪器。“走别人的路”，使那件仪器离开了发明人的手也有个准头。最难堪的大约是去年还在会上说“这活儿只有我做得了”的那位专家。今年学生来请教，开口已经是第二个问题了。专家若肯答，学问也就往前挪了一格。

翻开科研史，两门功夫有时还长在同一个人身上。屠呦呦重读葛洪的《肘后备急方》，留心到古人写青蒿用的是一个“绞”字。顺着这个字去想，提取过程中的温度便成了值得重查的条件。古书翻到这里，下一页得由实验来写。葛洪留下一个动词，够后来人想上一阵。后来人做出的结果，又何止替古人添一条注脚。

再请两位青年去剧场。今晚演嫦娥奔月。甲替嫦娥设计了一段腾空的身段，练了半年，起脚时连裙边都漂亮。乙在排练厅后面翻鲁迅的《奔月》，翻到羿提着猎物回家那一页，忍不住笑了。这位射过太阳的好汉，打只麻雀回来给太太加菜，偏偏弓太强，箭头太大，肉都射碎了。嫦娥今晚又得吃乌鸦肉炸酱面。乙把书递给甲：“你今晚升空之前，肯唔肯先返屋企食餐饭？”

于是多排了一场。台上，羿从碗底挑了半天，好容易找出一点麻雀肉，夹到妻子碗里。嫦娥看看他，又把那点肉夹回去。等她终于腾空，甲苦练半年的身段还是那个身段，台下却有人回头看了一眼桌上那两只碗。

这才是文化界最厉害的“让别人走投无路”。往后再有人排这出戏，哪怕台上只有一轮明月，台下也可能坐着一个惦记那顿晚饭的人。要从他手里挣回一张戏票，诸位得再想点办法。同行的日子确实难过了些，观众的日子可好过多了。

一个地方真想让科研和文化兴旺，就看它肯不肯付两笔常被省掉的钱。一笔给那个还说不清旧镜头能看见什么的人，准他试一回。另一笔给那个偏要重走一遍的人，算他一份独立的工。剧团也一样。半年练成的那一步值得掌声，替嫦娥留出半顿饭工夫的人，也该在节目单上有个名字。

散场时，甲乙又走到黄色的林子口。甲问：“今日到底边个走投无路？”

乙想了想：“靠一句‘自古以来就系咁’收足全票嗰位啰。”

后头卖票的探出半个身子：“听晚仲嚟唔嚟？”

两个人同时回头：“你听晚做边出先？”

卖票人把一张明晚的戏票翻过来，背面印着普希金的《致诗人》。甲就着窗口的灯读下去。诗里说，沿着自由的路，走向你那自由的心智引你去的地方。甲拿手指在“自由”底下划了两道：“呢句写我。”

乙把票往灯下移了半寸。诗人还有一问，大意是，苛求的艺术家啊，你自己满意吗？

甲想起那张投到幕布上的图。乙也没接话。他忽然想起嫦娥夹回去的那一点肉。排戏时他只顾看嫦娥，竟忘了看羿几时才发觉碗里多了一口。

卖票人见两个人还趴在窗边，从抽屉里取出一本翻软了角的诗集：“拎去慢慢睇。普希金呢位哲人，好诗仲有好多。今晚先荐《致诗人》。听日还书嗰阵，话我知你哋各自喺边一句停得最耐。”
