# 当黑塞的荒原狼站在吉克普林的四国交点，当打过官司的王力宏跟Namewee在北京胜利会师，谁才是北方真正的生态之王和音乐之王？

*文化副刊 · 寓言社评*

这个标题送到夜班，足足占了三行。美编问，三个“王”字，能否酌删一个？老校对拿红笔圈住头一个。后面两位还待公议，这一个是人家的姓，动不得。

先看吉克普林。姑且让黑塞笔下的哈里·哈勒坐一趟缆车。到了山顶，他展开地图，想照题目所言，一只爪子按住一个国家。地图偏偏认真。新疆禾木有吉克普林雪场，阿尔泰山系有中国、俄罗斯、蒙古国、哈萨克斯坦四个山邻，中俄哈与中俄蒙各有一处三国交界点。哈勒把地图折了一折，四国这才碰头。文学省了好些脚程。

山下的人大约以为，这匹从欧洲名著里走出来的狼，一到荒野便如鱼得水。读过黑塞的倒记得，哈勒租屋那栋楼，楼梯转角养着一盆南洋杉。他喜欢在那里坐坐，闻地板蜡的香气，看人家怎样把一片片叶子擦得干净。如今请他做北方生态之王，他在缆车上想起的，兴许是那个始终没有出场、却肯花工夫擦叶子的人。

倒是林缘有一行爪印，斜斜穿过雪地，到了树影里便看不清了。颁奖的人举起相机，等了半天。要使这张照片好看，自然盼狼回头；要使这片山林容得下狼，就得容它照自己的方向走。明年讨论雪道该修到哪里，那行爪印，理应比今日这篇社评多占一点版面。生态这一席，我们投给那匹让摄影记者交了白卷的狼。

再看北京。把两位歌手请到北京“胜利会师”，是本文借的一座戏台。真有其歌，真有其唱。2017年，马来西亚音乐人黄明志（Namewee）与王力宏合作的《漂向北方》推出。2019年元旦，两人在台北大安森林公园同台唱过。说来也妙，一首写北京的歌，竟能让一群人在台北的雨里，齐声往北方去。

题目特意给王力宏加了个定语，叫“打过官司的”。确有其事，他打过名誉权官司。法庭上，一个人须为自己说过的话负责。到了台上，歌手还有另一门功课，要替一些平日没有麦克风的人，把话送到最后一排。《漂向北方》里，我尤其喜欢两个人交班的那一刻。黄明志的字密，像刚下夜班的人赶末班车，还有半肚子话，得赶在车门合上前讲完。王力宏一接，那个长音把时间撑开了。坐在末排的人，够工夫吸一口气，跟他一起唱。

设想台下有个在北京待了十年的姑娘。家里头九年问她，什么时候回来？到了第十年，她年后收拾箱子，母亲顺口问，哪天回北京？同一个“回”字，母女俩过了十年才把它掉过头来。黄明志的段落，容得下这十年间一桩桩要交代的事。王力宏的副歌，容得下母亲问完那句话、女儿低头扣箱子的片刻。所谓胜利会师，若有什么值得庆贺，大抵是这两种声音终于在同一首歌里相逢。音乐这一席，两人同领。

清样付印前，老校对又来电话，说这次评奖章程有个漏洞。倘若“生态之王和音乐之王”须由同一位兼任，北方倒有一位老资格，四十多年前便以一首《狼》同时报了两项。

美编叹了口气，把刚刚排好的三行标题又往下挪了一行。

**“劳驾，给齐秦留个位。”**
