# 重庆的两只钟

[《重庆，散会以后》](chongqing_after_the_meeting_zh.md)续篇。以下人物对白、县议会记录与报纸均属架空创作。

开春以后，排字工的两个哥哥头一次吵架，是为了同一张招工启事。县里修铁路桥，要招短工二十日，工钱按日结。大哥把启事揭回来，想挣一副犁的钱。二哥把纸摊在饭桌上，拿一粒黄豆从开工那天数起，数到第十七下，说：“哥，那天该咱家放水。你那副新犁，打算犁干田？”

母亲把豆子拈回碗里：“你们先问清楚，做十六天给不给钱。”

谁也没想过要问这个。三弟到了报馆，翻出县里送来的原稿。上头果然一边写“按日计酬”，一边写“工毕给付”。他当了几年排字工，头一回发现，两句都排得对，拼在一处，也够人白干半个月。

县里的铁路工程师后来去议会解释过。他也有一本日历。钢梁在上游装好了船，船家只肯等四天。错过水位，钢梁得在岸上多搁一个月。桥那头的乡民也要春耕，其中有三十几户人家等着这一船捎来的耕牛。二哥听到这里，把原先预备好的那句“当官的只管剪彩”咽了回去。他不知道桥那边还有牛。工程师也不知道，他们村的渠水一年只轮到那么几天。

散会以后，三弟在报馆接到了重庆催问通车日期的电报。国家要追赶，究竟赶什么？对发电报的人来说，抗战好容易胜了，一座桥还得等航期、等钢料、等各县凑款。倘若天下再乱几年，旁人家的孩子已经能自己画桥图，中国的孩子恐怕还要在断桥边上摆渡。这份焦虑有它的道理。但电报上的日期只留了一个空格，填得进通车那一天，填不进沿岸几十处轮灌的日子。

偏偏这时，共国党输掉了县选举。重庆有人提议，让熟悉工程的旧县长再干三个月。理由相当体面，连大哥都觉得不妨：“桥又不晓得哪个当县长。”

母亲问：“那等三个月，是桥等，还是选赢的人等？”

交印那天，新县长请工程师照常上工。议会把修桥的钱分作两笔，钢梁照期起卸，短工每五日领一次工资，修引桥的日期则让沿渠各村报上来重排。代价也写进了账里：承包商多雇了一班人，县里只好把原定粉刷车站候车室的钱拨过去。大哥领到十五天工钱，犁是买不起了，回家跟二哥合计，两家先合租一副。等到通车，来宾下车，果然有人嫌车站墙皮难看。

三弟本来拟了个标题《民众一致拥护通车》。那天他望着两个哥哥，终于把“一致”拆回了字盘。大哥想多挣几天工钱，二哥想赶上放水，桥对岸的人急着领牛。谁能代表底层，把这三种心思说成一句话？

他换了一行小标题，印在通车消息底下：“下月初五议修西渠，沿岸住户可到会，账簿存车站候车室。”有人来查，自然也看见那堵没刷的墙。

若说这段架空历史里的政治由底层驱动，意思大约就在这里。千家万户能让停战成为谁也绕不过的问题，却未必能决定和约上一行字。等到一个种田的人可以站起来说出轮灌的日期，一个工程师必须当面说明水位，一位已经败选的县长也确实交出了印，百姓的日子才进入了决定本身。

当晚，三弟把样报带回家。母亲看完，用指甲在“初五”底下掐了个月牙，折起来收好。她也有一段渠要问。
